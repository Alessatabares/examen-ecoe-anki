# Revisión — Topográfico Clínico


## Pulmon

### Eje Clínico

**Disnea aguda**
- Súbita + dolor pleurítico + timpanismo + sin murmullo unilateral → **Neumotórax (a tensión si IY + desviación traqueal)**
- Súbita + factor de riesgo TVP/inmovilización + Wells alto → **TEP**
- Progresiva en días + fiebre + tos productiva + crepitantes localizados → **Neumonía**
- Sibilancias que revierten con broncodilatador → **Crisis asmática**
- Tabaquismo >10 paq-año + tórax en tonel + no revierte del todo → **EPOC reagudizado**
- Ortopnea + DPN + crepitantes bibasales + S3 → **Edema agudo de pulmón cardiogénico**
- Progresiva en meses + crepitantes «velcro» + acropaquias → **EPID / fibrosis pulmonar**

**Dolor torácico pleurítico**
- + disnea súbita + timpanismo + sin murmullo → **Neumotórax**
- + disnea súbita + hemoptisis + Wells alto → **TEP con infarto pulmonar**
- + fiebre + tos + soplo tubárico (consolidación) → **Neumonía**
- + roce pleural tras cuadro viral → **Pleuritis**
- + matidez basal + abolición del murmullo → **Derrame pleural**

**Tos**
- Aguda + fiebre + expectoración purulenta → **Neumonía / bronquitis aguda**
- Crónica + tabaquismo + expectoración matutina ≥3 meses/2 años → **Bronquitis crónica (EPOC)**
- Crónica + hemoptisis + pérdida de peso + sudoración nocturna → **TB / Ca broncogénico**
- Seca persistente en paciente con IECA → **Tos farmacológica por IECA**
- Nocturna + sibilancias + desencadenantes estacionales → **Asma**

**Hemoptisis**
- + síndrome constitucional + tabaquismo → **Ca broncogénico**
- + fiebre + sudoración nocturna + cavitación apical → **Tuberculosis**
- + disnea súbita + dolor pleurítico → **TEP con infarto pulmonar**
- + expectoración purulenta crónica abundante → **Bronquiectasias**
- Masiva + hematuria + insuficiencia renal → **Síndrome pulmón-riñón (Goodpasture/vasculitis)**

### Integrador

**INSPECCION / SIGNOS VITALES**
- Tiraje + desviación traqueal contralateral · Ingurgitación yugular · Timpanismo unilateral → **Neumotórax a tensión** · _ECOE: es clínico: descompresión con aguja YA, no espero la Rx_
- Tórax en tonel · Espiración prolongada con labios fruncidos · Tabaquismo >10 paq-año → **EPOC** · _ECOE: obstrucción que no revierte; espirometría con FEV1/FVC <0.7_
- Uso de músculos accesorios + cianosis · Incapacidad para completar frases · Silencio auscultatorio → **Crisis asmática grave** · _ECOE: broncodilatador + esteroide; el tórax silente es señal de gravedad_

**PALPACION**
- Frémito vocal AUMENTADO localizado · Fiebre + tos productiva · Matidez en la misma zona → **Neumonía (consolidación)** · _ECOE: consolidación: vibraciones aumentadas, pido Rx de tórax_
- Frémito vocal ABOLIDO · Ausencia de expansión · Matidez basal → **Derrame pleural** · _ECOE: líquido en el espacio pleural; confirmo con USG/Rx_
- Enfisema subcutáneo (crepitación a la palpación) · Antecedente de trauma/barotrauma · Disnea → **Neumotórax** · _ECOE: aire en partes blandas: busco neumotórax asociado_

**PERCUSION**
- Timpanismo unilateral · Abolición del murmullo · Disnea súbita → **Neumotórax** · _ECOE: hiperresonancia + sin murmullo = aire a presión_
- Matidez basal · Abolición de vibraciones vocales · Disminución del murmullo → **Derrame pleural** · _ECOE: matidez con vibraciones abolidas distingue derrame de consolidación_
- Matidez localizada · Frémito AUMENTADO · Soplo tubárico → **Consolidación neumónica** · _ECOE: matidez con vibraciones aumentadas = pulmón consolidado_

**AUSCULTACION**
- Crepitantes localizados · Soplo tubárico · Broncofonía/pectoriloquia → **Neumonía** · _ECOE: foco de consolidación: antibiótico según CURB-65_
- Crepitantes secos bibasales tipo «velcro» · Acropaquias · Disnea progresiva en meses → **EPID / fibrosis pulmonar** · _ECOE: patrón intersticial: solicito TCAR_
- Sibilancias espiratorias difusas · Espiración prolongada · Reversibilidad COMPLETA con broncodilatador → **Asma (el EPOC apenas revierte)** · _ECOE: reversibilidad completa = asma; en EPOC la obstrucción es fija/poco reversible_
- Crepitantes húmedos bibasales · S3 (galope) · Ortopnea + DPN → **Edema agudo de pulmón cardiogénico** · _ECOE: crepitantes + S3 apuntan a falla de bomba, no a infección_
- Ausencia de murmullo unilateral · Timpanismo · Disnea súbita → **Neumotórax** · _ECOE: silencio + timpanismo unilateral = aire pleural_
- Roce pleural · Dolor que aumenta con la inspiración · Antecedente viral → **Pleuritis** · _ECOE: roce que desaparece al contener la respiración_


## Corazon

### Eje Clínico

**Dolor torácico**
- Opresivo retroesternal + irradiado a brazo izq/mandíbula + diaforesís + ST elevado en cara contigua → **IAMCEST (reperfusión <90 min ICP o <30 min fibrinolísis)**
- Opresivo en reposo o crescendo + ECG sin ST elevado + troponina elevada → **IAMSEST (SCA sin elevación del ST; estratificar GRACE)**
- Opresivo con esfuerzo + cede en <10 min con reposo/nitrato + troponina normal → **Angina estable (isquemia demanda; prueba de esfuerzo)**
- Desgarrante de inicio súbito + irradia a espalda interescapular + asimetría de pulsos/TA entre brazos → **Disección aórtica (TC con contraste; control de FC y TA)**
- Pleurítico que mejora al sentarse e inclinarse hacia delante + frote + ST difuso cóncavo + PR descendido → **Pericarditis aguda (AINE + colchicina)**
- Tras herida punzante precordial + hipotensión + ruidos cardíacos apagados + IY → **Taponamiento por trauma penetrante (pericardiocentesis/toracotomía)**

**Palpitaciones**
- Pulso irregularmente irregular + déficit de pulso + ECG sin onda P + R-R variable → **Fibrilación auricular (control FC + anticoagular según CHA2DS2-VASc)**
- Palpitaciones rápidas + síncope + QRS ancho regular + disociación AV → **Taquicardia ventricular (cardioversión si inestable)**
- Bradicardia + síncope + PR > 200 ms fijo o disociación AV completa → **Bloqueo AV (segundo/tercer grado; valorar marcapasos)**
- Palpitaciones de inicio y fin súbitos + QRS estrecho regular ~150-220 lpm → **Taquicardia supraventricular paroxistica (maniobras vagales/adenosina)**
- Latidos aislados percibidos como vuelco + pausa compensadora + bigeminismo en ECG → **Extrasístoles ventriculares (benignas si corazón sano)**

**Síncope**
- Síncope de esfuerzo + soplo sistólico eyectivo en foco aórtico irradiado a carótidas + pulso parvus et tardus → **Estenosis aórtica severa (recambio valvular si sintomática)**
- Síncope brusco sin pródromos + palpitaciones previas + QT largo o TV documentada → **Síncope arrítmico (monitorizar; riesgo de muerte súbita)**
- Síncope precedido de náuseas/sudoración/visión en túnel + bipedestación prolongada → **Síncope vasovagal (medidas posturales; benigno)**
- Mareo/síncope al incorporarse + caída de TA sistólica ≥ 20 mmHg de pie → **Síncope ortostático (revisar fármacos/volemia)**
- Síncope + dolor desgarrante + diferencia de TA > 20 mmHg entre brazos → **Disección aórtica (emergencia; imagen urgente)**

**Disnea y edema (insuficiencia cardíaca)**
- Disnea de esfuerzo + ortopnea + DPN + crepitantes bibasales + S3 + FEVI < 40% → **IC con FE reducida (FEr; IECA/ARNI + betabloqueante + ARM + iSGLT2)**
- Disnea + HTA + crepitantes + FEVI ≥ 50% conservada + S4 + hipertrofia VI → **IC con FE preservada (FEp; control de TA y comorbilidades)**
- Edemas en miembros inferiores + IY + hepatomegalia + reflujo hepatoyugular → **IC derecha/congestión sistémica (diuréticos de asa)**
- Disnea súbita + ortopnea extrema + crepitantes hasta ápices + esputo rosado → **Edema agudo de pulmón (O2 + nitratos + diurético + VMNI)**
- Fiebre + soplo nuevo + disnea + petequias/nódulos de Osler + hemocultivos positivos → **Endocarditis infecciosa (Duke; antibiótico precoz)**

**Soplo**
- Soplo sistólico eyectivo crescendo-decrescendo en foco aórtico irradiado a carótidas + clic ausente → **Estenosis aórtica (gradiente medio ≥ 40 mmHg = severa)**
- Soplo diastólico decrescendo en borde paraesternal izq + pulso celer (salton) + presión de pulso amplia → **Insuficiencia aórtica (valorar dilatación VI)**
- Soplo holosistólico en ápex irradiado a axila + S3 + soplo que no varía con respiración → **Insuficiencia mitral (cirugía si sintomática/FEVI baja)**
- Soplo diastólico retumbante en ápex + chasquido de apertura + refuerzo presistólico → **Estenosis mitral (frecuente FA; reumatica)**
- Fiebre + soplo nuevo o cambiante + fenómenos embólicos + vegetación en eco → **Endocarditis infecciosa (hemocultivos + ecocardiograma)**

### Integrador

**INSPECCION GENERAL Y SIGNOS VITALES**
- Hipotensión + taquicardia + piel fría y sudorosa · Mala perfusión periférica · Relleno capilar > 2 s → **Shock cardiogénico** · _ECOE: TA baja con pulmones congestivos: pienso en fallo de bomba, pido eco urgente_
- Herida penetrante en zona precordial · Hipotensión + ruidos apagados · Ingurgitación yugular → **Taponamiento por trauma penetrante** · _ECOE: Herida en la caja de Beck: busco la tríada y preparo pericardiocentesis_
- Cianosis + diaforesís + ansiedad · Taquipnea + uso de musculatura accesoria · Esputo asalmonado → **Edema agudo de pulmón** · _ECOE: Paciente sentado y disnéico: O2 y diurético mientras confirmo_
- Fiebre + estigmas periféricos (Janeway/Osler) · Petequias conjuntivales · Hemorragias en astilla → **Endocarditis infecciosa** · _ECOE: Fiebre con soplo: saco tres hemocultivos antes del antibiótico_

**PULSOS Y TENSION ARTERIAL**
- Pulso irregularmente irregular · Déficit de pulso (FC central > periférica) · Sin onda P en ECG → **Fibrilación auricular** · _ECOE: Tomo el pulso un minuto completo: irregular sin patrón, sospecho FA_
- Asimetría de pulsos entre ambos brazos · Diferencia de TA > 20 mmHg · Pulso radial-femoral retardado → **Disección aórtica** · _ECOE: Mido TA en los dos brazos: si difieren mucho pienso en disección_
- Pulso parvus et tardus (pequeño y retardado) · Presión de pulso estrecha · Soplo aórtico asociado → **Estenosis aórtica** · _ECOE: Pulso carotídeo lento y pequeño: orienta a obstrucción aórtica_
- Pulso celer et magnus (saltón/colapsante) · Presión de pulso amplia · Pulso de Corrigan → **Insuficiencia aórtica** · _ECOE: Pulso que sube y baja rápido: sugiere regurgitación aórtica_
- Pulso paradojico (cae > 10 mmHg en inspiración) · Hipotensión · Taquicardia → **Taponamiento cardíaco** · _ECOE: Si el pulso desaparece al inspirar mido el pulso paradojico_

**PALPACION PRECORDIAL**
- Latido de la punta desplazado hacia abajo y afuera · Íctus amplio y sostenido · Sobrecarga de volumen → **Cardiomegalia por IC con FEr** · _ECOE: Palpo el íctus fuera de la línea medioclavicular: VI dilatado_
- Íctus sostenido y poco desplazado (sustained) · Impulso apical en cúpula · Hipertrofia VI → **Estenosis aórtica / HTA crónica** · _ECOE: Íctus potente pero localizado: hipertrofia por sobrecarga de presión_
- Frémito sistólico en foco aórtico · Thrill palpable · Soplo ≥ grado IV → **Estenosis aórtica severa** · _ECOE: Si palpo el thrill el soplo es al menos grado cuatro_
- Frote pericardico palpable + dolor que mejora sentado · Roce sistólico-diastólico · Sin desplazamiento del íctus → **Pericarditis aguda** · _ECOE: Palpo y ausculto el roce que cambia con la postura_

**AUSCULTACION POR FOCOS**
- Soplo eyectivo en foco aórtico (2º EID) irradiado a carótidas · Disminución del 2º ruido · Pulso parvus et tardus → **Estenosis aórtica** · _ECOE: Ausculto en el 2º espacio derecho e irradia al cuello: estenosis aórtica_
- Soplo diastólico decrescendo en foco aórtico/Erb · Mejor con paciente inclinado y en espiración · Presión de pulso amplia → **Insuficiencia aórtica** · _ECOE: Lo oigo mejor con el paciente inclinado hacia delante en espiración_
- Soplo que aumenta en inspiración en foco tricúspide (4º EID) · Onda v yugular prominente · Hepatomegalia pulsatil → **Insuficiencia tricúspide / fallo derecho** · _ECOE: El soplo que crece al inspirar es derecho: signo de Rivero-Carvallo_
- Soplo holosistólico en foco mitral (ápex) irradiado a axila · S3 audible · No varía con respiración → **Insuficiencia mitral** · _ECOE: Soplo en punta que va a la axila y no cambia con respirar: mitral_
- Tercer ruido (S3) de galope protodiastólico · Ritmo de galope + crepitantes · FEVI reducida → **IC con FE reducida** · _ECOE: El S3 en un adulto con disnea me dice sobrecarga de volumen_
- Cuarto ruido (S4) presistólico · Ventrículo rígido · FEVI preservada + HVI → **IC con FE preservada** · _ECOE: El S4 refleja un ventrículo rígido que cuesta llenar_
- Frote pericardico de tres componentes · Aumenta inclinado hacia delante · ST difuso cóncavo → **Pericarditis aguda** · _ECOE: El roce de cuero suena en sístole y diástole y cambia con la postura_

**INGURGITACION YUGULAR Y CONGESTION**
- PVY elevada (> 3 cm sobre ángulo esternal) + reflujo hepatoyugular · Edemas con fóvea · Hepatomegalia congestiva → **IC derecha/congestiva** · _ECOE: Mido la presión venosa yugular a 45 grados: está elevada_
- IY que aumenta en inspiración (signo de Kussmaul) · Ruidos apagados · Pulso paradojico → **Taponamiento cardíaco (tríada de Beck)** · _ECOE: IY + hipotensión + ruidos apagados: tríada de Beck, taponamiento_
- Onda a en cañón en el pulso yugular · Bradicardia + síncope · Disociación AV en ECG → **Bloqueo AV completo** · _ECOE: Las ondas a en cañón me indican disociación auriculoventricular_


## Higado-Biliar

### Eje Clínico

**Ictericia**
- Ictericia + coluria + acolia + prurito + GGT/FA muy altas → **Ictericia obstructiva (colestasis)**
- Ictericia + dolor cólico HCD + Murphy + fiebre → **Colecistitis / coledocolitiasis**
- Ictericia + fiebre con escalofríos + dolor HCD (tríada de Charcot) → **Colangitis aguda**
- Ictericia indolora + vesícula palpable no dolorosa (Courvoisier) + pérdida de peso → **Cáncer de cabeza de páncreas**
- Ictericia + AST/ALT > 1000 + astenia + transaminasas en miles → **Hepatitis viral aguda**
- Ictericia + AST/ALT > 2 con AST < 300 + GGT alta + hábito enolíco → **Hepatitis alcohólica**
- Ictericia + flapping + ascitis + INR alto en hepátata crónico → **Insuficiencia hepática / cirrosis descompensada**

**Dolor en hipocondrio derecho / epigastrio**
- Dolor cólico HCD tras comida grasa + ecografía con cálculos, sin fiebre → **Cólico biliar (colelitiasis)**
- Dolor HCD continuo + Murphy positivo + fiebre + leucocitosis → **Colecistitis aguda**
- Dolor epigástrico en cinturón irradiado a espalda + lipasa > 3x + vómitos → **Pancreatitis aguda**
- Dolor epigástrico sordo + pérdida de peso + esteatorrea + DM de novo → **Cáncer de páncreas**
- Dolor HCD sordo + hepatomegalia dolorosa + estigmas de hepatopatía → **Hepatitis / hepatomegalia congestiva**
- Dolor epigástrico crónico + esteatorrea + calcificaciones pancreáticas → **Pancreatitis crónica**

**Ascitis / distensión abdominal**
- Ascitis + circulación colateral + esplenomegalia + varices esofágicas → **Hipertensión portal (cirrosis)**
- Ascitis + GASA ≥ 1.1 g/dL + albuminemia baja → **Ascitis por cirrosis (transudado portal)**
- Ascitis + fiebre + dolor abdominal difuso + PMN > 250/mm3 en líquido → **Peritonitis bacteriana espontánea**
- Distensión + AST/ALT < 1 + obesidad + DM2 + dislipemia → **MASLD / MASH (esteatosis metabólica)**
- Ascitis + oliguria + creatinina al alza sin otra causa renal → **Síndrome hepatorrenal**
- Ascitis + vesícula y vía biliar normales + nódulos hepáticos → **Cirrosis / hepatocarcinoma**

**Hemorragia digestiva / anemia**
- Hematemesis en chorro + melenas + hepatopatía conocida → **Hemorragia por varices esofágicas**
- Melenas + hipotensión + estigmas de cirrosis + esplenomegalia → **Hipertensión portal con sangrado**
- Anemia + trombopenia + leucopenia (hiperesplenismo) en cirótico → **Hiperesplenismo por hipertensión portal**
- Hematemesis + dolor epigástrico + AINE / alcohol, sin hepatopatía → **Úlcera / gastritis (diagnóstico diferencial)**
- Sangrado + INR prolongado + bilirrubina alta + flapping → **Coagulopatía por insuficiencia hepática**

**Alteración del estado mental / metabólica**
- Confusión + asterixis (flapping) + fetor hepático + amonio alto → **Encefalopatía hepática**
- Somnolencia + estreñimiento o sangrado digestivo como desencadenante en cirótico → **Encefalopatía hepática precipitada**
- Sudoración + temblor + confusión que cede con glucosa (tríada de Whipple) → **Hipoglucemia / insulinoma**
- Poliuria + polidipsia + pérdida de peso + glucemia > 200 + cetosis → **Diabetes mellitus descompensada**
- Ictericia + encefalopatía + INR > 1.5 sin hepatopatía previa (< 26 sem) → **Insuficiencia hepática aguda (fallo fulminante)**

### Integrador

**INSPECCION**
- Coloración amarilla de escleras · Coloración amarilla de piel · Lechos ungueales/frenillo ictéricos → **Ictericia** · _ECOE: explorar con luz natural; descartar carotenemia (escleras respetadas)_
- Abdomen distendido en batracio · Ombligo evertido · Flancos abombados → **Ascitis** · _ECOE: confirmar con matidez cambiante; GASA ≥ 1.1 sugiere origen portal_
- Arañas vasculares en tórax · Circulación colateral abdominal (cabeza de medusa) · Ginecomastia → **Estigmas de hepatopatía crónica** · _ECOE: signos de hiperestrogenismo e hipertensión portal_
- Equimosis y petequias · Sangrado de mucosas · Hematomas espontáneos → **Coagulopatía** · _ECOE: insuficiencia hepática: corregir con vitamina K / plasma_

**PALPACION ABDOMINAL**
- Borde hepático > 2 cm bajo reborde costal · Superficie nodular y dura · Hepatomegalia dolorosa → **Hepatomegalia** · _ECOE: dura/nodular sugiere cirrosis o tumor; dolorosa sugiere congestión/hepatitis_
- Dolor en HCD al inspirar con palpación subcostal · Detención brusca de la inspiración · Defensa local → **Signo de Murphy positivo** · _ECOE: colecistitis aguda: ecografía + antibiótico + colecistectomía_
- Vesícula palpable lisa e indolora · Sin defensa · Asociada a ictericia → **Signo de Courvoisier** · _ECOE: obstrucción maligna distal (cáncer de páncreas)_
- Polo de bazo palpable bajo reborde costal izquierdo · Crece hacia FID en inspiración · Asociado a citopenias → **Esplenomegalia** · _ECOE: hiperesplenismo por hipertensión portal_
- Defensa epigástrica + dolor en cinturón · Equimosis periumbilical (Cullen) · Equimosis en flanco (Grey-Turner) → **Pancreatitis grave** · _ECOE: pancreatitis necrohemorrágica: ingreso/UCI_

**PERCUSION**
- Matidez en flancos en decúbito supino · Matidez que se desplaza al girar al paciente · Timpanismo central → **Matidez cambiante** · _ECOE: confirma ascitis libre > 1.5 L_
- Onda transmitida al percutir un flanco · Se palpa en el flanco contralateral · Bloqueo con mano en línea media → **Oleada/signo de la ola** · _ECOE: ascitis a tensión; valorar paracentesis evacuadora_
- Matidez hepática disminuida o ausente · Timpanismo sobre área hepática · Dolor a la percusión → **Pérdida de matidez hepática** · _ECOE: neumoperitoneo: sospechar perforación de víscera hueca_
- Aumento del área de matidez hepática (> 12 cm LMC) · Borde inferior descendido · Sin desplazamiento → **Hepatomegalia por percusión** · _ECOE: estimar tamaño hepático en línea medioclavicular_

**SIGNOS NEUROLOGICOS Y CUTANEOS**
- Temblor aleteante al extender las muñecas · Lapsos de tono postural · Bilateral y arrítmico → **Asterixis (flapping)** · _ECOE: encefalopatía hepática: lactulosa + tratar precipitante_
- Enrojecimiento de eminencias tenar e hipotenar · Respeta zona central · Indoloro → **Eritema palmar** · _ECOE: estigma de hepatopatía crónica / hiperestrogenismo_
- Aliento dulzón / a tierra húmeda · Asociado a desorientación · En hepatópata → **Fetor hepático** · _ECOE: marcador de insuficiencia hepatocelular grave_
- Contractura indolora de aponeurosis palmar · Dedos en flexión fija (4º-5º) · Asociada a enolismo → **Contractura de Dupuytren** · _ECOE: asociada a hepatopatía alcohólica crónica_


## Intestino

### Eje Clínico

**Dolor abdominal agudo**
- Migra de epigastrio a FID + Blumberg + anorexia → **Apendicitis**
- FII en >50a + fiebre + masa palpable → **Diverticulitis**
- Súbito epigástrico + abdomen en tabla + AINE → **Úlcera perforada**
- Desproporcionado a la exploración + FA/cardiopatía → **Isquemia mesentérica**
- Cólico + distensión + no ventosea + vacío de heces → **Obstrucción intestinal**
- Difuso + tabla rígida + sepsis + silencio abdominal → **Peritonitis**
- FID/periumbilical recurrente + diarrea + fisura perianal → **Crohn**

**Hemorragia digestiva alta**
- Hematemesis en posos de café + AINE/H. pylori → **Úlcera péptica (HDA)**
- Hematemesis masiva + hepátopata/alcohol → **Varices esofágicas**
- Sangrado tras vómitos/arcadas repetidas → **Mallory-Weiss**
- Melenas + síndrome constitucional + saciedad precoz → **Cáncer gástrico**
- Dolor torácico + enfisema subcutáneo tras vómito → **Boerhaave (perforación esofágica, NO es HDA: la urgencia es mediastinitis, no el sangrado)**

**Hemorragia digestiva baja**
- Hematoquezia indolora + >50a + cambio del ritmo → **Cáncer de colon**
- Rectorragia roja brillante al final de la defecación → **Hemorroides**
- Sangre roja + dolor intenso al defecar + estreñimiento → **Fisura anal**
- Diarrea sanguinolenta + moco + tenesmo + brotes → **Colitis ulcerosa**
- Sangrado rojo oscuro abundante en >60a indoloro → **HDB (diverticular/angiodisplasia)**
- Diverticulitis previa + hematoquezia autolimitada → **HDB diverticular**

**Disfagia**
- Disfagia a sólidos progresiva + pérdida de peso + >55a → **Cáncer de esófago**
- Disfagia a sólidos y líquidos + regurgitación nocturna → **Acalasia**
- Pirosis retroesternal + regurgitación ácida postprandial → **ERGE**
- Disfagia + impactación alimentaria en joven atópico → **Esofagitis eosinofílica**

**Vómito y obstrucción**
- Vómito bilioso + distensión + cirugía abdominal previa → **Obstrucción por bridas**
- Distensión masiva + anciano encamado + asa en grano de café → **Vólvulo de sigma**
- Vómito fecaloideo + ausencia total de gas/heces → **Obstrucción completa**
- Obstrucción + ancianos + cambio ritmo + pérdida de peso → **Obstrucción por Ca colon**
- Vómito + dolor desproporcionado + lactato elevado → **Isquemia mesentérica**

### Integrador

**INSPECCION**
- Distensión abdominal generalizada · Timpanismo a la percusión · Ausencia de ventoseo/heces → **Obstrucción intestinal** · _ECOE: valorar nivel: TC con contraste; SNG descompresión_
- Cicatrices de laparotomía previas · Distensión + cólico · Peristaltismo visible de lucha → **Obstrucción por bridas** · _ECOE: causa más frecuente de obstrucción de delgado_
- Asa distendida asimétrica en grano de café · Anciano + estreñimiento crónico · Timpanismo difuso → **Vólvulo de sigma** · _ECOE: Rx con asa en grano de café; desvolvulación endoscópica_
- Ictericia + circulación colateral · Ascitis + telangiectasias · Distensión por líquido → **Hepatopatía (riesgo de varices)** · _ECOE: buscar varices: endoscopia + profilaxis betabloqueante_

**AUSCULTACION**
- Ruidos aumentados metálicos de lucha · Distensión + cólico · Vómito bilioso → **Obstrucción mecánica** · _ECOE: fase inicial hiperperistáltica antes del silencio_
- Silencio abdominal (ausencia de ruidos) · Abdomen en tabla + defensa · Fiebre + taquicardia → **Peritonitis / íleo paralítico** · _ECOE: abdomen agudo quirúrgico: cirugía urgente_
- Ruidos ausentes + dolor desproporcionado · FA/cardiopatía embolígena · Lactato y D-dímero elevados → **Isquemia mesentérica** · _ECOE: angioTC urgente; tiempo es intestino_
- Soplo abdominal · Dolor postprandial crónico + pérdida de peso · Sitofobia → **Isquemia mesentérica crónica** · _ECOE: angina abdominal por ateromatosis_

**PALPACION**
- Dolor máximo en punto de McBurney · Blumberg (rebote) positivo · Psoas/Rovsing positivos → **Apendicitis** · _ECOE: Alvarado ≥7; ecografía/TC; apendicectomía_
- Defensa y masa dolorosa en FII · Fiebre + >50a · Blumberg local → **Diverticulitis** · _ECOE: TC: clasificación de Hinchey; ATB +/- drenaje_
- Abdomen en tabla (defensa generalizada) · Blumberg difuso · Inmovilidad antialágica → **Peritonitis por perforación** · _ECOE: aire libre en Rx tórax; laparotomía urgente_
- Masa palpable en FID + febrícula · Diarrea crónica + pérdida de peso · Fisura perianal asociada → **Crohn (plastón/absceso)** · _ECOE: colonoscopia + calprotectina; biología si fistuliza_
- Masa abdominal dura irregular + adenopatías · Síndrome constitucional · Hepatomegalia nodular → **Cáncer de colon** · _ECOE: colonoscopia + biopsia; estadiaje TC; CEA_

**PERCUSION**
- Timpanismo generalizado aumentado · Distensión + obstrucción · Asa fija dilatada → **Obstrucción intestinal** · _ECOE: diferenciar mecánica de íleo_
- Pérdida de la matidez hepática · Aire libre subdiafragmático · Abdomen en tabla → **Víscera perforada** · _ECOE: signo de Jobert; neumoperitoneo: cirugía urgente_
- Matidez cambiante (ascitis) · Oleada ascítica · Hepatopatía + colaterales → **Ascitis (hipertensión portal)** · _ECOE: paracentesis diagnóstica; descartar PBE_

**TACTO RECTAL**
- Sangre roja brillante en el dedo de guante · Paquetes hemorroidales no dolorosos · Prolapso al esfuerzo → **Hemorroides** · _ECOE: grado y tratamiento según clínica; ligadura/cirugía_
- Dolor intenso que impide el tacto + espásticidad · Desgarro posterior en línea media · Sangre roja al defecar + estreñimiento → **Fisura anal** · _ECOE: baños de asiento + nitroglicerina/diltiazem tópico_
- Tumoración fluctuante perianal dolorosa · Fiebre + eritema local · Supuración → **Absceso perianal** · _ECOE: drenaje quirúrgico urgente; vigilar fístula_
- Masa rectal dura fija + sangre/moco · Dedil manchado de sangre oscura · Cambio del ritmo intestinal → **Cáncer de recto** · _ECOE: colonoscopia + biopsia; RM pelvis para estadiaje_
- Heces negras alquitranadas (melena) en el dedil · Hematemesis + AINE · Anemia → **HDA por úlcera péptica** · _ECOE: endoscopia urgente; IBP iv; clasificación de Forrest_


## Rinon-Urinario

### Eje Clínico

**Oliguria / anuria**
- Hipotensión + sed + mucosas secas + FeNa <1% + BUN/Cr >20 → **AKI prerrenal (por hipoperfusión)**
- Hipovolemia por vómitos/diarrea/diuréticos + orina concentrada Na <20 → **AKI prerrenal**
- Tras hipotensión/sepsis/nefrotóxico + cilindros granulosos pardos + FeNa >2% → **Necrosis tubular aguda (NTA)**
- Anuria súbita + globo vesical + dilatación bilateral en USG → **Obstrucción postrenal (uropatía obstructiva)**
- Oliguria + edema + HTA + hematuria con cilindros hemáticos → **Síndrome nefrítico (GN aguda)**
- Varón mayor + globo vesical palpable + goteo y chorro débil previos → **Retención urinaria por HBP**
- Oliguria progresiva en meses + eGFR bajo crónico + riñones pequeños → **Enfermedad renal crónica (ERC)**

**Hematuria**
- Microhematuria + cilindros hemáticos + hematíes dismorficos + proteinuria → **Síndrome nefrítico (origen glomerular)**
- Macrohematuria + cólico lumbar irradiado a genitales + agitación → **Litiasis ureteral**
- Hematuria + disuria + polaquiuria + dolor suprapúbico sin fiebre → **Cistitis**
- Macrohematuria indolora + tabaquismo + edad avanzada → **Neoplasia urotelial (descartar)**
- Hematuria + fiebre + lumbalgia + puño-percusión positiva → **Pielonefritis aguda**
- Hematuria 1-2 días tras infección respiratoria (sinífaringitis) → **Nefropatía IgA**

**Edema**
- Edema gravitacional + proteinuria >3.5 g/día + hipoalbuminemia + hiperlipidemia → **Síndrome nefrótico**
- Edema periorbitario matutino + HTA + hematuria + oliguria → **Síndrome nefrítico**
- Edema generalizado + eGFR bajo + albuminuria + anemia + sobrecarga → **ERC con sobrecarga de volumen**
- Edema con espuma en la orina (proteinuria masiva) + trombosis venosa → **Síndrome nefrótico (estado protrombótico)**
- Edema + balance positivo tras reposición excesiva en AKI → **Sobrecarga hídrica iátrogena**

**Dolor lumbar / cólico renal**
- Cólico súbito en flanco irradiado a ingle + paciente inquieto + hematuria → **Litiasis (cólico nefrítico)**
- Lumbalgia + fiebre alta + escalofríos + Giordano positivo + piuria → **Pielonefritis aguda**
- Dolor lumbar + anuria + hidronefrosis bilateral en USG → **Uropatía obstructiva**
- Lumbalgia + fiebre + obstrucción (cálculo que no progresa) → **Pionefrosis / sepsis urinaria obstructiva (urgencia)**
- Dolor sordo crónico + riñones poliquísticos palpables + HTA → **Poliquistosis renal (PQRAD)**

**Síndrome urinario (disuria / polaquiuria)**
- Disuria + polaquiuria + urgencia + dolor suprapúbico SIN fiebre → **Cistitis (ITU baja)**
- Disuria + fiebre + lumbalgia + Giordano positivo + malestar general → **Pielonefritis (ITU alta)**
- Disuria + secreción uretral + pareja con síntomas → **Uretritis (ITS)**
- Polaquiuria + nicturia + chorro débil + goteo en varón mayor → **HBP**
- Disuria + piuria estéril (urocultivo negativo de rutina) → **Uretritis por Chlamydia / TB urinaria**
- Síntomas urinarios + exantema + eosinofilia + fármaco reciente (AINE/antibiótico) → **Nefritis intersticial aguda (NIA)**

### Integrador

**SIGNOS VITALES / VOLEMIA**
- Hipotensión ortostática + taquicardia + mucosas secas · Pliegue cutáneo lento + sed · Oliguria con orina concentrada → **AKI prerrenal (hipovolemia)** · _ECOE: valoro volemia: la prerrenal mejora con reposición; pido FeNa y BUN/Cr_
- Fiebre + taquicardia + hipotensión · Lumbalgia + Giordano positivo · Oliguria → **Sepsis urinaria / pielonefritis** · _ECOE: shock séptico de foco urinario: hemocultivo + antibiótico precoz + líquidos_
- HTA + edema + ingurgitación yugular · Crepitantes bibasales (sobrecarga) · Oliguria reciente → **AKI/ERC con sobrecarga de volumen** · _ECOE: hipervolemia: restrinjo líquidos y Na, valoro diálisis si refractario_

**PUNO-PERCUSION RENAL (GIORDANO)**
- Puño-percusión lumbar dolorosa unilateral · Fiebre alta + escalofríos · Piuria + bacteriuria → **Pielonefritis aguda** · _ECOE: Giordano positivo + fiebre = ITU alta; urocultivo y antibiótico, no solo tira_
- Puño-percusión positiva + dolor cólico que no cede · Paciente inquieto que no halla postura · Hematuria + fiebre → **Cálculo obstructivo infectado (urgencia)** · _ECOE: obstrucción + fiebre exige drenaje urgente (catéter doble J / nefrostomía)_
- Puño-percusión negativa · Disuria + polaquiuria sin fiebre · Dolor suprapúbico → **Cistitis (ITU baja)** · _ECOE: Giordano negativo + sin fiebre orienta a vejiga, no a riñón_

**PALPACION VESICAL (GLOBO)**
- Masa suprapúbica mate redondeada y dolorosa · Deseo miccional intenso sin poder orinar · Varón mayor con prostatismo → **Retención urinaria aguda (HBP)** · _ECOE: globo vesical: sondaje vesical descompresivo; alivia el dolor y protege el riñón_
- Globo vesical + anuria + creatinina elevada · Hidronefrosis bilateral en USG · Antecedente de obstrucción baja → **AKI postrenal obstructiva** · _ECOE: descomprimo (sonda/nefrostomía): la causa postrenal es potencialmente reversible_
- Ausencia de globo + oliguria · Mucosas secas / hipotensión · FeNa <1% → **AKI prerrenal** · _ECOE: vejiga vacía descarta retención; el problema es de perfusión, no obstructivo_

**EXAMEN DE ORINA / SEDIMENTO (INTERPRETACION)**
- Cilindros granulosos pardos (muddy brown) · FeNa >2% + Na urinario >40 · Tras isquemia o nefrotóxico → **Necrosis tubular aguda (NTA)** · _ECOE: cilindros pardos + FeNa alta = daño tubular intrínseco, ya no prerrenal_
- Cilindros hemáticos + hematíes dismorficos · Proteinuria + HTA + edema · Oliguria → **Síndrome nefrítico (glomérulo)** · _ECOE: cilindros hemáticos = hematuria glomerular; estudio inmunológico y complemento_
- Proteinuria >3.5 g/24h + cuerpos ovales grasos (cruz de Malta) · Hipoalbuminemia + hiperlipidemia · Edema con espuma → **Síndrome nefrótico** · _ECOE: proteinuria masiva define el nefrótico; cuantifico con cociente proteína/creatinina_
- Leucocituria + nitritos + bacteriuria · Disuria + polaquiuria · Urocultivo >100000 UFC → **ITU (cistitis / pielonefritis)** · _ECOE: tira con nitritos + leucocitos apoya ITU; confirmo con urocultivo antes de antibiótico_
- Piuria estéril + cilindros leucocitarios + eosinofiluria · Exantema + eosinofilia + fármaco reciente · Creatinina en ascenso → **Nefritis intersticial aguda (NIA)** · _ECOE: piuria estéril + eosinófilos + fármaco = NIA; retiro el fármaco causal_
- Cristaluria + hematuria + pH orientativo · Cólico lumbar irradiado a ingle · Imagen de cálculo en USG/TC → **Litiasis renal** · _ECOE: cristales y hematuria con cólico apoyan litiasis; TC sin contraste lo confirma_

**EDEMA / BALANCE HIDRICO (KDIGO-ERC)**
- Fovea en miembros inferiores + edema palpebral · Proteinuria + hipoalbuminemia · Aumento de peso → **Síndrome nefrótico** · _ECOE: edema con foveola + proteinuria masiva; pierdo albumina por orina, retengo agua y sal_
- eGFR <60 sostenido ≥3 meses + albuminuria · Anemia + hiperfosfatemia + acidosis · HTA + edema → **ERC (estadios G y A de KDIGO)** · _ECOE: clasifico por eGFR (G1-G5) y albuminuria (A1-A3); no es solo un número de creatinina_
- Diuresis <0.5 ml/kg/h ≥6 h o creatinina en ascenso · Balance hídrico positivo · Sobrecarga de volumen → **AKI (criterios KDIGO)** · _ECOE: AKI por diuresis/creatinina; vigilo K+, acidosis y sobrecarga (indicaciones de diálisis: AEIOU)_
- Edema refractario + hiperpotasemia + acidosis + urémia · Pericarditis o encefalopatía urémica · Sobrecarga que no responde a diurético → **Indicación de diálisis urgente** · _ECOE: AEIOU: Acidosis, Electrolitos (K+), Intoxicación, Overload, Urémia → diálisis_


## SNC

### Eje Clínico

**Déficit focal agudo (vascular)**
- Hemiparesia + afasia de instauración súbita, <4.5 h → **EVC isquémico → activar código ictus**
- Déficit focal + FA / valvulopatía / soplo carotídeo → **EVC isquémico cardioembolico / aterotrombotico**
- Déficit focal + cefalea intensa + HTA + vomito + deterioro rápido → **EVC hemorragico (hematoma intraparenquimatoso)**
- Déficit focal que revierte por completo en <1 h, sin lesión en TC → **AIT (accidente isquémico transitorio) → estudio urgente, ABCD2**
- Cefalea en trueno (peor de la vida) + rigidez nucal ± síncope → **HSA (hemorragia subaracnoidea) → TC sin contraste; si normal, punción lumbar**
- Vértigo + diplopía + disártria + ataxia (síndrome cruzado) → **EVC de fosa posterior / territorio vertebrobasilar**

**Cefalea con red flags**
- Cefalea en trueno que alcanza máximo en segundos → **HSA hasta demostrar lo contrario**
- Cefalea progresiva semanas + vomito matutino + papiledema → **HIC / tumor cerebral (efecto masa)**
- Cefalea + fiebre + rigidez nucal + fotofobia → **Meningitis → hemocultivos + PL + antibiótico precoz**
- Cefalea + fiebre + foco infeccioso (otitis/sinusitis) + déficit focal → **Absceso cerebral**
- Cefalea + alteración del comportamiento + crisis + fiebre → **Encefalitis (herpética: aciclovir empírico)**
- Cefalea peor en decúbito/Valsalva + marcha inestable + incontinencia → **Hidrocefalia (HTIC / normotensiva si triada de Hakim)**
- Cefalea + dolor mandíbula al masticar + arteria temporal indurada (>50 a) → **Arteritis de células gigantes → corticoide urgente, VSG**

**Alteración de la conciencia**
- Anciano con cefalea progresiva + somnolencia tras caída/ACO → **Hematoma subdural crónico**
- TCE con intervalo lúcido y luego deterioro rápido + anisocoria → **Hematoma epidural (sangrado arterial) → ciruga urgente**
- Confusión postcrítica (postictal) tras movimientos tónico-clónicos → **Crisis convulsiva (estado postictal)**
- Crisis continuas o sin recuperar conciencia >5 min → **Estatus epiléptico → benzodiacepina IV**
- Deterioro de conciencia + fiebre + rigidez nucal → **Meningoencefalitis**
- Coma + hipertensión + bradicardia + respiración irregular (triada Cushing) → **HTIC / herniación inminente**

**Debilidad / parálisis (patrón)**
- Hemiparesia + hiperreflexia + Babinski + espasticidad (1.ª neurona) → **Lesión central (corteza/cápsula/tronco) → EVC / masa**
- Debilidad ascendente simétrica + arreflexia, sin nivel sensitivo → **Síndrome de Guillain-Barré → vigilar fuerza respiratoria**
- Para/tetraparesia + nivel sensitivo + retención urinaria + dolor dorsal → **Compresión medular → RM urgente + corticoide**
- Brotes neurológicos diseminados en tiempo y espacio (neuritis óptica, diplopia) → **Esclerosis múltiple**
- Debilidad facial periférica que afecta frente (no respeta) sin otro foco → **Parálisis de Bell (VII periférico)**
- Temblor de reposo + bradicinesia + rigidez en rueda dentada → **Enfermedad de Parkinson**

**Cronicidad / degenerativo**
- Deterioro cognitivo progresivo de memoria, sin deficit focal agudo → **Demencia (Alzheimer)**
- Deterioro cognitivo escalonado + factores de riesgo vascular → **Demencia vascular**
- Triada marcha apráxica + incontinencia + deterioro cognitivo → **Hidrocefalia normotensiva (Hakim)**
- Temblor de reposo unilateral + micrografía + cara hipomímica → **Enfermedad de Parkinson**
- Fluctuación cognitiva + alucinaciones visuales + parkinsonismo → **Demencia por cuerpos de Lewy**

### Integrador

**ESTADO MENTAL Y GLASGOW**
- Apertura ocular al dolor · Respuesta verbal confusa · Localiza el dolor → **Glasgow 11 → deterioro de conciencia, vigilar va aérea** · _ECOE: Glasgow = ocular(4) + verbal(5) + motor(6); ≤8 valoro intubación_
- No apertura ocular · Sin respuesta verbal · Sin respuesta motora → **Glasgow 3 → coma profundo** · _ECOE: Glasgow ≤8: protejo va aérea, TC urgente_
- Desorientado en tiempo y lugar · Memoria reciente alterada · Cálculo y atención fallidos → **Deterioro cognitivo → aplico Minimental** · _ECOE: exploro funciones superiores; descarto delirium vs demencia_
- Inicio súbito de confusión · Fluctuación horaria · Inatención marcada → **Delirium → busco causa orgánica** · _ECOE: delirium es agudo y fluctuante; demencia es crónica y estable_

**PARES CRANEALES Y FONDO DE OJO**
- Papiledema bilateral en fondo de ojo · Cefalea progresiva · Vómito matutino → **HTIC → TC urgente, no hago PL antes de TC** · _ECOE: papiledema = hipertensión intracraneal; contraindica PL hasta descartar masa_
- Anisocoria con pupila midriática arreactiva · Ptosis ipsilateral · Ojo desviado abajo y afuera → **Parálisis del III par por herniación uncal** · _ECOE: midriasis fija unilateral = compresión del III → emergencia neuroquirúrgica_
- Desviación de comisura con frente conservada · Pliegues frontales simétricos · Cierra el ojo del lado parético → **Parálisis facial central (EVC)** · _ECOE: central respeta la frente; periférica (Bell) la afecta_
- Boca desviada + frente lisa del mismo lado · No cierra el ojo (signo de Bell) · Borramiento del surco nasogeniano → **Parálisis facial periférica (VII)** · _ECOE: afecta toda la hemicara: descarto Bell vs otitis vs zoster_
- Hemianopsia homonima en campimetría · Déficit motor asociado · Inicio súbito → **EVC de territorio posterior / cerebral media** · _ECOE: el defecto campimétrico localiza la lesión retroquiasmática_

**FUERZA, TONO Y REFLEJOS**
- Hemiparesia con balance 3/5 · Hiperreflexia del hemicuerpo · Babinski extensor presente → **Lesión de 1.ª neurona (central) → EVC/masa** · _ECOE: Babinski + hiperreflexia + espasticidad = síndrome piramidal_
- Debilidad distal con arreflexia · Hipotonía flaccida · Babinski ausente (flexor) → **Lesión de 2.ª neurona / periférica → Guillain-Barré** · _ECOE: patrón periférico: arreflexia + flaccidez, sin Babinski_
- Debilidad ascendente simétrica · Arreflexia generalizada progresiva · Disociación albúmino-citológica en LCR → **Síndrome de Guillain-Barré** · _ECOE: vigilo capacidad vital: riesgo de fallo respiratorio_
- Para/tetraparesia espstica · Hiperreflexia por debajo del nivel · Babinski bilateral → **Compresión medular → RM urgente + corticoide** · _ECOE: el nivel motor y sensitivo localiza el segmento medular_
- Temblor de reposo · Rigidez en rueda dentada · Bradicinesia → **Enfermedad de Parkinson** · _ECOE: triada parkinsoniana; reflejos normales, sin Babinski_

**SENSIBILIDAD Y NIVEL**
- Nivel sensitivo neto en tórax/abdomen · Anestesia por debajo del nivel · Retención urinaria + dolor dorsal → **Compresión medular → RM urgente** · _ECOE: el nivel sensitivo es el sello topográfico de la médula_
- Hipoestesia hemicorporal con déficit motor mismo lado · Inicio súbito · Acompaña a hemiparesia → **EVC (territorio talámico / cerebral media)** · _ECOE: hemihipoestesia + hemiparesia = lesión central contralateral_
- Parestesias en guante y calcetín · Simétricas y distales · Curso crónico → **Polineuropatía (diabética) → no es agudo** · _ECOE: patrón longitud-dependiente: distinto del nivel medular_
- Pérdida disociada (termóalgica) suspendida · Tacto conservado · Curso crónico cervical → **Siringomielia / lesión centromedular** · _ECOE: disociación termoalgésica orienta al centro medular_

**SIGNOS MENINGEOS Y CEREBELO/MARCHA**
- Rigidez de nuca a la flexión pasiva · Signo de Kernig positivo · Signo de Brudzinski positivo → **Meningitis → PL + antibiótico precoz; no demoro por TC si no hay focalidad** · _ECOE: Kernig (extender rodilla con cadera flexionada duele) y Brudzinski (flexión cuello → flexión caderas)_
- Cefalea en trueno + rigidez nucal · Fotofobia · Sin fiebre → **HSA → TC sin contraste; si normal, PL buscando xantocromía** · _ECOE: irritación meníngea por sangre, no por infección_
- Marcha atáxica con aumento de la base · Dismetría dedo-nariz · Romberg que no empeora al cerrar ojos → **Síndrome cerebeloso → EVC de fosa posterior** · _ECOE: ataxia con ojos abiertos = cerebelosa; Romberg + = cordonal posterior_
- Marcha festinante con pasos cortos · Giro en bloque · Reflejos posturales abolidos → **Enfermedad de Parkinson** · _ECOE: marcha festinante e hipocinesia distinguen del cerebelo_
- Marcha apráxica imán al suelo · Incontinencia urinaria · Deterioro cognitivo → **Hidrocefalia normotensiva (triada de Hakim)** · _ECOE: triada de Hakim → valoro derivación ventrículo-peritoneal_


## Ojo

### Eje Clínico

**Ojo rojo**
- Secreción + sensación de arenilla + visión conservada + sin dolor profundo → **Conjuntivitis**
- Hiperemia ciliar (periqueratica) + dolor + fotofobia + miosis + Tyndall en cámara anterior → **Uveítis anterior**
- Dolor intenso + halos de colores + midriasis media fija + ojo duro pétreo + náuseas → **Glaucoma agudo de ángulo cerrado**
- Dolor profundo que despierta por la noche + enrojecimiento violaceo + asociado a enfermedad reumática → **Escleritis**
- Enrojecimiento sectorial superficial + no doloroso + no afecta visión → **Epiescleritis**
- Inyección + dolor + defecto que tiñe con fluoresceína + antecedente de cuerpo extraño → **Queratitis / úlcera corneal**

**Pérdida visual súbita indolora**
- Brusca + altitudinal o total + defecto pupilar aferente + fondo con retina pálida y mácula rojo cereza → **Oclusión de arteria central de la retina**
- Brusca o en horas + fondo con hemorragias en llama difusas y venas tortuosas (retina en tormenta) → **Oclusión de vena central de la retina**
- Cortina ascendente + destellos (fotopsias) + miodesopsias (moscas) previas → **Desprendimiento de retina**
- Subaguda + dolor con los movimientos oculares + discromatopsia + defecto pupilar aferente → **Neuritis óptica**
- Brusca unilateral en mayor de 50 + cefalea temporal + claudicación mandibular + VSG alta → **Neuropatía óptica isquémica por arteritis de la temporal**
- Lluvia de moscas/telaraña roja + diabético + pérdida brusca → **Hemorragia vítrea**

**Pérdida visual gradual**
- Visión borrosa progresiva + deslumbramiento + halos + leucocoria + reflejo rojo disminuido → **Cataratas**
- Pérdida del campo periférico (visión en túnel) + excavación papilar + PIO elevada → **Glaucoma crónico de ángulo abierto**
- Escotoma central + metamorfopsias + drusas o membrana neovascular en mácula en mayor de 60 → **Degeneración macular asociada a la edad (DMAE)**
- Diabético de larga evolución + microaneurismas + exudados + neovasos en fondo de ojo → **Retinopatía diabética**
- Defectos campimétricos bitemporales + cefalea + alteración endocrina → **Compresión quiasmática (adenoma hipofisario)**

**Dolor ocular / proptosis**
- Dolor a la mirada + proptosis + oftalmoplejía + quemosis + fiebre → **Celulitis orbitaria**
- Edema y eritema palpebral + visión y motilidad normales + sin dolor a la mirada + sin proptosis → **Celulitis preseptal**
- Nódulo doloroso en el borde palpebral apuntando a pestañas → **Orzuelo**
- Nódulo indoloro firme alejado del borde, de evolución lenta → **Chalazion**
- Proptosis bilateral + retracción palpebral + diplopia + bocio/tirotoxicosis → **Orbitopatía tiroidea (Graves)**

### Integrador

**INSPECCION DEL OJO ROJO**
- Pupila en midriasis media fija + ojo duro pétreo a la palpación · Halos de colores + visión borrosa · Dolor intenso + náuseas y vómitos → **Glaucoma agudo de ángulo cerrado** · _ECOE: es clínico: bajar la PIO YA con acetazolamida IV + hipotensores tópicos (manitol si no cede); la pilocarpina va DESPUÉS de bajar la PIO, no de primera; derivación urgente_
- Hiperemia ciliar periqueratica + miosis · Tyndall (células en cámara anterior) + hipopion · Fotofobia + dolor profundo → **Uveítis anterior** · _ECOE: midriáticos + corticoide tópico y buscar enfermedad sistémica asociada_
- Hiperemia conjuntival difusa + secreción · Visión conservada + sin dolor profundo · Reflejo pupilar normal → **Conjuntivitis** · _ECOE: diferencio vírica/bacteriana/alérgica; alarma si dolor o baja visión → descarto causa grave_
- Defecto epitelial que tiñe verde con fluoresceína · Dolor + sensación de cuerpo extraño + blefaroespasmo · Antecedente de lente de contacto o trauma → **Queratitis / úlcera corneal** · _ECOE: no parchear ni dar anestésico tópico crónico; cubrir y derivar_

**PUPILAS Y REFLEJOS**
- Defecto pupilar aferente relativo (Marcus Gunn) al test de luz alternante · Visión muy disminuida en ese ojo · Dolor con los movimientos o fondo pálido → **Neuritis óptica / neuropatía óptica** · _ECOE: el DPAR localiza la lesión en nervio óptico/retina extensa, no en el cristalino_
- Midriasis arreactiva unilateral + ptosis + ojo desviado abajo y afuera · Cefalea brusca intensa · Posible aneurisma de comunicante posterior → **Paresia del III par compresiva** · _ECOE: midriasis + dolor = urgencia neuroquirúrgica, descartar aneurisma_
- Anisocoria mayor en oscuridad + ptosis leve (mismo lado) + anhidrosis facial · Sin afectación de la motilidad · Posible disección carotídea o masa apical → **Síndrome de Horner** · _ECOE: la miosis del lado afecto se hace evidente en penumbra_
- Pupilas pequeñas que no reaccionan a la luz pero sí a la convergencia · Disociación luz-cerca bilateral · Antecedente neurológico/lúes → **Pupila de Argyll Robertson** · _ECOE: diferenciar de la pupila tónica de Adie (unilateral, reacción lenta)_

**AGUDEZA VISUAL Y CAMPOS**
- Agudeza que mejora al mirar por un agujero estenopeico · Borrosidad + halos sin ojo rojo · Sin defecto pupilar → **Defecto refractivo o catarata** · _ECOE: el estenopeico que mejora orienta a causa óptica, no neurológica_
- Campimetría con pérdida periférica progresiva (visión en túnel) · PIO elevada + excavación papilar aumentada · Asintomático hasta fases avanzadas → **Glaucoma crónico de ángulo abierto** · _ECOE: el campo central se conserva hasta el final; cribado de PIO y papila_
- Hemianopsia bitemporal en la confrontación · Cefalea + síntomas endocrinos · Defecto que respeta el meridiano vertical → **Lesión del quiasma óptico** · _ECOE: el patrón campimétrico localiza la lesión en la vía visual_
- Escotoma central con rejilla de Amsler distorsionada (metamorfopsias) · Mayor de 60 + drusas en mácula · Dificultad para leer caras y letras → **Degeneración macular (DMAE)** · _ECOE: afecta visión central fina; deriva la forma húmeda urgente por anti-VEGF_

**FONDO DE OJO**
- Retina pálida y edematosa con mácula rojo cereza + arterias filiformes · Pérdida visual brusca indolora total · Defecto pupilar aferente → **Oclusión de arteria central de la retina** · _ECOE: ventana terapéutica corta: masaje ocular y derivación inmediata, descartar arteritis_
- Hemorragias en llama difusas + venas tortuosas + edema de papila (retina en tormenta) · Pérdida visual subaguda · Factores de riesgo cardiovascular → **Oclusión de vena central de la retina** · _ECOE: patrón hemorrágico difuso por estasis venoso, no por isquemia arterial_
- Microaneurismas + exudados duros + hemorragias puntiformes + neovasos · Diabético de larga evolución · Visión aún conservada o borrosa → **Retinopatía diabética** · _ECOE: la fase proliferativa con neovasos exige panfotocoagulación_
- Papila con borde difuminado y elevada (edema de papila) bilateral · Cefalea + náuseas + visión transitoriamente borrosa · Sin defecto pupilar aferente (bilateral) → **Papiledema por hipertensión intracraneal** · _ECOE: edema bilateral + cefalea → descarto masa/HTIC, no es neuritis_
- Excavación papilar aumentada (relación copa/disco > 0.6) · PIO elevada · Campo periférico reducido → **Glaucoma crónico** · _ECOE: la excavación progresiva del nervio es el daño estructural del glaucoma_

**MOTILIDAD OCULAR**
- Dolor a la mirada + limitación de la motilidad + proptosis + quemosis · Fiebre + edema palpebral · Diplopia → **Celulitis orbitaria** · _ECOE: dolor a la mirada + proptosis = orbitaria (no preseptal): TC e ingreso con antibiótico IV_
- Motilidad y visión normales + edema y eritema palpebral sin proptosis · Sin dolor a los movimientos oculares · Afebril o febrícula → **Celulitis preseptal** · _ECOE: la motilidad y visión conservadas la distinguen de la orbitaria_
- Diplopia binocular + ojo desviado abajo y afuera + ptosis + midriasis · Cefalea · Empeora al cerrar el ojo sano → **Paresia del III par craneal** · _ECOE: comprobar pupila: si está afectada, sospecho compresión/aneurisma_
- Diplopia horizontal que aumenta al mirar al lado afecto (no abduce) · Antecedente de HTIC o trauma · Ojo en aducción en reposo → **Paresia del VI par craneal** · _ECOE: es el de recorrido más largo: falso signo localizador de HTIC_
- Proptosis bilateral + retracción palpebral + restricción a la supraversión · Bocio + temblor + pérdida de peso · Diplopia → **Orbitopatía tiroidea (Graves)** · _ECOE: la restricción muscular es mecánica por engrosamiento, no neurológica_


## Oido

### Eje Clínico

**Otalgia**
- Dolor al traccionar el pabellón + signo del trago positivo → **Otitis externa**
- Otalgia tras baño o limpieza con bastoncillos + prurito previo → **Otitis externa**
- Otalgia interna intensa tras IVAS + fiebre + hipoacusia → **Otitis media aguda**
- Otalgia retroauricular + desplazamiento del pabellón hacia delante → **Mastoiditis**
- Otalgia referida sin hallazgos en otoscopia (descartar patología dentaria/ATM/faríngea) → **Otalgia refleja**

**Otorrea**
- Otorrea purulenta tras perforación + cede la otalgia bruscamente → **Otitis media aguda perforada**
- Otorrea crónica fetida + perla blanca en ático (otoscopia) → **Colesteatoma**
- Otorrea acuosa-mucoide crónica sin dolor + perforación central seca → **Otitis media crónica simple**
- Otorrea escasa + conducto edematoso y eccematoso + dolor al trago → **Otitis externa**
- Hipoacusia de transmisión + tímpano deslustrado sin perforación (otoscopia) → **Otitis media con derrame**

**Hipoacusia y acufeno**
- Hipoacusia de transmisión + Rinne negativo + Weber lateraliza al oído enfermo → **Hipoacusia de transmisión**
- Hipoacusia neurosensorial + Rinne positivo + Weber lateraliza al oído sano → **Hipoacusia neurosensorial**
- Hipoacusia fluctuante + acufeno + sensación de plenitud ótica + vértigo recurrente → **Enfermedad de Ménière**
- Hipoacusia neurosensorial unilateral progresiva + acufeno + inestabilidad (descartar) → **Schwannoma vestibular**
- Hipoacusia neurosensorial súbita unilateral en horas-días → **Hipoacusia súbita**

**Vertigo y mareo**
- Vértigo breve (< 1 min) desencadenado por cambios de posición cefalíca + Dix-Hallpike positivo → **VPPB**
- Vértigo rotatorio de horas + acufeno + hipoacusia fluctuante → **Enfermedad de Ménière**
- Vértigo intenso continuo de días tras cuadro viral + sin hipoacusia ni acufeno → **Neuritis vestibular**
- Vértigo + hipoacusia súbita unilateral → **Laberintitis — pero la hipoacusia súbita es URGENCIA ORL: descartar causa central/retrococlear y dar corticoides precoces**
- Inestabilidad + cefalea + foco neurológico o nistagmo vertical/multidireccional → **Vértigo central**

### Integrador

**OTOSCOPIA**
- Conducto edematoso y eccematoso · Tímpano normal mal visible · Dolor a la introducción del espejo → **Otitis externa** · _ECOE: limpio y aplico gotas tópicas con antibiótico-corticoide_
- Tímpano abombado e hiperémico · Pérdida del triángulo luminoso · Nivel hidroaéreo o pus → **Otitis media aguda** · _ECOE: valoro analgesia ± antibiótico según criterios_
- Tímpano deslustrado retraído · Burbujas-nivel tras el tímpano · Sin abombamiento ni otalgia → **Otitis media con derrame** · _ECOE: timpanometría curva B; reviso a las semanas_
- Perla blanca-escamas en ático · Perforación marginal · Otorrea fetida crónica → **Colesteatoma** · _ECOE: derivó a ORL: TC y cirugía_
- Perforación central seca · Hipoacusia de transmisión · Sin colesteatoma → **Otitis media crónica simple** · _ECOE: evito agua y derivó para timpanoplastia_

**SIGNO DEL TRAGO Y PALPACION**
- Dolor al presionar el trago · Dolor al traccionar el pabellón · Conducto inflamado → **Otitis externa** · _ECOE: diagnóstico clínico; trato tópico_
- Tumefacción retroauricular · Pabellón desplazado hacia delante-afuera · Dolor y eritema sobre mastoides → **Mastoiditis** · _ECOE: urgencia: ingreso, antibiótico IV y TC_
- Trago indoloro · Sin dolor mastoideo · Otalgia interna profunda → **Otitis media aguda** · _ECOE: exploro tímpano en otoscopia_
- Adenopatía preauricular dolorosa · Conducto ocupado · Trago positivo → **Otitis externa difusa** · _ECOE: descarto extensión y trato_

**ACUMETRIA RINNE Y WEBER**
- Rinne NEGATIVO en oído afecto · Weber lateraliza al oído ENFERMO · Vía ósea > aérea → **Hipoacusia de transmisión** · _ECOE: busco causa: cerumen, derrame, perforación_
- Rinne POSITIVO en ambos · Weber lateraliza al oído SANO · Vía aérea > ósea → **Hipoacusia neurosensorial** · _ECOE: audiometría; descarto retrococlear_
- Hipoacusia neurosensorial fluctuante · Acufeno + plenitud ótica · Crisis de vertigo → **Enfermedad de Ménière** · _ECOE: audiometría seriada y dieta hiposódica_
- Hipoacusia neurosensorial súbita · Weber al oído sano · Sin causa transmisiva → **Hipoacusia súbita** · _ECOE: urgencia ORL: corticoides precoces_

**EXPLORACION VESTIBULAR**
- Dix-Hallpike POSITIVO · Nistagmo torsional con latencia y agotable · Vértigo breve posicional → **VPPB** · _ECOE: maniobra de Epley reposicionadora_
- Nistagmo horizonto-rotatorio unidireccional · Inhibido por fijación visual · Head-impulse POSITIVO al lado afecto → **Neuritis vestibular** · _ECOE: periférico: sedantes vestibulares cortos y rehabilitación_
- Nistagmo vertical o multidireccional · NO se inhibe con fijación · Head-impulse NEGATIVO + foco neurológico → **Vértigo central** · _ECOE: urgencia: neuroimagen (descarto ictus)_
- Vértigo rotatorio episodios horas · Acufeno e hipoacusia ipsilateral · Romberg inestable → **Enfermedad de Ménière** · _ECOE: trato la crisis y derivo a ORL_


## Endocrino

### Eje Clínico

**Poliuria / polidipsia**
- Poliuria con orina diluida (densidad baja) que no cede al restringir líquidos; Na+ normal-alto según el acceso al agua → **Diabetes insípida (central o nefrogénica)**
- Poliuria-polidipsia con glucemia > 200 mg/dL, pérdida de peso y cetonuria → **Diabetes mellitus tipo 1**
- Poliuria-polidipsia insidiosa en adulto obeso con acantosis nigricans → **Diabetes mellitus tipo 2**
- Polidipsia compulsiva + orina diluida + hiponatremia dilucional (psiquiátrico/potomania) → **Polidipsia primaria (el SIADH NO da poliuria: retiene agua y cursa con oliguria)**
- Poliuria con hipercalcemia, estreñimiento y litiasis renal recurrente → **Hiperparatiroidismo primario**
- Poliuria con HTA, hipopotasemia y debilidad muscular → **Hiperaldosteronismo primario (Conn)**

**Alteración de peso / intolerancia térmica**
- Pérdida de peso con apetito conservado, intolerancia al calor, temblor y TSH suprimida (opuesta a la clínica) → **Hipertiroidismo**
- Aumento de peso, intolerancia al frío, estreñimiento y TSH elevada (opuesta a la clínica) → **Hipotiroidismo**
- Fiebre, agitación, taquiarritmia e insuficiencia cardiaca en paciente tirotóxico → **Tormenta tiroidea**
- Hipotermia, bradicardia, estupor y edema sin fóvea tras suspender levotiroxina → **Coma mixedematoso**
- Aumento de peso central, cara de luna llena, estrías vínicas y debilidad proximal → **Síndrome de Cushing**
- Crecimiento acral (manos, pies, prognatismo) y cefalea con campos visuales alterados → **Acromegalia**

**HTA secundaria**
- HTA paroxística con cefalea pulsátil, sudoración y palpitaciones (tríada clásica) → **Feocromocitoma en crisis**
- HTA mantenida con hipopotasemia espontánea y alcalosis metabólica → **Hiperaldosteronismo primario (Conn)**
- HTA con obesidad central, equimosis fáciles e hiperglucemia → **Síndrome de Cushing**
- HTA con intolerancia al calor, taquicardia y bocio difuso → **Hipertiroidismo**
- HTA en joven con crecimiento acral y diabetes de novo → **Acromegalia**
- HTA con hipercalcemia y nefrolitiasis → **Hiperparatiroidismo primario**

**Hipo / hiperglucemia**
- Hiperglucemia > 250 con acidosis metabólica, cetonas y respiración de Kussmaul → **Cetoacidosis diabética (CAD)**
- Hiperglucemia extrema > 600 con osmolaridad alta, deshidratación y sin cetosis relevante → **Estado hiperosmolar hiperglucémico (EHH)**
- Hipoglucemia de ayuno con síntomas neuroglucópenos que ceden con glucosa (tríada de Whipple) → **Insulinoma**
- Hipoglucemia, hipotensión e hiperpigmentación con hipoNa+ e hiperK+ → **Insuficiencia suprarrenal primaria (Addison)**
- Hipoglucemia con astenia, pérdida de vello y amenorrea (panhipopituitarismo) → **Panhipopituitarismo**
- Hiperglucemia con obesidad central, estrías e HTA → **Síndrome de Cushing**

**Fatiga / hiper-hipocalcemia / hiperpigmentación / hipopituitarismo**
- Hipercalcemia con PTH elevada, estreñimiento, poliuria y litiasis (huesos, piedras, quejidos) → **Hiperparatiroidismo primario**
- Hipocalcemia con tetania, parestesias peribucales y signos de Chvostek-Trousseau → **Hipoparatiroidismo**
- Fractura vertebral por fragilidad con DMO T-score ≤ -2.5 → **Osteoporosis**
- Astenia, hipotensión e hiperpigmentación de pliegues y mucosas con hipoNa+ e hiperK+ → **Insuficiencia suprarrenal primaria (Addison)**
- Shock, dolor abdominal y fiebre con hipoglucemia tras estrés o suspensión de corticoides → **Crisis suprarrenal**
- Galactorrea, amenorrea y disminución de libido con campos visuales alterados → **Prolactinoma**
- Astenia, pálidez, pérdida de vello axilar-pubiano y fallo gonadal-tiroideo-suprarrenal → **Panhipopituitarismo**

### Integrador

**INSPECCION GENERAL / HABITUS**
- Cara de luna llena · Giba dorsal y estrías vínicas abdominales · Obesidad central con extremidades delgadas → **Síndrome de Cushing** · _ECOE: Busca equimosis y debilidad proximal al levantarse de la silla_
- Exoftalmos bilateral con retracción palpebral · Mirada fija y signo de lid-lag · Bocio difuso con temblor fino → **Hipertiroidismo (Graves)** · _ECOE: Describe la oftalmopatía: proptosis y signo de von Graefe_
- Facies abotargada y edema periorbitario · Macroglosia y piel seca-amarillenta · Edema sin fóvea generalizado (mixedema) → **Hipotiroidismo** · _ECOE: El mixedema del hipotiroidismo es generalizado y sin fóvea; el mixedema PREtibial localizado es de Graves, no de hipotiroidismo_
- Crecimiento de manos, pies y mandíbula · Prognatismo y rasgos toscos · Separación dental y macroglosia → **Acromegalia** · _ECOE: Compara fotos antiguas y mide el aumento de la talla del anillo-zapato_
- Hiperpigmentación de pliegues, cicatrices y mucosa oral · Adelgazamiento e hipotensión · Aspecto de astenia intensa → **Insuficiencia suprarrenal primaria (Addison)** · _ECOE: La hiperpigmentación por ACTH-MSH alta distingue Addison del hipopituitarismo_

**CUELLO / TIROIDES (palpación + soplo)**
- Bocio difuso, blando y simetrico · Frémito a la palpación · Soplo tiroideo a la auscultación → **Hipertiroidismo (Graves)** · _ECOE: El soplo refleja hipervascularización; ausculta el polo superior_
- Nódulo tiroideo único, firme y desplazable con la deglución · Sin adenopatías cervicales · Eutiroideo o autónomo → **Nódulo tiroideo** · _ECOE: Pide al paciente que trague mientras palpas por detrás_
- Tiroides aumentada, firme y bocelada (de superficie irregular) · Consistencia gómica · Hipotiroidismo asociado → **Tiroiditis de Hashimoto** · _ECOE: Correlaciona la consistencia firme con TSH elevada_
- Cuello sin bocio palpable, piel seca · Bradicardia y voz rónca · Relajación lenta de reflejos → **Hipotiroidismo** · _ECOE: Aunque no palpes bocio, la TSH elevada confirma el hipotiroidismo_
- Tiroides dolorosa, dura y adherida de crecimiento rápido · Adenopatías y disfonía · Posible compresión traqueal → **Carcinoma anaplásico de tiroides** · _ECOE: El crecimiento rápido y doloroso obliga a descartar malignidad_

**SIGNOS DE TIROTOXICOSIS**
- Temblor fino distal con brazos extendidos · Taquicardia sinusal o fibrilación auricular · Piel caliente y sudorosa → **Hipertiroidismo** · _ECOE: Coloca una hoja sobre las manos extendidas para evidenciar el temblor_
- Fiebre alta, agitación y delirio · Taquiarritmia con insuficiencia cardiaca · Diarrea y vómitos con deshidratación → **Tormenta tiroidea** · _ECOE: Aplica la escala de Burch-Wartofsky ante tirotoxicosis descompensada_
- Palpitaciones y pérdida de peso con apetito conservado · Intolerancia al calor e hiperdefecación · TSH suprimida con T4 libre alta → **Hipertiroidismo** · _ECOE: La TSH baja con T4 alta confirma tirotoxicosis primaria_
- Crisis de HTA, cefalea, sudoración y palpitaciones · Palidez paroxistica y ansiedad · Hiperglucemia transitoria → **Feocromocitoma en crisis** · _ECOE: Diferencia del hipertiroidismo por el carácter paroxistico y la palidez_

**PIEL / PIGMENTACION**
- Hiperpigmentación de codos, nudillos, líneas palmares y mucosa · Vitíligo asociado · HipoTA ortostática → **Insuficiencia suprarrenal primaria (Addison)** · _ECOE: El exceso de ACTH-MSH oscurece pliegues y cicatrices_
- Estrías anchas vínicas (purpúreas), equimosis y piel fina · Hirsutismo y acné · Mala cicatrización → **Síndrome de Cushing** · _ECOE: Estrías > 1 cm y purpúreas orientan a hipercortisolismo_
- Piel seca, áspera y fría, amarillenta (carotinemia) · Caída del tercio externo de la ceja · Pelo quebradizo → **Hipotiroidismo** · _ECOE: El tinte amarillo sin ictericia escleral sugiere hipotiroidismo_
- Mixedema pretibial (placas induradas en cara anterior de piernas) · Piel caliente y húmeda · Onicolisis (uñas de Plummer) → **Hipertiroidismo (Graves)** · _ECOE: El mixedema pretibial es paradojícamente signo de tirotoxicosis autoinmune_
- Acantosis nigricans en cuello y axilas · Obesidad y acrocordones · Heridas que no cicatrizan → **Diabetes mellitus tipo 2** · _ECOE: La acantosis traduce hiperinsulinismo y resistencia a la insulina_

**REFLEJOS / NEUROMUSCULAR**
- Relajación lenta del reflejo aquileo (fase de relajación prolongada) · Bradipsiquia y somnolencia · Bradicardia → **Hipotiroidismo** · _ECOE: La relajación lenta del aquileo es signo clásico de hipotiroidismo_
- Reflejos vivos e hiperreflexia con temblor · Taquicardia y nerviosismo · Debilidad muscular proximal → **Hipertiroidismo** · _ECOE: Reflejos rápidos contrastan con la relajación lenta del hipotiroidismo_
- Signo de Chvostek (contracción facial al percutir el facial) · Signo de Trousseau (espasmo carpal con manguito) · Parestesias peribucales y tetania → **Hipoparatiroidismo** · _ECOE: Ambos signos reflejan hipocalcemia e irritabilidad neuromuscular_
- Debilidad muscular proximal con dificultad para subir escaleras · Hiporreflexia con hipopotasemia · HTA asociada → **Hiperaldosteronismo primario (Conn)** · _ECOE: La debilidad por hipoK+ acompaña a HTA con renina baja_
- Hipotonía, somnolencia y arreflexia con deshidratación · Confusión por hipercalcemia · Estreñimiento → **Hiperparatiroidismo primario** · _ECOE: La hipercalcemia deprime la excitabilidad neuromuscular_


## Reproductor Fem

### Eje Clínico

**Sangrado uterino anormal**
- Sangrado intermenstrual + útero aumentado e irregular → **Miomas / leiomiomas**
- Menometrorragia en edad fértil sin causa estructural → **Sangrado uterino disfuncional**
- Sangrado posmenopausico (alarma) → descartar siempre → **Ca de endometrio**
- Sangrado poscoital en mujer con cuello visible anómalo → **Ca cervicouterino**
- Goteo escaso + cuello friáble e inflamado → **Cervicitis**
- Sangrado del primer trimestre con β-hCG presente → **Amenaza de aborto / aborto**

**Dolor pélvico**
- Dolor súbito intenso unilateral + náuseas + masa anexial → **Torsión ovárica**
- Amenorrea + dolor + inestabilidad hemodinámica + abdomen agudo → **Embarazo ectópico roto**
- Dolor a la movilización cervical + fiebre + flujo purulento → **EPI (enfermedad pélvica inflamatoria)**
- Dolor hipogástrico cíclico con masa anexial quística → **Quiste ovárico**
- Dismenorrea progresiva + dispareunia profunda → **Endometriosis**
- Distensión + ascitis + masa ovárica sólida en posmenopáusica → **Ca de ovario**

**Hemorragia obstétrica**
- Dolor abdominal súbito + hipertono uterino + sangrado oscuro escaso → **DPPNI (abruptio placentae)**
- Sangrado rojo brillante INDOLORO en 2º-3º trimestre → **Placenta previa**
- Amenorrea + dolor anexial + β-hCG > 1500 sin saco intrauterino → **Embarazo ectópico**
- Sangrado + dolor cólico + cuello dilatado con restos → **Aborto en curso / incompleto**
- Sangrado escaso + cuello cerrado + embrión vivo → **Amenaza de aborto**
- Hemorragia posparto + útero blando que no se contrae → **Atonia uterina**

**HTA y edema en el embarazo**
- TA ≥ 140/90 + proteinuria tras 20 semanas → **Preeclampsia**
- Preeclampsia + cefalea, escotomas, epigastralgia + plaquetopenia → **Preeclampsia grave / síndrome HELLP**
- HTA + proteinuria + convulsiones tonicoclónicas → **Eclampsia**
- HTA crónica previa al embarazo o antes de 20 sem → **HTA crónica**
- Edema fisiológico de miembros sin HTA ni proteinuria → **Edema gestacional benigno**

**Flujo vaginal**
- Flujo gris-blanquecino homogéneo + olor a pescado (KOH +) → **Vaginosis bacteriana**
- Flujo blanco grumoso (requesón) + prurito y eritema → **Candidiasis vulvovaginal**
- Flujo amarillo-verdoso espumoso + cuello en fresa → **Tricomoniasis (ITS)**
- Flujo mucopurulento cervical + dolor + pareja con uretritis → **Cervicitis por clamidia / gonococo**
- Úlcera genital indolora de bordes indurados → **Sífilis (ITS)**

**Masa mamaria**
- Masa dura, fija, irregular + retracción y piel de naranja → **Ca de mama**
- Nódulo bien delimitado, móvil, elástico en mujer joven → **Fibroadenoma**
- Mama roja, caliente, dolorosa + fiebre en lactancia → **Mastitis**
- Nódulos múltiples dolorosos que cambian con el ciclo → **Cambios fibroquísticos**
- Eczema unilateral del pezón que no cura → **Enfermedad de Paget de la mama**

### Integrador

**EXPLORACION MAMARIA**
- Masa pétrea fija a planos profundos · Retracción del pezón · Piel de naranja + adenopatía axilar dura → **Ca de mama** · _ECOE: infiltración y diseminación linfática_
- Nódulo liso, móvil, bien delimitado · Elástico, indoloro · Sin cambios cutáneos ni adenopatías → **Fibroadenoma** · _ECOE: tumor benigno de mujer joven_
- Cuadrante eritematoso, caliente y doloroso · Fiebre durante la lactancia · Posible fluctuación si absceso → **Mastitis puerperal** · _ECOE: infección del tejido mamario_
- Eczema del pezón-areóla que no cicatriza · Prurito y descamación unilateral · A veces masa subyacente → **Enfermedad de Paget** · _ECOE: carcinoma intraductal del pezón_

**ABDOMEN OBSTETRICO**
- Altura uterina acorde con amenorrea · Maniobras de Leopold para situación fetal · Foco cardiaco fetal audible → **Embarazo normoevolutivo** · _ECOE: valoración del crecimiento y estática fetal_
- Útero leñoso, hipertónico y doloroso · Sangrado oscuro escaso + sufrimiento fetal · Madre con HTA o trauma previo → **DPPNI** · _ECOE: desprendimiento placentario, urgencia obstétrica_
- Altura uterina mayor a la esperada · Movimientos fetales presentes · Sin dolor ni sangrado → **Polihidramnios / macrosomia** · _ECOE: discordancia altura-edad gestacional_
- Contracciones uterinas rítmicas palpables · Endurecimiento abdominal periódico · Borramiento cervical asociado → **Trabajo de parto** · _ECOE: dinámica uterina activa_

**ABDOMEN GINECOLOGICO**
- Masa hipogástrica firme e irregular · Crece desde la pelvis, móvil · Sangrado uterino abundante asociado → **Miomatosis uterina** · _ECOE: útero aumentado por leiomiomas_
- Defensa y dolor súbito en fosa ilíaca · Masa anexial palpable y dolorosa · Náuseas y vómitos → **Torsión ovárica** · _ECOE: isquemia anexial, urgencia quirúrgica_
- Distensión con masa pélvica sólida fija · Ascitis y matidez desplazable · Pérdida de peso en posmenopáusica → **Ca de ovario** · _ECOE: signos de tumor ovárico avanzado_
- Dolor a la palpación de fosas ilíacas bilateral · Fiebre + defensa + flujo purulento · Reacción peritoneal baja → **EPI complicada** · _ECOE: inflamación pélvica ascendente_

**ESPECULOSCOPIA**
- Cuello con lesión exofítica friáble que sangra · Sangrado poscoital al contacto · Secreción serohemática → **Ca cervicouterino** · _ECOE: tumor cervical visible al espéculo_
- Cuello eritematoso con secreción mucopurulenta · Sangra con facilidad al roce · Sin masa exofítica → **Cervicitis** · _ECOE: inflamación del cuello uterino_
- Flujo gris adherente que recubre paredes · Olor a pescado al añadir KOH · pH vaginal > 4.5 → **Vaginosis bacteriana** · _ECOE: disbiosis vaginal_
- Cuello con punteado hemorrágico (en fresa) · Flujo verdoso espumoso abundante · Eritema vaginal difuso → **Tricomoniasis** · _ECOE: ITS por protozoo flagelado_
- Saco gestacional o restos asomando por OCE · Cuello dilatado + sangrado activo · Dolor cólico hipogástrico → **Aborto en curso** · _ECOE: expulsión del producto de la gestación_

**TACTO BIMANUAL**
- Dolor intenso a la movilización cervical · Anexos engrosados y dolorosos · Fiebre y flujo purulento → **EPI** · _ECOE: signo del candelabro por irritación anexial_
- Masa anexial dolorosa + cuello cerrado · Dolor a la movilización + amenorrea · β-hCG positiva con útero vacío → **Embarazo ectópico** · _ECOE: gestación extrauterina, riesgo de rotura_
- Útero aumentado, irregular y nodular · Consistencia firme, indoloro · Móvil con el cuello → **Miomas uterinos** · _ECOE: útero polimiomatoso_
- Masa anexial quística lisa y móvil · Dolor leve o ausente · Sin signos sistémicos → **Quiste de ovario** · _ECOE: tumoración anexial benigna_

**SIGNOS VITALES Y TA EN EMBARAZO**
- TA ≥ 140/90 en gestante > 20 sem · Proteinuria en tira reactiva · Edemas y aumento brusco de peso → **Preeclampsia** · _ECOE: trastorno hipertensivo del embarazo_
- HTA grave + cefalea, fosfenos, epigastralgia · Hiperreflexia y clonus · Plaquetas bajas + transaminasas altas → **Preeclampsia grave / HELLP** · _ECOE: preeclampsia con criterios de gravedad_
- HTA + proteinuria + crisis convulsiva · Pérdida de conciencia posictal · Riesgo materno-fetal inminente → **Eclampsia** · _ECOE: convulsión por preeclampsia, urgencia vital_
- Taquicardia + hipotensión + palidez en gestante · Sangrado o dolor abdominal súbito · Relleno capilar lento → **Embarazo ectópico roto / DPPNI** · _ECOE: shock hemorrágico obstétrico_


## Reproductor Masc

### Eje Clínico

**Dolor escrotal agudo**
- Dolor súbito intenso + náuseas + testes ascendido y horizontal + Prehn negativo + sin reflejo cremastérico (joven) → **Torsión testicular**
- Dolor escrotal gradual + fiebre + Prehn positivo + reflejo cremastérico conservado + secreción/disuria → **Epididimitis aguda**
- Dolor intenso de inicio agudo + nódulo doloroso en polo superior (signo del punto azul) → **Torsión de hidatide de Morgagni**
- Dolor + eritema escrotal + crepitación + sepsis en diabético/inmunodeprimido → **Gangrena de Fournier**
- Dolor escrotal + edema + antecedente de paperas reciente → **Orquitis (parotidítica)**

**Masa o aumento escrotal**
- Nódulo testicular duro indoloro + no transilumina + varón joven 15-35 a → **Ca de testículo**
- Aumento escrotal indoloro + transilumina positivo + sin reflejo de masa sólida → **Hidrocele**
- Masa blanda en bolsa de gusanos + desaparece en decúbito + izquierdo + Valsalva la aumenta → **Varicocele**
- Varicocele derecho de aparición súbita en adulto que no desaparece en decúbito → **Varicocele 2° a tumor renal (alerta)**
- Masa quística indolora separada del testículo en epidídimo + transilumina → **Espermatocele/quiste de epidídimo**
- Tumefacción inguinoescrotal reductible que aumenta con Valsalva + ruidos hidroaéreos → **Hernia inguinoescrotal**

**Síntomas urinarios bajos (LUTS)**
- Varón >50 a + chorro débil + goteo + nicturia + tacto rectal próstata lisa elástica agrandada → **HBP**
- Varón >60 a + nódulo pétreo irregular al tacto rectal + APE elevado + dolor óseo → **Ca de próstata**
- Fiebre + dolor perineal + disuria + tacto rectal próstata caliente muy dolorosa (no masajear) → **Prostatitis aguda bacteriana**
- Dolor pelviano crónico + molestia miccional fluctuante ≥3 meses + tacto poco expresivo → **Prostatitis crónica/dolor pelviano crónico**
- Imposibilidad súbita de orinar + globo vesical doloroso palpable → **Retención aguda de orina**

**Secreción uretral y disfunción sexual**
- Secreción uretral purulenta abundante + disuria + inicio agudo tras contacto sexual → **Uretritis gonocócica**
- Secreción mucoide escasa + disuria + inicio subagudo (Chlamydia/Mycoplasma) → **Uretritis no gonocócica**
- Dificultad mantenida para lograr/mantener erección + factores vasculares (DM, HTA, tabaco) → **Disfunción eréctil**
- Erección dolorosa >4 h sin estimulación + isquemia (anemia falciforme, fármacos) → **Priapismo isquémico**
- Glande eritematoso + pruriginoso + secreción bajo prepucio + diabético/falta de higiene → **Balanitis (candidiásica)**
- Imposibilidad de retraer el prepucio + anillo constrictivo → **Fimosis**

### Integrador

**EXPLORACIÓN ESCROTAL Y TESTICULAR**
- Testes ascendido y horizontal · Reflejo cremastérico ausente · Prehn negativo (no alivia al elevar) → **Torsión testicular** · _ECOE: Urgencia: ventana ≤6 h → cirugía inmediata_
- Epidídimo engrosado y doloroso · Reflejo cremastérico conservado · Prehn positivo (alivia al elevar) → **Epididimitis aguda** · _ECOE: Doppler: flujo aumentado_
- Transiluminación positiva · Masa quistica indolora · No se palpa por separado el testículo → **Hidrocele** · _ECOE: Eco si dudas para descartar tumor_
- Transiluminación negativa · Nódulo duro pétreo indoloro · No reductible → **Ca de testículo** · _ECOE: Eco escrotal + marcadores AFP/β-hCG/LDH_
- Bolsa de gusanos al palpar · Aumenta con Valsalva de pie · Desaparece en decúbito (izquierdo) → **Varicocele** · _ECOE: Si derecho súbito → descartar masa renal_
- Signo del punto azul en polo superior · Nódulo selectivo doloroso · Reflejo cremastérico presente → **Torsión de hidatide** · _ECOE: Manejo conservador habitual_

**TACTO RECTAL DE PRÓSTATA**
- Próstata aumentada simétrica · Superficie lisa elástica · Surco medio conservado → **HBP** · _ECOE: APE leve-moderado; IPSS para síntomas_
- Nódulo pétreo irregular · Asimetría + surco borrado · Fija/adherida → **Ca de próstata** · _ECOE: APE elevado → biopsia + RM_
- Próstata caliente y muy dolorosa · Tumefacta · No masajear (riesgo bacteriemia) → **Prostatitis aguda** · _ECOE: Fiebre + sedimento; antibiótico_
- Tono esfinteriano normal · Ampolla rectal sin masas · Próstata poco expresiva → **Prostatitis crónica/DPC** · _ECOE: Síntomas ≥3 meses fluctuantes_

**INSPECCIÓN DEL PENE Y URETRA**
- Secreción purulenta abundante · Meato eritematoso · Disuria de inicio agudo → **Uretritis gonocócica** · _ECOE: Gram: diplococos intracelulares; ITS_
- Secreción mucoide escasa · Síntomas subagudos · Pareja con ITS → **Uretritis no gonocócica** · _ECOE: PCR Chlamydia/Mycoplasma; tratar pareja_
- Glande eritematoso pruriginoso · Exudado blanquecino subprepucial · Diabético/mala higiene → **Balanitis** · _ECOE: Glucemia + antifúngico tópico_
- Prepucio no retrátil · Anillo fibroso constrictor · Sin compromiso vascular → **Fimosis** · _ECOE: Corticoide tópico o circuncisión_
- Glande atrapado y edematoso · Prepucio retraído que no reduce · Dolor + congestión → **Parafimosis** · _ECOE: Urgencia: reducción manual inmediata_
- Pene en erección persistente · Rigidez dolorosa de cuerpos cavernosos · Glande blando >4 h → **Priapismo isquémico** · _ECOE: Urgencia: aspiración + fenilefrina_


## Cabeza

### Eje Clínico

**Cefalea primaria**
- Bilateral en banda + opresiva + no empeora con esfuerzo + sin náuseas → **Cefalea tensional**
- Pulsatil hemicraneal + fotofobia/sonofobia + náuseas + aura visual previa → **Migraña**
- Unilateral periorbitaria atroz + lágrimeo + rinorrea + Horner + agitación → **Cefalea en racimos (cluster)**
- Hemicraneal pulsatil + empeora con la actividad + el paciente busca cuarto oscuro → **Migraña sin aura**
- Diaria + uso de analgésicos >15 días/mes → **Cefalea por abuso de medicación**

**Cefalea secundaria (red flags)**
- En trueno + intensidad máxima en segundos + rigidez de nuca → **Hemorragia subaracnoidea**
- + fiebre + rigidez de nuca + fotofobia (síndrome meníngeo) → **Meningitis**
- + foco neurológico + papiledema + empeora al despertar/Valsalva → **Masa intracraneal / HTIC**
- Nueva + >50 años + arteria temporal indurada + claudicación mandibular → **Arteritis de células gigantes**
- + inmunodepresión o cáncer conocido + curso progresivo → **Lesión estructural (absceso/metástasis)**
- Postural: empeora de pie y mejora tumbado tras punción lumbar → **Cefalea por hipotensión de LCR**

**Dolor facial**
- Hemifacial + congestión + rinorrea purulenta >10 días + empeora al inclinarse → **Sinusitis**
- Paroxismos láncinantes en territorio V2-V3 + gatillo al tocar/masticar → **Neuralgia del trigémino**
- Retroocular + ptosis + midriasis + diplopia + dolor súbito intenso → **Aneurisma de comunicante posterior (III par) — la disección carotídea da Horner con MIOSIS, no midriasis**
- Preauricular + dolor al masticar + chasquido + bruxismo → **Disfunción temporomandibular**
- Maxilar + relación con pieza dental + percusión dolorosa → **Origen odontogénico**

**Parálisis facial**
- Hemicara COMPLETA incluida la frente + no cierra el ojo + signo de Bell → **Parálisis de Bell (periférica)**
- Respeta la frente (la arruga) + déficit de extremidades asociado → **Lesión central (ictus)**
- Periférica + vesículas en pabellón auricular + otalgia → **Síndrome de Ramsay-Hunt**
- Periférica bilateral + parestesias ascendentes + arreflexia → **Guillain-Barré**
- Periférica + masa parotídea de crecimiento lento → **Tumor de parótida**

**Tumefacción facial / preauricular**
- Preauricular bilateral + dolor al masticar + fiebre + contacto epidémico → **Parotiditis (paperas)**
- Submandibular + dolor cólico que aumenta antes de comer + se palpa cálculo → **Sialolitiasis**
- Preauricular + fiebre + eritema + pus por el conducto de Stenon → **Parotiditis bacteriana aguda**
- Indolora + crecimiento lento + consistencia firme unilateral → **Tumor de glándula salival**
- Difusa + crepitación + tras infección dental + fiebre alta → **Celulitis facial / angina de Ludwig**

### Integrador

**PALPACION DE LA ARTERIA TEMPORAL**
- Arteria temporal indurada, engrosada y no pulsatil · Hipersensibilidad al peinarse o apoyar la cabeza · >50 años + claudicación mandibular + VSG >50 → **Arteritis de células gigantes** · _ECOE: es urgencia: corticoide a dosis altas YA antes de la biopsia para salvar la visión_
- Amaurosis fugax o pérdida visual mono-ocular · Cefalea temporal nueva + síndrome constitucional · VSG y PCR muy elevadas → **Arteritis de células gigantes con afección ocular** · _ECOE: la NOIA es irreversible; no espero la biopsia para tratar_
- Arteria temporal pulsatil normal y no dolorosa · Cefalea pulsatil hemicraneal recurrente · Fotofobia + náuseas → **Migraña** · _ECOE: arteria normal aleja la arteritis; manejo de migraña_

**EXPLORACION DE PARES CRANEALES (V y VII)**
- Parálisis facial que afecta la FRENTE (no arruga ese lado) · No cierra el ojo + desviación de la comisura · Hiperacusia + alteración del gusto → **Parálisis de Bell (VII periférico)** · _ECOE: afecta la frente: la lesión es periférica; protejo el ojo y doy corticoide precoz_
- Parálisis facial que RESPETA la frente (sí arruga) · Hemiparesia o disartria asociadas · Inicio súbito → **Lesión central (ictus)** · _ECOE: respeta la frente por inervación bilateral del frontal; activo código ictus_
- Dolor paroxistico láncinante en mejilla/mandíbula · Zona gatillo al tocar o masticar · Exploración neurológica normal entre crisis → **Neuralgia del trigémino** · _ECOE: V sin déficit sensitivo fijo; carbamazepina, descarto causa estructural si hay foco_
- Vesículas en el conducto auditivo + parálisis periférica · Otalgia intensa + hipoacusia/vértigo · Erupción en territorio del VII → **Síndrome de Ramsay-Hunt** · _ECOE: parálisis periférica con vesículas: antiviral + corticoide, peor pronóstico que Bell_

**PALPACION DE SENOS PARANASALES**
- Dolor a la presión sobre senos frontales y maxilares · Rinorrea purulenta >10 días · Empeora al inclinar la cabeza hacia delante → **Sinusitis aguda** · _ECOE: dolor + rinorrea purulenta prolongada: sinusitis; antibiótico si no mejora o empeora_
- Dolor periorbitario + edema palpebral + proptosis · Fiebre alta + afección del estado general · Limitación de la motilidad ocular → **Celulitis orbitaria (complicación de sinusitis)** · _ECOE: proptosis y oftalmoplejía son alarma: TC urgente y antibiótico IV_
- Senos no dolorosos a la palpación · Cefalea opresiva bilateral en banda · Sin rinorrea ni fiebre → **Cefalea tensional** · _ECOE: senos indoloros sin rinorrea descartan sinusitis como causa_

**PALPACION DE GLANDULAS SALIVALES**
- Tumefacción preauricular bilateral dolorosa · Dolor al masticar + fiebre + malestar · Contacto epidémico, no vacunado → **Parotiditis (paperas)** · _ECOE: parótida bilateral dolorosa vírica; vigilo orquitis y meningitis como complicaciones_
- Cálculo palpable en suelo de boca + dolor cólico · El dolor aumenta justo antes de comer · Tumefacción submandibular intermitente → **Sialolitiasis** · _ECOE: cálico ductal que aumenta con la salivación; hidratación y sialogogos, ecografía_
- Salida de pus por el conducto de Stenon al ordenar · Parótida eritematosa, caliente y muy dolorosa · Anciano deshidratado, mala higiene oral → **Parotiditis bacteriana aguda** · _ECOE: pus al exprimir = bacteriana; antibiótico, hidratación y sialogogos_
- Masa firme indolora de crecimiento lento · Parálisis facial asociada (signo de malignidad) · Fija a planos profundos → **Tumor maligno de glándula salival** · _ECOE: masa con parálisis del VII orienta a malignidad; derivo para imagen y biopsia_

**FONDO DE OJO (papiledema)**
- Papila de bordes borrosos y elevada, sin pulso venoso · Cefalea que empeora al despertar y con Valsalva · Náuseas en escopetazo + diplopía por VI → **Papiledema por hipertensión intracraneal** · _ECOE: papiledema bilateral = HTIC; neuroimagen urgente antes de cualquier punción lumbar_
- Edema de papila + pérdida visual + arteria temporal indurada · >50 años + claudicación mandibular · VSG muy elevada → **Neuropatía óptica isquémica (arteritis)** · _ECOE: papila pálida edematosa en mayor de 50: corticoide inmediato para salvar el otro ojo_
- Papila normal, excavación fisiológica conservada · Cefalea pulsatil con aura visual reversible · Exploración neurológica normal → **Migraña con aura** · _ECOE: fondo de ojo normal apoya cefalea primaria frente a HTIC_


## Musculoesqueletico

### Eje Clínico

**Monoartritis aguda**
- Primer dedo del pie (podagra), inicio nocturno, varon, hiperuricemia → **Gota**
- Cristales de urato monosódico, birrefringencia negativa, tofos → **Gota**
- Rodilla caliente y tumefacta, fiebre, no puede apoyar, artrocentesis purulenta → **Artritis séptica**
- Cristales de pirofosfato cálcico, birrefringencia positiva, anciano, condrocalcinosis → **Pseudogota**
- Monoartritis aguda en cualquier articulación: artrocentesis SIEMPRE para descartar séptica → **Artritis séptica**
- Tumefacción migratoria, joven sexualmente activo, tenosinovitis y pústulas → **Artritis gonocócica**

**Poliartritis**
- Simetrica, pequeñas articulaciones de manos, rigidez matutina > 1 hora → **Artritis reumatoide**
- Anti-CCP positivo, factor reumatoide, erosiones, desviación cubital → **Artritis reumatoide**
- Mujer joven, rash malar, fotosensibilidad, artritis no erosiva, ANA positivo → **Lupus eritematoso sistémico**
- Dactilitis (dedo en salchicha), psoriasis cutánea, afectación de interfalángicas distales → **Artritis psoriásica**
- Oligoartritis asimétrica de miembros inferiores, entesitis, uretritis previa → **Artritis reactiva**

**Debilidad de cinturas (> 50 años)**
- Dolor y rigidez de cintura escapular y pelvica, VSG y PCR muy elevadas → **Polimialgia reumática**
- Asociación con cefalea, claudicación mandibular y amaurosis → **Arteritis de células gigantes**
- Debilidad proximal simétrica, elevación de CK, dificultad para peinarse o subir escaleras → **Polimiositis**
- Debilidad proximal con rash heliotropo y pápulas de Gottron → **Dermatomiositis**

**Dolor óseo**
- Dolor tras traumatismo, deformidad, impotencia funcional, crepitación → **Fractura**
- Dolor óseo localizado con fiebre, eritema y calor sobre el hueso → **Osteomielitis**
- Fractura por fragilidad (vertebral, cadera, muñeca), T-score ≤ -2.5 → **Osteoporosis**
- Dolor óseo nocturno, antecedente de neoplasia (mama, próstata, pulmón), hipercalcemia → **Metástasis óseas**
- Dolor óseo, anemia, insuficiencia renal, hipercalcemia, lesiones líticas en sacabocados → **Mieloma múltiple**

**Lumbalgia y dolor radicular**
- Dolor lumbar que mejora con reposo, empeora con esfuerzo, sin red flags → **Lumbalgia mecánica**
- Dolor irradiado por la pierna (citiática), Lasegue positivo, parésia de un dermatoma → **Hernia discal**
- Lumbalgia con fiebre, pérdida de peso, dolor nocturno o antecedente de cáncer: red flags → **Lumbalgia secundaria (red flag)**
- Anestesia en silla de montar, retención urinaria, pérdida de tono del esfínter anal → **Síndrome de cola de caballo**
- Dolor inflamatorio, rigidez matutina, varón joven, HLA-B27, sacroileítis → **Espondilitis anquilosante**

### Integrador

**INSPECCION ARTICULAR**
- Tumefacción · Eritema · Primer dedo del pie → **Gota** · _ECOE: podagra clásica_
- Desviación cubital · Dedos en cuello de cisne · Simétrica en manos → **Artritis reumatoide** · _ECOE: deformidad crónica_
- Dedo en salchicha · Placas psoriásicas · Pitting ungueal → **Artritis psoriásica** · _ECOE: dactilitis_
- Tofos en pabellón auricular · Nódulos blanquecinos · Hiperuricemia → **Gota** · _ECOE: depósito de urato_
- Rash malar en alas de mariposa · Fotosensibilidad · Artritis no erosiva → **Lupus eritematoso sistémico** · _ECOE: signo cutáneo guía_

**PALPACION**
- Calor local · Derrame articular · Fiebre, no apoya → **Artritis séptica** · _ECOE: aspirar SIEMPRE_
- Calor y derrame en rodilla · Anciano · Condrocalcinosis radiológica → **Pseudogota** · _ECOE: pirofosfato cálcico_
- Dolor a la palpación ósea · Fiebre · Eritema sobre hueso → **Osteomielitis** · _ECOE: infección ósea_
- Crepitación · Deformidad · Traumatismo previo → **Fractura** · _ECOE: solución de continuidad_
- Nódulos reumáticos en codos · Simétrico · Anti-CCP positivo → **Artritis reumatoide** · _ECOE: afectación crónica_

**RANGO DE MOVIMIENTO**
- Limitación dolorosa de cinturas · VSG y PCR muy altas · > 50 años → **Polimialgia reumática** · _ECOE: rigidez proximal_
- Debilidad proximal simétrica · CK elevada · No puede subir escaleras → **Polimiositis** · _ECOE: miopatía inflamatoria_
- Rigidez matutina > 1 hora · Mejora con el movimiento · Simétrica → **Artritis reumatoide** · _ECOE: patrón inflamatorio_
- Pérdida de expansión torácica · Test de Schober positivo · HLA-B27 → **Espondilitis anquilosante** · _ECOE: columna rígida_

**EXPLORACION DE COLUMNA**
- Lasegue positivo · Parésia radicular de un dermatoma · Dolor irradiado por la pierna → **Hernia discal** · _ECOE: compresión de raíz_
- Anestesia en silla de montar · Pérdida de tono del esfínter anal · Retención urinaria → **Síndrome de cola de caballo** · _ECOE: urgencia quirúrgica_
- Dolor lumbar mecánico · Mejora con reposo · Sin red flags → **Lumbalgia mecánica** · _ECOE: exploración normal_
- Dolor nocturno con fiebre · Pérdida de peso · Antecedente de cáncer → **Lumbalgia secundaria (red flag)** · _ECOE: señal de alarma_
- Sacroileítis · Dolor inflamatorio que despierta · Varón joven → **Espondilitis anquilosante** · _ECOE: dolor de ritmo inflamatorio_

**PATRON DE AFECTACION**
- Monoartritis aguda · Artrocentesis con cristales o pus · Caliente y tumefacta → **Artritis séptica** · _ECOE: mono = aspirar_
- Poliartritis simétrica de pequeñas articulaciones · Anti-CCP · Rigidez matutina → **Artritis reumatoide** · _ECOE: patrón simétrico_
- Oligoartritis asimétrica de miembros inferiores · Entesitis · Uretritis previa → **Artritis reactiva** · _ECOE: patrón asimétrico_
- Dolor óseo difuso nocturno · Hipercalcemia · Neoplasia conocida → **Metástasis óseas** · _ECOE: afectación ósea_
- Fractura por fragilidad · T-score ≤ -2.5 · Sin traumatismo significativo → **Osteoporosis** · _ECOE: hueso frágil_


## Piel

### Eje Clínico

**Lesión eritematosa / infección de piel**
- Placa eritematosa mal delimitada + caliente + dolorosa + afecta dermis-tejido subcutáneo → **Celulitis**
- Placa eritematosa MUY bien delimitada + borde sobreelevado + brillante + cara/MMII → **Erisipela**
- Costras melicéricas color miel + niños + periorificial → **Impétigo**
- Dolor DESPROPORCIONADO a la lesión + crepitación + bullas hemorrágicas + toxicidad sistémica → **Fascitis necrotizante**
- Eritema + edema + fiebre + linfangitis ascendente (cordón rojo) → **Celulitis con linfangitis**
- Eritema perilesional + supuración + fluctuación localizada → **Absceso cutáneo**

**Exantema farmacológico grave**
- Máculas en diana atípicas + despegamiento <10% superficie + mucosas afectadas + fármaco reciente → **Síndrome de Stevens-Johnson (SSJ)**
- Despegamiento epidérmico >30% superficie + Nikolsky positivo + mucosas + fármaco → **Necrólisis epidérmica tóxica (NET)**
- Exantema morbiliforme extenso + fiebre + eosinofilia + afectación hepática + fármaco 2-8 semanas antes → **DRESS**
- Edema facial + adenopatías + eosinofilia tras anticonvulsivante/alopurinol → **DRESS**
- Eritema doloroso + ampollas fláccidas + Nikolsky positivo + mucosa oral erosionada → **SSJ / NET**

**Lesión pigmentada / tumoral**
- Lésión pigmentada Asimétrica + Bordes irregulares + Color heterogéneo + Diámetro >6 mm + Evolución (ABCDE) → **Melanoma**
- Pápula perlada + telangiectasias en superficie + borde enrollado + úlcera central + zona fotoexpuesta → **Carcinoma basocelular**
- Placa o nódulo hiperqueratosico + costra + crecimiento sobre queratosis actínica/cicatriz → **Carcinoma epidermoide**
- Lésión que sangra/ulcera y no cura + cambio reciente en nevus previo → **Tumor cutáneo (melanoma/CE) hasta descartar**
- Nódulo pigmentado + halo inflamatorio + crecimiento rápido + adenopatía regional → **Melanoma con diseminación**

**Úlcera crónica**
- Úlcera supramaleolar interna + bordes irregulares + exudativa + hiperpigmentación + pulsos presentes → **Úlcera venosa**
- Úlcera distal/acra + bordes netos en sacabocados + dolorosa + pulsos AUSENTES + piel fría pálida → **Úlcera arterial**
- Úlcera plantar en punto de presión + indolora + neuropatía + diabético → **Úlcera diabética (neuropática)**
- Úlcera sobre prominencia ósea (sacro/talón) + paciente encamado + inmovilidad → **Úlcera por presión**
- Úlcera + dolor desproporcionado + bordes necróticos + progresión rápida + crepitación → **Fascitis necrotizante sobre úlcera**

**Prurito / ampollas**
- Ampollas fláccidas + Nikolsky positivo + erosiones mucosas crónicas SIN fármaco desencadenante → **Pénfigo vulgar (crónico autoinmune; el agudo + fármaco sería SSJ/NET)**
- Ampollas TENSAS + base eritematosa + prurito intenso + Nikolsky NEGATIVO + anciano → **Penfigoide ampolloso**
- Exantema pruriginoso + fármaco reciente + posible progresión a despegamiento → **Reacción farmacológica grave (vigilar SSJ/NET)**
- Costras melicéricas pruriginosas + contagio en niños → **Impétigo**

### Integrador

**INSPECCION DE LA LESION**
- Placa eritematosa MUY bien delimitada + borde sobreelevado · Brillante + caliente · Localización en cara o pierna → **Erisipela** · _ECOE: borde nítido distingue erisipela de celulitis; antibiótico antiestreptocócico_
- Placa eritematosa MAL delimitada + límites difusos · Caliente + edematosa · Afecta tejido subcutáneo → **Celulitis** · _ECOE: borde impreciso y profundidad mayor que la erisipela_
- Costras color miel (melicéricas) · Distribución periorificial · Niño + contagio → **Impétigo** · _ECOE: costra mielicérica = infección superficial por S. aureus/estreptococo_
- Lésión pigmentada Asimétrica + Bordes irregulares · Color heterogéneo + Diámetro >6 mm · Evolución/cambio reciente (ABCDE) → **Melanoma** · _ECOE: regla ABCDE: derivo para biopsia escisional, nunca afeitado_
- Pápula perlada con telangiectasias + borde enrollado · Úlcera central que no cura · Zona fotoexpuesta (cara) → **Carcinoma basocelular** · _ECOE: perla + telangiectasias en zona solar; crecimiento lento y local_
- Placa hiperqueratosica/costrosa sobre piel fotodañada · Crece y ulcera · Sobre queratosis actínica o cicatriz → **Carcinoma epidermoide** · _ECOE: puede metastatizar; valoro adenopatías regionales_

**PALPACION**
- Dolor DESPROPORCIONADO a los hallazgos visibles · Crepitación (gas en tejidos) · Toxicidad sistémica + progresión rápida → **Fascitis necrotizante** · _ECOE: dolor desproporcionado + crepitación = urgencia quirúrgica, desbridamiento inmediato_
- Fluctuación localizada a la presión · Eritema y calor perilesional · Punto de máximo dolor → **Absceso cutáneo** · _ECOE: fluctuación = colección; requiere drenaje, no solo antibiótico_
- Induración y calor sin fluctuación · Borde mal definido · Cordón rojo ascendente (linfangitis) → **Celulitis con linfangitis** · _ECOE: trazo eritematoso ascendente sigue vía linfática_

**SIGNO DE NIKOLSKY / AMPOLLAS**
- Presión tangencial DESPEGA la epidermis (Nikolsky positivo) · Ampollas fláccidas + erosiones extensas · Fármaco reciente + mucosas afectadas → **SSJ / NET** · _ECOE: Nikolsky positivo + fármaco = emergencia, suspendo el fármaco y derivo a unidad de quemados_
- Ampollas TENSAS que NO se despegan (Nikolsky negativo) · Base eritematosa + prurito intenso · Paciente anciano → **Penfigoide ampolloso** · _ECOE: ampolla tensa y Nikolsky negativo lo separan del pénfigo y de la NET_
- Ampollas fláccidas + Nikolsky positivo · Erosiones mucosas dolorosas crónicas · Sin fármaco desencadenante claro → **Pénfigo vulgar** · _ECOE: autoinmune; Nikolsky positivo también, pero curso crónico no farmacológico_

**EXPLORACION DE MUCOSAS**
- Erosiones y costras hemorrágicas en labios · Conjuntivitis + erosiones genitales · Fármaco 1-3 semanas antes → **SSJ / NET** · _ECOE: afectación de ≥2 mucosas + fármaco orienta a SSJ/NET, no a un exantema banal_
- Mucosa oral erosionada dolorosa crónica · Sin desencadenante farmacológico · Ampollas fláccidas cutáneas → **Pénfigo vulgar** · _ECOE: las erosiones orales suelen ser el primer signo del pénfigo_
- Mucosas RESPETADAS · Exantema morbiliforme extenso + edema facial · Fiebre + eosinofilia + alteración hepática → **DRESS** · _ECOE: DRESS afecta órganos internos más que mucosas; pido hemograma y transaminasas_

**PULSOS / PERFUSION EN ULCERAS**
- Pulsos distáles AUSENTES + piel fría y pálida · Úlcera acra dolorosa en sacabocados · Mejora al colgar la pierna → **Úlcera arterial** · _ECOE: ausencia de pulsos + dolor = isquemia; pido índice tobillo-brazo, no comprimo_
- Pulsos PRESENTES + edema + hiperpigmentación · Úlcera supramaleolar interna exudativa · Mejora con elevación de la pierna → **Úlcera venosa** · _ECOE: pulsos conservados + estasis venosa = compresión (tras descartar arteriopatía)_
- Sensibilidad ABOLIDA (monofilamento) + pulsos variables · Úlcera plantar indolora en punto de presión · Diabético → **Úlcera diabética (neuropática)** · _ECOE: úlcera indolora en zona de carga = neuropatía; descargo presión y exploro perfusión_
- Eritema que no blanquea sobre prominencia ósea · Úlcera en sacro o talón · Paciente encamado/inmovilizado → **Úlcera por presión** · _ECOE: presión mantenida sobre hueso; cambios posturales y alívio de presión_


## Sangre

### Eje Clínico

**Síndrome anémico (clasificar por VCM)**
- Astenia + palidez + disnea de esfuerzo + VCM <80 (microcítica) + ferritina baja → **Anemia ferropénica → buscar pérdida digestiva/menstrual oculta**
- Microcítica + ferritina normal/alta + enfermedad crónica/inflamatoria de base → **Anemia de trastornos crónicos (hierro secuestrado, hepcidina alta)**
- VCM 80-100 (normocítica) + reticulocitos altos + ictericia + LDH alta + haptoglobina baja → **Anemia hemolítica → Coombs, frotis (esquistocitos vs esferocitos)**
- VCM >100 (macrocítica) + glositis + parestesias + alteración de la marcha → **Anemia por déficit de B12 (megaloblastica con afectación neurológica)**
- Macrocítica + alcoholismo o malabsorción, sin clínica neurológica → **Déficit de folato (megaloblastica sin neuropatía)**
- Pancitopenia + reticulocitos bajos + médula vacía en biopsia → **Anemia aplásica → descartar fármacos/tóxicos**
- Anemia microcítica + origen mediterráneo + RDW normal + electroforesis con HbA2 alta → **Talasemia (microcitosis desproporcionada al grado de anemia)**

**Serie roja alta / poliglobulia**
- Hto/Hb altos + prurito tras la ducha (acuagénico) + plaquetas y leucocitos altos + EPO baja → **Policitemia vera → JAK2; riesgo de trombosis, flebotomías**
- Hto alto aislado + EPO alta + EPOC/tabaquismo/altitud/SAOS → **Poliglobulia secundaria (hipoxia crónica, EPO elevada apropiada)**
- Hto alto + plaquetas muy altas + esplenomegalia + leucoeritroblastosis en frotis → **Síndrome mieloproliferativo crónico (estudio JAK2/BCR-ABL)**
- Hto aparentemente alto por hemoconcentración (deshidratación/diuréticos) → **Poliglobulia relativa (masa eritrocitaria normal)**

**Serie blanca / médula (síndrome B y fiebre)**
- Fiebre + neutrófilos <500 en paciente con quimioterapia reciente → **Neutropenia febril → URGENCIA: antibiótico de amplio espectro <1 h**
- Astenia + sangrado + infecciones + blastos >20% en sangre/médula → **Leucemia aguda → ingreso; riesgo de CID (sobre todo M3 promielocítica)**
- Leucocitosis muy alta + basofilia + esplenomegalia masiva + cromosoma Filadelfia → **Leucemia mieloide crónica (BCR-ABL; imatinib)**
- Adenopatía indolora gómica + síndrome B (fiebre, sudoración, pérdida de peso) → **Linfoma → biopsia escisional; Reed-Sternberg si Hodgkin**
- Linfocitosis madura mantenida en anciano + adenopatías + sombras de Gumprecht → **Leucemia linfática crónica (frotis con linfocitos rotos)**
- Anciano + dolor óseo + anemia + hipercalcemia + insuficiencia renal + pico monoclonal → **Mieloma múltiple (CRAB; banda M en electroforesis)**

**Plaquetas y sangrado petequial**
- Petequias + equimosis + sangrado mucoso + plaquetas bajas aisladas, resto normal → **PTI (púrpura trombocitopénica inmune; trombopenia aislada de exclusión)**
- Péntada: trombopenia + anemia hemolítica microangiopática + fiebre + clínica neurológica + fallo renal → **PTT → URGENCIA: plasmaféresis; ADAMTS13 bajo, esquistocitos**
- Trombopenia + diarrea sanguinolenta (E. coli O157) + fallo renal en niño → **SHU (síndrome hemolítico urémico) → microangiopatía**
- Trombocitosis >450000 + esplenomegalia + síntomas vasomotores (eritromelalgia) → **Trombocitemia esencial (JAK2; riesgo de trombosis y hemorragia)**
- Trombopenia 5-10 días tras heparina + trombosis paradojica (no sangrado) → **Trombopenia inducida por heparina (TIH) → suspender heparina**
- Trombopenia leve + esplenomegalia + hepatopatía crónica → **Hiperesplenismo (secuestro plaquetario en cirrosis)**

**Coagulación (TP / TTPa)**
- Hemartros y hematomas profundos en varón + TTPa alargado + TP normal → **Hemofilia A/B (déficit factor VIII/IX; vía intrínseca)**
- Sangrado mucoso + epistaxis + TTPa algo alargado + tiempo de sangría alargado → **Enfermedad de von Willebrand (defecto plaquetario-coagulación más frecuente)**
- TP alargado que corrige con vitamina K + antibióticos/colestasis/malnutrición → **Déficit de vitamina K (factores II, VII, IX, X)**
- Sangrado difuso por múltiples sitios + TP y TTPa alargados + fibrinógeno bajo + D-dímero alto + esquistocitos → **CID → URGENCIA: tratar la causa (sepsis, obstétrica, neoplasia)**
- TP alargado aislado + hepatopatía crónica + síntesis disminuida → **Coagulopatía hepática (el hígado no sintetiza factores)**
- Sangrado + uso de cumarínico + INR muy alto → **Sobredosificación de anticoagulante oral → vitamina K ± complejo protrombínico**

**Trombosis (Wells, edema unilateral)**
- Edema unilateral de pierna + dolor en pantorrilla + cordon venoso palpable + Wells alto → **TVP → dimero D y eco-Doppler; anticoagular**
- Disnea súbita + dolor pleurítico + taquicardia + hipoxemia + TVP asociada → **TEP → URGENCIA: angio-TC; S1Q3T3 en ECG**
- Trombosis recurrentes/en sitios atipicos + abortos de repetición + TTPa alargado → **Síndrome antifosfolípido (anticoagulante lúpico; trombosis paradojica)**
- Trombosis en joven + antecedentes familiares + sin desencadenante claro → **Trombofilia hereditaria (factor V Leiden, protrombina, déficit antitrombina/proteina C-S)**
- Trombosis venosa + neoplasia conocida o síndrome constitucional → **Trombosis paraneoplásica (síndrome de Trousseau)**

### Integrador

**INSPECCIÓN DE PIEL Y MUCOSAS**
- Palidez de conjuntivas y lecho ungueal · Astenia y disnea de esfuerzo · Taquicardia compensadora → **Síndrome anémico → solicito hemograma con VCM y reticulocitos** · _ECOE: la palidez mucocon-juntival orienta a anemia; clasifico luego por VCM_
- Ictericia de escleras · Coluria + palidez · Esplenomegalia palpable → **Anemia hemolítica → LDH, bilirrubina indirecta, haptoglobina, Coombs** · _ECOE: ictericia + anemia + reticulocitosis = hemólisis_
- Petequias en miembros inferiores que no desaparecen a la vitropresión · Equimosis espontáneas · Sangrado de encías → **Trombopenia → cuento plaquetas y reviso frotis** · _ECOE: petequia = capilar; no blanquea a la presión (distingue de eritema)_
- Púrpura palpable en glúteos y piernas · Lesiones sobreelevadas · Artralgias y dolor abdominal → **Púrpura vasculítica (Schönlein-Henoch) → plaquetas normales** · _ECOE: púrpura palpable orienta a vasculitis, no a trombopenia_
- Prurito intenso tras el baño caliente · Pletórico/rubicundo · Eritromelalgia en dedos → **Policitemia vera → pido Hto, EPO y JAK2** · _ECOE: prurito acuagénico + pletóra = sospecha de poliglobulia primaria_

**PALPACIÓN DE ADENOPATÍAS**
- Adenopatía cervical dura, fija y mayor de 2 cm · Indolora · Crecimiento progresivo → **Adenopatía maligna → biopsia escisional** · _ECOE: dura, fija, indolora y >2 cm = banderas de malignidad_
- Adenopatías móviles, blandas y dolorosas · Asociadas a faringitis/infección local · Resolución en semanas → **Adenopatía reactiva (infecciosa benigna)** · _ECOE: blanda, dolorosa y móvil orienta a causa inflamatoria_
- Adenopatías generalizadas en varios territorios · Fiebre + sudoración nocturna + pérdida de peso · Esplenomegalia asociada → **Linfoma con síndrome B → biopsia y TC de estadiaje** · _ECOE: síntomas B definen estadio y pronóstico en linfomas_
- Adenopatía que duele tras ingesta de alcohol · Mediastínica en radiografía · Paciente joven → **Linfoma de Hodgkin (dolor adenopático con alcohol)** · _ECOE: explorar todas las cadenas: cervical, axilar, inguinal, epitroclear_

**PALPACIÓN DE BAZO E HÍGADO**
- Bazo palpable bajo reborde costal en inspiración · Matidez esplénica aumentada en percusión · Borde con escotadura característica → **Esplenomegalia → oriento según tamaño y clínica** · _ECOE: el bazo crece hacia fosa ilíaca derecha y tiene escotadura_
- Esplenomegalia masiva que cruza la línea media · Leucocitosis con basofilia · Astenia → **Leucemia mieloide crónica → estudio BCR-ABL** · _ECOE: esplenomegalia gigante: pienso en LMC, mielofibrosis, leishmaniasis_
- Esplenomegalia + hepatomegalia firme + estigmas de hepatopatía · Trombopenia y leucopenia · Varices/circulación colateral → **Hiperesplenismo por hipertensión portal** · _ECOE: el bazo grande secuestra células → citopenias_
- Hepatomegalia + esplenomegalia + adenopatías · Síndrome B · Anemia asociada → **Síndrome linfoproliferativo → estudio de extensión** · _ECOE: organomegalias + adenopatías = sospecha de linfoma/leucemia_

**SIGNOS DE TROMBOSIS (EDEMA UNILATERAL)**
- Edema y aumento de perímetro en una sola pierna · Dolor a la palpación de pantorrilla · Eritema y calor local → **TVP → aplico escala de Wells y pido eco-Doppler** · _ECOE: edema unilateral + signos locales = sospecho TVP; mido perímetros_
- Empastamiento de pantorrilla · Cordón venoso palpable · Dilatación de venas superficiales colaterales → **TVP confirmada clínicamente → anticoagulación** · _ECOE: Wells suma edema, dolor, inmovilización, cáncer y antecedentes_
- Disnea súbita + dolor pleurítico · Taquicardia e hipoxemia · TVP en la pierna → **TEP → URGENCIA: angio-TC pulmonar** · _ECOE: toda TVP puede embolizar; busco síntomas respiratorios_
- Edema bilateral de ambas piernas con fóvea · Sin dolor localizado ni eritema · Asociado a cardiopatía/hepatopatía → **Edema sistémico (no trombo) → descarta TVP** · _ECOE: el edema bilateral simetrico apunta a causa sistémica, no tromboítica_

**EXPLORACIÓN DE SANGRADO MUCOSO**
- Sangrado de encías al cepillado · Epistaxis de repetición · Equimosis ante mínimos traumatismos → **Sangrado de patrón plaquetario → pido recuento y función plaquetar** · _ECOE: mucoso + petequial = plaquetas; profundo + hematomas = coagulación_
- Hemartros y hematomas musculares profundos · Antecedente familiar varoníl · Sangrado tardío tras heridas → **Hemofilia → mido TTPa y factores VIII/IX** · _ECOE: vía intrínseca (TTPa) alargada con TP normal sugiere hemofilia_
- Sangrado difuso por puntos de venopunción y heridas · Paciente séptico o crítico · TP y TTPa alargados con plaquetas bajas → **CID → URGENCIA: D-dímero, fibrinógeno y tratar la causa** · _ECOE: sangrado por múltiples sitios + consumo = coagulación intravascular diseminada_
- Menorragia abundante y prolongada · Epistaxis frecuente desde la infancia · Antecedente familiar de sangrado → **Enfermedad de von Willebrand → estudio de factor vW** · _ECOE: sangrado mucoso crónico hereditario sin trombopenia orienta a vW_


## ORL / Cuello

### Eje Clínico

**Epistaxis**
- Sangrado por una fosa, ceden con presión bidigital, paciente joven → **Epistaxis anterior (plexo de Kiesselbach)**
- Sangrado posterior abundante, deglute sangre, hipertenso/anticoagulado → **Epistaxis posterior (arteria esfenopalatina)**
- Epistaxis unilateral recidivante + obstrucción nasal en varón adolescente → **Angiofibroma nasofaríngeo juvenil**
- Epistaxis unilateral con secreción fétida en niño pequeño → **Cuerpo extraño nasal**
- Epistaxis recurrente + telangiectasias en labios/lengua + antecedente familiar → **Telangiectasia hemorrágica hereditaria (Rendu-Osler)**
- Sangrado nasal profuso con inestabilidad → compromiso hemodinámico → **Epistaxis grave con shock hipovolémico**

**Obstrucción nasal y rinorrea**
- Estornudos en salvas + rinorrea acuosa + prurito + estacionalidad → **Rinitis alérgica**
- Obstrucción bilateral + anosmia + rinorrea, asociado a asma/intolerancia AINE → **Poliposis nasosinusal**
- Obstrucción unilateral + rinorrea fétida purulenta en niño → **Cuerpo extraño nasal**
- Rinorrea purulenta + dolor facial + fiebre > 10 días o empeoramiento bifásico → **Rinosinusitis bacteriana aguda**
- Congestión crónica por abuso de vasoconstrictores tópicos → **Rinitis medicamentosa**
- Rinorrea cristalina unilateral tras traumatismo craneal (glucosa positiva) → **Fistula de LCR (rinolicuorrea)**

**Odinofagia y disfagia alta**
- Fiebre + exudado amigdalar + adenopatías + ausencia de tos (Centor 3-4) → **Faringoamigdalitis estreptocócica (SBHGA)**
- Trismus + voz de papa caliente + úvula desplazada + abombamiento unilateral → **Absceso periamigdalino**
- Odinofagia intensa + babeo + estridor + posición en trípode, NO bajar lengua → **Epiglotitis aguda**
- Faringitis + adenopatías + esplenomegalia + exantema tras amoxicilina, joven → **Mononucleosis infecciosa (VEB)**
- Odinofagia leve + tos + disfonía + rinorrea (Centor 0-1) → **Faringitis viral**
- Odinofagia + rígidez cervical + abombamiento de pared faríngea posterior en niño → **Absceso retrofaríngeo**

**Disfonía y masa cervical**
- Disfonía aguda + tos + cuadro catarral, autolimitada → **Laringitis aguda**
- Disfonía > 3 semanas en fumador/bebedor mayor de 40 años → **Carcinoma de laringe**
- Adenopatía cervical dolorosa, móvil, de aparición reciente con infección → **Adenitis cervical reactiva**
- Adenopatía dura, fija, indolora > 3 semanas en adulto fumador → **Metástasis cervical / neoplasia**
- Masa cervical anterior que asciende con la deglución, línea media → **Quiste del conducto tirogloso**
- Masa lateral blanda en borde anterior del esternocleidomastoideo, congénita → **Quiste branquial**

### Integrador

**RINOSCOPIA ANTERIOR / INSPECCION NASAL**
- Punto sangrante en tabique anterior · Cede con presión bidigital 10-15 min · Sin sangrado posterior → **Epistaxis anterior (Kiesselbach)** · _ECOE: compresión del ala nasal contra el tabique_
- No se visualiza origen anterior · Sangre que cae por orofaringe · Hipertenso/anticoagulado → **Epistaxis posterior** · _ECOE: puede precisar taponamiento posterior o balón_
- Masas pediculadas grises traslucidas · Bilateral + anosmia · Mucosa pálida edematosa → **Poliposis nasosinusal** · _ECOE: buscar tríada de Samter (asma + AINE)_
- Cuerpo brillante unilateral + secreción fétida · Niño pequeño · Una sola fosa afectada → **Cuerpo extraño nasal** · _ECOE: unilateralidad fétida = cuerpo extraño hasta probar lo contrario_

**EXPLORACION OROFARINGEA**
- Exudado amigdalar bilateral + adenopatías · Ausencia de tos + fiebre · Centor 3-4 → **Faringoamigdalitis estreptocócica** · _ECOE: Centor ≥ 3 apoya etiología bacteriana_
- Abombamiento periamigdalino + úvula desviada · Trismus + voz de papa caliente · Unilateral → **Absceso periamigdalino** · _ECOE: voz de papa caliente = urgencia ORL, drenaje_
- Babeo + estridor + trípode · Rechazo a tragar saliva · Aspecto tóxico → **Epiglotitis aguda** · _ECOE: NO bajar la lengua ni explorar con depresor: riesgo de espasmo glótico_
- Exudado + esplenomegalia + exantema postamoxicilina · Adenopatías generalizadas · Paciente joven → **Mononucleosis infecciosa** · _ECOE: evitar amoxicilina por exantema; serología VEB_

**PALPACION CERVICAL**
- Adenopatía móvil dolorosa reciente · Infección ORL asociada · Consistencia elástica → **Adenitis cervical reactiva** · _ECOE: dolorosa + móvil + corta evolución = benigna probable_
- Adenopatía dura fija indolora > 3 semanas · Fumador mayor de 40 · Sin foco infeccioso → **Metástasis cervical** · _ECOE: dura + fija + indolora + crecimiento = estudio de neoplasia_
- Masa línea media que asciende al tragar y sacar lengua · Congénita · Indolora salvo infección → **Quiste del conducto tirogloso** · _ECOE: asciende con la protrusión lingual_
- Tiroides aumentada + nódulo desplazable con deglución · Sin adenopatías patológicas · Eutiroideo o no → **Masa/nódulo tiroideo** · _ECOE: el tiroides se desplaza con la deglución_

**VALORACION DE VIA AEREA (ESTRIDOR / TIRAJE)**
- Estridor inspiratorio + tiraje supraesternal · Disfagia + babeo · Aspecto tóxico → **Obstrucción de vía aérea superior** · _ECOE: estridor + tiraje = compromiso de vía aérea, asegurar ABC_
- Estridor + cianosis + agitación · Uso de músculos accesorios · Disminución del nivel de conciencia → **Obstrucción crítica de vía aérea** · _ECOE: cianosis + bradipnea = obstrucción inminente, vía aérea avanzada_
- Voz de papa caliente + trismus · Abombamiento orofaríngeo · Fiebre → **Absceso periamigdalino con riesgo de vía aérea** · _ECOE: vigilar permeabilidad; drenaje urgente_
- Disfonía progresiva + estridor en fumador · Masa laríngea sospechada · Pérdida de peso → **Carcinoma de laringe con compromiso de vía aérea** · _ECOE: disfonía > 3 semanas en fumador = derivar ORL_


## Boca

### Eje Clínico

**Dolor / tumefacción dental**
- Dolor pulsatil + tumefacción focal de la encía + diente con caries → **Absceso dentario**
- Dolor a la percusión del diente + fluctuación + fiebre → **Absceso dentario**
- Encías rojas que sangran al cepillado + sin pérdida de hueso → **Gingivitis**
- Sangrado gingival + retracción + movilidad dental (pérdida de soporte) → **Periodontitis**
- Tumefacción que progresa al piso de boca + dificultad para tragar → **Angina de Ludwig**

**Lesión en mucosa oral**
- Úlcera pequeña dolorosa con halo rojo + recurrente + se cura sola → **Aftas**
- Placas blancas que SÍ se desprenden al raspado + dejan base eritematosa → **Candidiasis oral**
- Placa blanca que NO se desprende al raspado + indolora → **Leucoplasia (sospecha de Ca)**
- Placa/úlcera que no cura en >2 semanas + fumador/alcohol + induración → **Ca oral**
- Placa eritematosa o mixta que no se desprende + bordes irregulares → **Eritroplasia (sospecha de Ca)**

**Tumefacción submandibular / piso de boca**
- Celulitis dura submandibular bilateral + lengua elevada + fiebre → **Angina de Ludwig**
- Foco dental molar inferior + tumefacción del piso de boca → **Angina de Ludwig**
- Estridor + voz apagada + babeo + no traga saliva → **Angina de Ludwig (vía aérea)**
- Tumefacción focal gingival sin afectar piso de boca → **Absceso dentario**

### Integrador

**INSPECCION DE MUCOSA ORAL**
- Placa blanca que se RASPA y desprende · Base eritematosa al retirarla · Inmunodeprimido / prótesis → **Candidiasis oral** · _ECOE: antifúngico tópico_
- Placa blanca que NO se desprende al raspar · Indolora + fumador · Persiste en el tiempo → **Leucoplasia (sospecha de Ca)** · _ECOE: biopsia: derivo_
- Úlcera que no cura en >2 semanas · Bordes indurados + sangra · Tabaco + alcohol → **Ca oral** · _ECOE: biopsia urgente: derivo_
- Úlcera pequeña con halo rojo · Muy dolorosa + recurrente · Cura sola en días → **Aftas** · _ECOE: sintomático_

**PALPACION DEL PISO DE BOCA / SUBMANDIBULAR**
- Induración leñosa submandibular bilateral · Lengua elevada + babeo · Fiebre + foco dental molar → **Angina de Ludwig** · _ECOE: vía aérea + ingreso urgente_
- Estridor / voz apagada al explorar · No traga la saliva · Trismo → **Angina de Ludwig (vía aérea)** · _ECOE: aseguro vía aérea YA_
- Tumefacción indurada del suelo de la boca · Adenopatía fija pétrea · Tabaco + alcohol → **Ca oral** · _ECOE: derivo + biopsia_

**EXPLORACION DENTAL / GINGIVAL**
- Diente con caries + dolor a la percusión · Tumefacción gingival fluctuante · Fiebre → **Absceso dentario** · _ECOE: drenaje + antibiótico_
- Encías rojas que sangran al sondaje · Sin movilidad ni pérdida ósea · Placa bacteriana → **Gingivitis** · _ECOE: higiene: reversible_
- Retracción gingival + bolsas profundas · Movilidad dental + pérdida de soporte · Sangrado → **Periodontitis** · _ECOE: derivo a periodoncia_


## Vascular Perif

### Eje Clínico

**Edema de miembro**
- Edema unilateral con empastamiento y dolor en pantorrilla → **Trombosis venosa profunda (TVP) → riesgo de TEP**
- Edema bilateral con fovea que mejora al elevar la pierna → **Insuficiencia venosa crónica**
- Edema unilateral crónico SIN fovea con piel engrosada → **Linfedema**
- Edema vespertino bimaleolar con varices visibles → **Insuficiencia venosa crónica**
- Edema unilateral indoloro de dorso del pie con signo de Stemmer positivo → **Linfedema**
- Edema con fovea profunda y duradera al presionar el tobillo → **Edema venoso o sistémico**

**Dolor de miembro**
- Dolor en pantorrilla al caminar que cede en reposo (claudicación) → **Enfermedad arterial periférica (EAP) → ITB < 0.9**
- Dolor de reposo nocturno que mejora colgando la pierna fuera de la cama → **EAP crítica (isquemia crónica avanzada)**
- Dolor súbito intenso con miembro frío y pálido → **Isquemia arterial aguda → las 6 P**
- Dolor y pesadez de piernas que empeora de pie y mejora elevando → **Insuficiencia venosa crónica**
- Dolor con empastamiento y aumento de temperatura en una pantorrilla → **Trombosis venosa profunda (TVP)**

**Úlcera de miembro**
- Úlcera en región maleolar interna, exudativa, bordes irregulares, poco dolorosa → **Úlcera venosa**
- Úlcera distal en dedos o talón, en sacabocados, muy dolorosa, fondo pálido → **Úlcera arterial (EAP)**
- Úlcera con dermatitis ocre y lipodermatoesclerosis perimaleolar → **Úlcera venosa**
- Úlcera en punta de dedo con pulsos ausentes y piel fría → **Úlcera arterial (EAP)**
- Úlcera en zona de presión con ausencia de pulsos pedios → **Úlcera arterial (EAP)**

**Aspecto agudo del miembro**
- Miembro frío, pálido, sin pulso y doloroso de inicio brusco → **Isquemia arterial aguda → urgencia**
- Pierna roja, caliente, edematosa y tensa de instauración rápida → **Trombosis venosa profunda (TVP)**
- Parálisis y paresia distal con cianosis moteada irreversible → **Isquemia arterial aguda avanzada**
- Pie pálido al elevar y rubicundo al colgar (Buerger positivo) → **EAP crítica**

### Integrador

**INSPECCION DEL MIEMBRO**
- Dermatitis ocre maleolar · Varices visibles · Úlcera maleolar interna → **Insuficiencia venosa crónica** · _ECOE: éstasis venoso_
- Palidez distal · Atrofia cutánea y pérdida de vello · Uñas distróficas → **Enfermedad arterial periférica (EAP)** · _ECOE: isquemia crónica_
- Miembro pálido y motéado · Cianosis distal súbita · Dolor intenso de inicio brusco → **Isquemia arterial aguda** · _ECOE: urgencia vascular_
- Edema sin fovea del dorso del pie · Piel engrosada en piel de naranja · Signo de Stemmer positivo → **Linfedema** · _ECOE: obstrucción linfática_

**PALPACION DE PULSOS PERIFERICOS**
- Ausencia de pulso pedio y tibial posterior · Soplo femoral · Claudicación al caminar → **Enfermedad arterial periférica (EAP)** · _ECOE: ITB < 0.9_
- Pulso ausente distal a la obstrucción · Miembro frío y pálido · Inicio brusco → **Isquemia arterial aguda** · _ECOE: ausencia de Pulso (6 P)_
- Pulsos periféricos conservados · Edema con fovea · Varices y telangiectasias → **Insuficiencia venosa crónica** · _ECOE: patología venosa_
- Pulsos presentes con edema unilateral sin fovea · Sin claudicación · Stemmer positivo → **Linfedema** · _ECOE: patología linfática_

**TEMPERATURA Y LLENADO CAPILAR**
- Miembro frío al tacto · Relleno capilar > 3 segundos · Palidez al elevar → **Enfermedad arterial periférica (EAP)** · _ECOE: hipoperfusión crónica_
- Frialdad brusca de todo el miembro · Relleno capilar muy enlentecido · Dolor y palidez → **Isquemia arterial aguda** · _ECOE: Poiquilotermia (6 P)_
- Aumento de temperatura unilateral en pantorrilla · Eritema y tensión cutánea · Edema unilateral → **Trombosis venosa profunda (TVP)** · _ECOE: inflamación venosa_
- Temperatura normal con piel templada · Relleno capilar conservado · Edema vespertino → **Insuficiencia venosa crónica** · _ECOE: retorno venoso lento_

**SIGNOS DE TVP Y PRUEBA DE FOVEA**
- Edema unilateral con empastamiento gemelar · Dolor con la dorsiflexión del pie · Aumento de perímetro > 3 cm respecto a la otra pierna → **Trombosis venosa profunda (TVP)** · _ECOE: Wells ≥ 2 probable_
- Eritema y calor unilateral · Cordón venoso palpable doloroso · Riesgo de embolia pulmonar → **Trombosis venosa profunda (TVP) con riesgo de TEP** · _ECOE: urgencia_
- Fovea presente y profunda al presionar el maléolo · Edema bilateral declive · Mejora al elevar la pierna → **Insuficiencia venosa crónica** · _ECOE: edema con fovea_
- Ausencia de fovea pese a edema marcado · Piel dura y engrosada · Signo de Stemmer positivo → **Linfedema** · _ECOE: edema SIN fovea_


## Inmune

### Eje Clínico

**Reacción alérgica aguda / anafilaxia**
- Urticaria + estridor + hipotensión tras alimento o picadura → **Anafilaxia (adrenalina IM YA)**
- Habones generalizados + prurito SIN compromiso de vía aérea ni hipotensión → **Urticaria aguda alérgica**
- Edema de labios y lengua + estridor + sibilancias minutos tras fármaco → **Anafilaxia con compromiso de vía aérea**
- Broncoespasmo + hipotensión + síntomas digestivos tras contraste yodado → **Anafilaxia (reacción bifásica posible)**
- Síncope + taquicardia + urticaria tras segunda dosis de antibiótico → **Anafilaxia (shock distributivo)**
- Prurito palmoplantar + sensación de muerte inminente como pródromo → **Pródromo de anafilaxia**

**Edema facial / labial súbito (angioedema)**
- Edema de labios y lengua SIN urticaria en paciente que toma enalapril → **Angioedema por IECA (mediado por bradicinina)**
- Episodios recurrentes de edema sin habones + dolor abdominal + antecedente familiar → **Angioedema hereditario por déficit de C1-INH**
- Edema de glotis SIN urticaria que NO responde a adrenalina ni antihistamínicos → **Angioedema bradicinínico (vía aérea en riesgo)**
- Edema facial + urticaria + prurito tras nuevo fármaco → **Angioedema histaminérgico (alérgico)**
- Edema laringeo recurrente con C4 bajo y C1-INH funcional disminuido → **Angioedema hereditario tipo II**
- Edema sin habones de inicio tardío (años) con paraproteinemia → **Angioedema adquirido por déficit de C1-INH**

**Exantema farmacológico grave con afectación sistémica**
- Exantema + fiebre + edema facial + eosinofilia 2-6 semanas tras fármaco → **DRESS (afectación de órgano: hígado/riñón)**
- Lesiones en diana + despegamiento <10% superficie + afectación de mucosas → **Síndrome de Stevens-Johnson (SSJ)**
- Despegamiento >30% de la piel + Nikolsky positivo + mucosas erosionadas → **Necrólisis epidérmica tóxica (NET)**
- Exantema + eosinofilia + transaminasas elevadas + linfadenopatía → **DRESS (síndrome de hipersensibilidad)**
- Pustulas estériles sobre base eritematosa + fiebre + neutrofilia rápida tras fármaco → **PEGA (pustulosis exantemática aguda generalizada)**
- Exantema maculopapular leve sin mucosas ni eosinofilia tras antibiótico → **Exantema medicamentoso simple (benigno)**

### Integrador

**VALORACIÓN DE VÍA AÉREA / RESPIRATORIA**
- Estridor inspiratorio · Edema de labios y lengua · Voz apagada o disfonía → **Anafilaxia / angioedema con compromiso de vía aérea** · _ECOE: adrenalina IM 0.5 mg en vasto externo YA + preparar vía aérea_
- Edema de glotis SIN urticaria · Toma de IECA · No responde a adrenalina → **Angioedema bradicinínico (IECA / C1-INH)** · _ECOE: suspender IECA + icatibant o C1-INH; asegurar vía aérea_
- Sibilancias + broncoespasmo · Tiraje supraesternal · Saturación < 92% → **Anafilaxia (afectación respiratoria)** · _ECOE: adrenalina IM + oxígeno + broncodilatador_
- Edema lingual progresivo · Imposibilidad de tragar saliva · Disnea creciente → **Angioedema de vía aérea (riesgo de obstrucción)** · _ECOE: intubación precoz antes de que progrese el edema_

**INSPECCIÓN DE PIEL Y MUCOSAS**
- Habones + prurito generalizado · Mejora con antihistamínico · Sin afectación de mucosas → **Urticaria aguda alérgica** · _ECOE: antihistamínico; vigilar progresión a anafilaxia_
- Edema facial SIN habones · Recurrente + antecedente familiar · Dolor abdominal asociado → **Angioedema hereditario por déficit de C1-INH** · _ECOE: C1-INH o icatibant; NO responde a adrenalina_
- Lesiones en diana + mucosas erosionadas · Signo de Nikolsky positivo · Despegamiento cutáneo → **SSJ / NET** · _ECOE: suspender fármaco + unidad de quemados + soporte_
- Exantema + edema facial · Eosinofilia en hemograma · Linfadenopatía → **DRESS** · _ECOE: suspender fármaco + corticoides + control de órgano_

**SIGNOS VITALES / HIPOTENSIÓN**
- Hipotensión + taquicardia · Urticaria + estridor · Inicio en minutos tras desencadenante → **Anafilaxia (shock distributivo)** · _ECOE: adrenalina IM YA + decúbito con piernas elevadas + fluidos_
- Hipotensión refractaria a fluidos · Antecedente de reacción previa · Prurito palmoplantar prodrómico → **Anafilaxia grave** · _ECOE: repetir adrenalina IM cada 5-10 min + cristaloides en bolo_
- Fiebre + taquicardia · Exantema extenso + eosinofilia · Transaminasas elevadas → **DRESS (afectación sistémica)** · _ECOE: suspender fármaco + corticoides sistémicos_
- Fiebre + hipotensión · Despegamiento >30% + Nikolsky · Pérdida de líquidos por piel → **NET (riesgo vital)** · _ECOE: manejo como gran quemado + reposición hidroelectrolítica_
