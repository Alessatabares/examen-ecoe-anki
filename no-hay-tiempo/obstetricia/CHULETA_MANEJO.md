# Chuleta manejo obstetricia — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero el **EJE / patrón madre** (la regla que decide la bifurcación), luego la
> **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag). Memorizas 7 ejes + el primer
> movimiento de cada cuadro.

---

## 7 EJES / PATRONES MADRE

1. **Hemorragia obstétrica: ESTABILIZO antes de diagnosticar.** 2 vías, cristaloide, cruzar sangre, vigilar a madre y feto; el dx fino viene después.
2. **Sangrado de 3er trimestre: NO TACTO hasta descartar placenta previa** (USG primero).
3. **Preeclampsia/eclampsia: Mg + antiHTA, pero lo definitivo es INTERRUMPIR el embarazo.** El sulfato de Mg previene/trata la convulsión; no "cura" la preeclampsia.
4. **La EDAD GESTACIONAL bifurca casi todo** (viabilidad, corticoide, tocólisis, vía de interrupción).
5. **Fármacos: hay prohibidos y seguros en embarazo** (evita IECA/ARA-II, warfarina, retinoides, etc.).
6. **Vigilancia fetal: la categoría del RCTG decide la conducta** (I tranquiliza, III → interrumpir).
7. **Control prenatal: tamizaje universal por trimestre** (+ vacunas, suplementos, datos de alarma).

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave | Red flag / trampa |
|---|---|---|
| Ectópico estable | **Metotrexato** (criterios) o cirugía conservadora | Vigilar β-hCG; descartar ruptura |
| Ectópico roto / inestable | **Reanimar + cirugía urgente (salpingectomía)** | No esperar imagen si inestable |
| Aborto (amenaza vs incompleto) | Amenaza → reposo/vigilar; incompleto → **AMEU/misoprostol** | Anti-D si Rh–; descartar ectópico |
| Mola hidatiforme | **Evacuación (AMEU)** + **seguimiento de β-hCG** | Riesgo de enfermedad trofoblástica; anticoncepción |
| Placenta previa con sangrado | **NO tactar** + estabilizar + hospital; cesárea según caso | USG localiza; corticoide si pretérmino |
| DPPNI | **Estabilizar + interrumpir** (vía según estado materno-fetal) | USG normal NO lo excluye; CID |
| Preeclampsia con severidad | **Sulfato de Mg + antiHTA + INTERRUMPIR** según EG | Mg previene convulsión, no cura |
| Eclampsia | **Mg (1ª línea para la convulsión) + ABC + antiHTA + interrumpir** | No benzodiacepina como 1ª línea; Mg |
| Síndrome HELLP | Estabilizar + **interrumpir** + soporte | Puede no tener HTA marcada |
| Sulfato de Mg | Dosis de carga + mantenimiento; **monitoreo** (reflejos, FR, diuresis) | Vigilar toxicidad |
| Intoxicación por Mg | **Gluconato de calcio** + suspender Mg + soporte | Hiporreflexia → depresión respiratoria |
| Antihipertensivos en embarazo | **Labetalol, hidralazina, nifedipino, alfametildopa** | **NO IECA/ARA-II** |
| Diabetes gestacional | Dieta + automonitoreo; **insulina** si no llega a meta | Vigilar macrosomía; tamizar posparto |
| Profilaxis EGB intraparto | **Penicilina IV intraparto** si EGB+ / factores | Reduce sepsis neonatal precoz |
| Amenaza de parto pretérmino (24-34) | **Corticoide** (madurez pulmonar) + **tocólisis** + **Mg neuroprotección** (<32) | El corticoide es lo que cambia el pronóstico |
| RPM pretérmino (<34) | **Corticoide + antibiótico (latencia) + vigilar** | Corioamnionitis → interrumpir |
| Corioamnionitis | **Antibiótico + INTERRUMPIR** (no prolongar) | Fiebre + útero doloroso + taquicardia fetal |
| Isoinmunización Rh — profilaxis | **Anti-D (inmunoglobulina)** a la Rh– no sensibilizada | A las 28 sem, posparto y tras eventos |

---

## MENOS COMUNES / DETALLES (segunda pasada)

- **Ectópico roto** = urgencia quirúrgica (no metotrexato).
- **Mola:** anticoncepción durante el seguimiento de β-hCG (un embarazo enmascararía la recaída).
- **Corticoide antenatal:** beneficio máximo 24-34 sem (valorar hasta 36+6 en casos); + neuroprotección con Mg <32 sem.
- **Eclampsia/HELLP** pueden aparecer **posparto**.
- **Vacunas:** Tdap e influenza SÍ; virus vivos NO.
- **Suplementos:** ácido fólico (preconcepcional/1T), hierro.
