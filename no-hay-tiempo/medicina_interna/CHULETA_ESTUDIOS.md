# Chuleta estudios / exploración medicina interna — herramienta → lectura (para verbalizar qué pides y para qué)

> **Regla:** primero el **DISCRIMINADOR** (una herramienta que separa un grupo por un hallazgo),
> luego el **PANEL** (la batería que pides por entidad, con el rol de cada estudio), y de remate
> los **SIGNOS y SCORES** que recitas de memoria. No pides "todo": pides con una pregunta en mente.

---

## DISCRIMINADORES (por herramienta) — qué separa cada hallazgo

**1. ECG (dolor torácico / palpitaciones)** → **ST elevado** = IAMCEST (reperfusión) · **infra-ST/T invertida** = SCASEST · **sin P + R-R irregular** = FA · **ST difuso cóncavo + PR↓** = pericarditis · **T picudas → QRS ancho** = hiperkalemia.
*Trampa: ECG normal NO descarta SCA → troponina seriada.*

**2. Troponina (alta sensibilidad)** → **elevada con curva (sube/baja)** = IAM tipo 1 · **elevada estable** = daño crónico (ERC, IC) · **negativa seriada + bajo riesgo** = descarta IAM.
*Trampa: TEP, sepsis, IC, miocarditis y ERC también la elevan.*

**3. BNP / NT-proBNP (disnea)** → **muy elevado** = IC probable · **bajo/normal** = IC poco probable (alto VPN).
*Trampa: obesidad lo baja falsamente; edad, FA y ERC lo suben.*

**4. Dímero D + Wells/PERC (TEP/TVP)** → **probabilidad baja + dímero negativo** = descarta (sin imagen) · **probabilidad alta** = anticoagular + angio-TAC directo.
*Trampa: solo sirve para DESCARTAR en baja probabilidad; el positivo no confirma.*

**5. Gasometría arterial** → **pH↓ + HCO₃↓ + brecha alta** = acidosis metabólica (CAD/láctica/uremia) · **pH↓ + PCO₂↑** = acidosis respiratoria (EPOC) · **PaO₂↓ con PCO₂↓** = insuf. tipo I (NAC/TEP/edema) · **PaO₂↓ + PCO₂↑** = tipo II (EPOC).
*Trampa: PCO₂ "normal" en crisis asmática grave anuncia paro.*

**6. EGO + sedimento** → **cilindros hemáticos + proteinuria** = glomerulonefritis (nefrítico) · **proteinuria masiva + lipiduria** = nefrótico · **cilindros granulosos pardos** = NTA · **leucocituria + nitritos** = ITU · **sedimento limpio + AKI** = pre/postrenal.
*Trampa: tira "sangre +" sin eritrocitos = mioglobina/hemoglobina.*

**7. Índices urinarios (FeNa) en AKI** → **FeNa <1%, Na urinario <20, orina concentrada** = prerrenal (responde a volumen) · **FeNa >2%, Na >40** = NTA.
*Trampa: el diurético invalida la FeNa (usa FeUrea).*

**8. Índices de la anemia (VCM, ferritina, reticulocitos)** → **VCM↓ + ferritina↓** = ferropénica · **VCM↓/normal + ferritina normal/alta** = enfermedad crónica · **VCM↑ + hipersegmentados** = megaloblástica · **reticulocitos↑** = hemólisis/sangrado · **reticulocitos↓** = falla de producción.
*Trampa: la ferritina es reactante de fase aguda (puede esconder ferropenia).*

## PANELES (por entidad) — la batería que pido y para qué

| Entidad | Pido (clave) | Criterio / lo que descarto |
|---|---|---|
| SCA / dolor torácico | **ECG seriado + troponina seriada**, lípidos, Rx tórax | ECG+troponina definen CEST vs SEST; descarta TEP/disección/neumotórax |
| Insuficiencia cardiaca | **BNP + ecocardiograma (FEVI)**, ECG, Rx, TSH, ferritina | FEVI separa FEr vs FEp; buscar el desencadenante |
| CAD / EHH | **Glucemia, gasometría, cetonas, electrolitos (K) seriados, brecha**, osmolaridad | CAD = cetosis+acidosis; EHH = hiperosmolar sin cetoacidosis |
| AKI | **Cr/urea seriadas, EGO+sedimento, FeNa, USG renal/vesical** | USG descarta obstrucción; FeNa/cilindros clasifican |
| Hiponatremia | **Osmolaridad sérica, osmolaridad y Na urinarios, volemia**, tiroidea/suprarrenal | Algoritmo Osm → volemia → Na urinario; SIADH = euvolémico |
| Crónico complejo / riesgo CV | **HbA1c, lípidos, función renal + albuminuria (RAC)**, TA, IMC, PFH, ácido úrico | Integra todo en riesgo global; prediabetes = ventana |
| Cirrosis descompensada | **PFH+bili+albúmina+INR (MELD/Child), paracentesis (PMN)**, EGD varices | Ascitis nueva/deterioro → paracentesis; PMN ≥250 = PBE |
| Patrón de transaminasas | **AST, ALT, FA, GGT, bilirrubina + albúmina e INR** | Hepatocelular (ALT/AST) vs colestásico (FA/GGT); función = albúmina/INR |

## SIGNOS Y SCORES (de memoria)

| Score / signo | Para qué |
|---|---|
| **CHA₂DS₂-VASc** | Riesgo embólico en FA → decide anticoagulación |
| **CURB-65** | Gravedad de la neumonía → sitio de manejo |
| **Wells (TEP/TVP)** | Probabilidad pretest → dímero D vs imagen |
| **qSOFA** | Riesgo de sepsis (TAS≤100, FR≥22, alterado) |
| **GRACE** | Riesgo en SCASEST → urgencia de coronariografía |
| **Killip** | IC en el contexto del IAM → mortalidad |
| **NYHA** | Clase funcional de la IC |
| **Child-Pugh / MELD** | Gravedad/pronóstico de la cirrosis |
| **Maddrey / Lille** | Hepatitis alcohólica grave (corticoide) / respuesta |
| **Criterios de Duke** | Diagnóstico de endocarditis |
| Frote pericárdico | Pericarditis (3 componentes) |
| Pulso parvus et tardus | Estenosis aórtica severa |
| Pulso paradójico / triada de Beck | Taponamiento cardiaco |
| Respiración de Kussmaul | Compensación de acidosis metabólica (CAD) |
| Asterixis (flapping) | Encefalopatía (hepática/urémica/hipercápnica) |
| Puñopercusión renal (Giordano) | Pielonefritis / patología renal |
| T picuda → QRS ancho | Hiperkalemia (riesgo arritmia) |
| Onda U / aplanamiento de T | Hipokalemia (más con digoxina) |
