# Chuleta manejo medicina interna — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero recitas el **EJE / patrón madre** (la regla que decide la bifurcación),
> luego enganchas la **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag).
> No memorizas dosis: memorizas 8 ejes + el primer movimiento de cada enfermedad.

---

## 8 EJES / PATRONES MADRE (lo que decide antes del diagnóstico fino)

1. **Primero ABC + monitor + glucemia + ECG**, no el diagnóstico fino. Inestable → resucito y trato en paralelo; estable → workup ordenado. *(Hipoglucemia, hiperK con ECG alterado y choque se tratan al lado de la cama.)*
2. **Toda descompensación crónica tiene un desencadenante: búscalo.** Infección · mala adherencia · transgresión · fármaco nuevo (AINE/esteroide) · SCA/arritmia · sangrado · electrolitos.
3. **Dolor torácico/disnea: descarta primero LO QUE MATA.** SCA · TEP · disección · neumotórax a tensión · taponamiento (ECG + troponina + SatO₂ en <10 min).
4. **Crisis metabólica/endocrina: LÍQUIDOS + corregir el déficit + tratar el gatillo.** En crisis suprarrenal y mixedema, **hidrocortisona ANTES** de la hormona tiroidea.
5. **En Na/K la VELOCIDAD de corrección importa tanto como el número.** Na: no subir >8-10 mEq/L/24 h · hiperK con ECG: **gluconato de calcio YA** · hipoK: corrige el **magnesio**.
6. **Insuficiencia respiratoria: la meta de O₂ depende de si RETIENE CO₂.** Sin riesgo → 94-98% · EPOC retenedor → **88-92%** · acidosis respiratoria → VMNI.
7. **El RIESGO CV GLOBAL decide la intensidad del tratamiento.** Integra HTA + diabetes/prediabetes + lípidos + tabaco + renal; alto riesgo → metas estrictas (LDL, TA <130/80, iSGLT2/GLP-1).
8. **Sepsis: bundle de 1 hora + control del FOCO.** Lactato · hemocultivos antes del antibiótico · antibiótico amplio · cristaloide 30 mL/kg · noradrenalina si TAM <65.

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave (verbalizo) | Red flag / trampa |
|---|---|---|
| Hipertensión arterial | IECA/ARA-II + CCB + tiazida; meta <130/80 | No combines IECA+ARA-II; vigila K/Cr |
| Crisis hipertensiva | **Emergencia** (daño órgano) → IV, ↓TAM 10-25% 1ª h · **urgencia** → VO gradual | No bajar rápido en urgencia (isquemia) |
| Diabetes tipo 2 | Metformina + **iSGLT2/GLP-1** si riesgo CV/renal (independiente de HbA1c) | Trata también TA, LDL, tabaco |
| IC con FEr | **4 pilares** (ARNI/IECA, BB, ARM, iSGLT2) + diurético | BB no se inicia en descompensación congestiva |
| IC con FEp | **iSGLT2** + diurético + tratar comorbilidades | No sobre-diuretizar |
| Fibrilación auricular | Inestable → **cardioversión**; estable → control FC/ritmo + **anticoagular (CHA₂DS₂-VASc)** | Control de FC NO sustituye anticoagulación |
| IAMCEST | **Reperfusión**: ICP <120 min o fibrinólisis + DAPT + anticoag + estatina | Tiempo es músculo; O₂ solo si SatO₂<90% |
| SCASEST | Antiagregación + anticoag + estatina + **estratificar (GRACE)** → coronariografía | **NO fibrinólisis** en el SEST |
| EPOC exacerbado | Broncodilatadores + **esteroide** + ATB si purulencia + O₂ 88-92% + VMNI si acidosis | Narcosis por exceso de O₂ |
| Crisis asmática | SABA repetido + O₂ + **esteroide precoz** + ipratropio + magnesio | PCO₂ "normal" en crisis grave = paro inminente |
| Neumonía (NAC) | **CURB-65** → sitio + antibiótico empírico + O₂ | Reevalúa a 48-72 h (empiema/resistencia) |
| TEP | Estable → **anticoagular**; inestable → **trombólisis** | Alta probabilidad → imagen directa (no dímero) |
| AKI (enfoque) | Clasificar pre/renal/postrenal + tratar causa + suspender nefrotóxicos | Diálisis urgente: **AEIOU** |
| Hiponatremia | Sintomática grave → **salino 3%**; resto → tratar causa, corrección lenta | Subir >8-10 mEq/L/24 h → mielinólisis |
| Cetoacidosis (CAD) | **Líquidos + insulina IV + potasio** + tratar gatillo | **No insulina si K<3.3**; glucosa al suero al bajar de ~200 |
| Cirrosis descompensada | Tratar la complicación (ascitis/PBE/varices/encefalopatía) + buscar precipitante | PBE → cefotaxima + **albúmina**; ascitis nueva → paracentesis |
| Sepsis / shock séptico | **Bundle 1 h** + control del foco | Antibiótico en la 1ª hora salva vidas |
| Gota (agudo) | AINE / colchicina / esteroide; **NO tocar alopurinol en el ataque** | Urato-bajante después, con profilaxis |

## MENOS COMUNES (segunda pasada) — primer movimiento + trampa

**Cardio:** Estenosis aórtica (sintomática → **reemplazo RVAo/TAVI**; evita vasodilatadores) · Insuficiencia mitral aguda (EAP → estabilizar + **cirugía urgente**) · Pericarditis (**AINE + colchicina**; vigila taponamiento → pericardiocentesis).

**Endocrino:** EHH (**líquidos agresivos** + insulina + K) · Tormenta tiroidea (**BB + tionamida → yodo 1 h después + hidrocortisona**) · Coma mixedematoso (**T4 IV + hidrocortisona ANTES**; no recalentar activo) · Crisis suprarrenal (**hidrocortisona 100 mg IV YA** + líquidos) · Graves (BB + metimazol; yodo radiactivo/cirugía; vigila **agranulocitosis**).

**Electrolitos:** Hiperkalemia (**calcio** estabiliza → insulina/glucosa + β2 → eliminar) · Hipokalemia (reponer K + **corregir Mg**).

**Renal:** Nefrótico (**IECA/ARA-II** antiproteinúrico + diurético + estatina + profilaxis trombosis) · Nefrítico (**control TA/volumen** + tratar causa; RPGN → inmunosupresión pronto) · NTA (**soporte** + suspender tóxicos; recupera en 1-3 sem) · Postrenal (**desobstruir**; vigila diuresis post-obstructiva).

**Hepático:** Encefalopatía (**lactulosa** ± rifaximina + corregir precipitante) · Hepatitis alcohólica (abstinencia + soporte; grave Maddrey ≥32 → **corticoide**; tiamina antes de glucosa) · MASLD/MASH (**pérdida de peso 7-10%** + comorbilidades).

**Hemato:** Anemia de enfermedad crónica (**tratar enfermedad de base**) · Anemia macrocítica (**reponer B12 antes/junto con folato**).

**Reumato:** AR (**FAME precoz: metotrexato**, treat-to-target) · LES (**hidroxicloroquina para todos** + inmunosupresor según órgano) · PMR (**corticoide dosis baja**, respuesta dramática; vigila arteritis de células gigantes → dosis alta).

**Infecto:** Endocarditis (**3 hemocultivos + eco + Duke**; ATB IV prolongado ± cirugía) · Pielonefritis/ITU complicada (ATB ± IV + **imagen si no mejora en 48-72 h**; obstrucción + ITU = pionefrosis → drenar).
