# Chuleta manejo urgencias — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero el **EJE / patrón madre** (la regla que decide la bifurcación), luego la
> **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag). En urgencias casi todo
> se decide por **ABCDE + estable/inestable + tiempo es órgano**.

---

## 8 EJES / PATRONES MADRE

1. **ABCDE: primero lo que MATA.** A (vía aérea/cervical) · B (O₂/ventilación) · C (vías, monitor, hemorragia) · D (déficit + **glucemia**) · E (exposición/Tª). Reevaluar desde A.
2. **Estable vs inestable:** si inestable, **resucito en paralelo** al diagnóstico (no lo saco del área de choque).
3. **Alteración del alerta:** glucemia + **cóctel** (tiamina/glucosa/naloxona) + descartar reversibles (AEIOU-TIPS).
4. **Dolor torácico/disnea: descarta las que matan** (SCA, TEP, disección, neumotórax a tensión, taponamiento).
5. **Choque: clasifica el tipo** (hipovolémico/distributivo/cardiogénico/**obstructivo**) → trata la causa + soporte. El obstructivo no mejora con suero: **quita la obstrucción**.
6. **Toxicología: trata al paciente, no al tóxico** (ABC + antídoto si existe + descontaminación + soporte). Pide **paracetamol siempre**.
7. **Sepsis: bundle 1 h + foco.**
8. **Tiempo es órgano:** adrenalina (anafilaxia), reperfusión (SCA), trombólisis (ACV), benzodiacepina (status), antibiótico (sepsis), aguja (neumotórax a tensión) — **ante alta sospecha, no esperes a confirmar todo**.

---

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave | Red flag / trampa |
|---|---|---|
| SCA | CEST→**reperfusión** (ICP/fibrinólisis)+DAPT; SEST→antitrombótico+GRACE | ECG normal no descarta; **no fibrinólisis en SEST** |
| Choque | Clasificar tipo → causa + volumen ± **noradrenalina** | Obstructivo: quita la obstrucción, no suero |
| Paro/RCP (ACLS) | RCP de calidad + desfibrilar (FV/TVsp) + adrenalina + **5H/5T** | Asistolia/AESP no se desfibrilan |
| ACV/ictus | Glucemia + **TAC urgente** + hora; isquémico→trombólisis | **No antitrombótico hasta TAC** |
| Status epiléptico | **Benzodiacepina YA** → antiepiléptico IV → anestesia | Corrige hipoglucemia/hipoNa; no la retrases |
| Sepsis | **Bundle 1 h** + foco | Antibiótico en la 1ª hora |
| Anafilaxia | **Adrenalina IM en muslo YA** + líquidos | NO es el antihistamínico; vigila bifásica |
| CAD | **Líquidos + insulina IV + K** + gatillo | No insulina si K<3.3; glucosa al bajar de ~200 |
| EHH | **Líquidos agresivos** + insulina + K | El pilar es el líquido (más que insulina) |
| Crisis asmática grave | O₂ + SABA + **esteroide** + ipratropio ± Mg | Silencio/PCO₂ normal = paro inminente |
| EPOC exacerbado | SABA/SAMA + esteroide + ATB si purulencia + O₂ 88-92% + **VMNI** | Narcosis por O₂; VMNI evita intubar |
| TEP | Estable→anticoagular; **inestable→trombólisis** | Alta probabilidad→imagen directa |
| Emergencia HTA | IV, **↓TAM 10-25% 1ª h** | Sin daño = urgencia (VO); disección/eclampsia rápido |
| Intoxicaciones | ABC+glucemia+ECG+toxidrome+**antídoto**+soporte | Carbón no a ciegas; pide paracetamol |
| Hipoglucemia | **Regla del 15** / glucosa IV / glucagón | Tiamina antes en alcohólico; sulfonilurea recurre |
| Hiperkalemia | **Calcio YA** (ECG) → insulina/glucosa+β2 → eliminar | Calcio NO baja el K (protege membrana) |
| Alteración del alerta/coma | ABC+glucemia+cóctel; **GCS≤8→vía aérea** | TAC si focalidad/trauma |
| Hemorragia digestiva alta | Reanimar + **IBP IV** + endoscopia <24 h | Varices→+vasoactivo+antibiótico; estabilizar antes |

## MENOS COMUNES (segunda pasada) — primer movimiento + trampa

**Tóxicos específicos:** Paracetamol (**NAC**, nivel 4 h) · Opioides (**naloxona**) · Benzodiacepinas (soporte; flumazenil con cautela) · Organofosforados (**atropina + pralidoxima**) · Monóxido (**O₂ 100%**/hiperbárica; la oximetría engaña) · Tricíclicos (**bicarbonato** si QRS ancho) · Alcoholes tóxicos (**fomepizol** + diálisis) · Salicilatos (**bicarbonato**/diálisis).
**Ambiental:** Golpe de calor (**enfriamiento agresivo**; antitérmicos no sirven) · Hipotermia (**recalentar**; "no muerto hasta caliente y muerto").
**Vía aérea/obstructivo:** Atragantamiento (golpes + compresiones; **no barrido a ciegas**) · Neumotórax a tensión (**aguja YA**) · Taponamiento (**pericardiocentesis**).
**Sangrado/trauma (enlaces):** Hemorragia masiva (**1:1:1 + TXA <3 h + hipotensión permisiva**) · Quemaduras (vía aérea + **Parkland**).
**Extra:** Mordeduras (**lavado** + profilaxis rabia/tétanos) · Vacunación del adulto (tétanos en heridas) · FUO (**no tratamiento empírico a ciegas**) · Síncope (cardiogénico → ingreso) · Disección aórtica (**betabloqueante antes** del vasodilatador; A→cirugía).
