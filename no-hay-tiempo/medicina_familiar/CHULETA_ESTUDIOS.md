# Chuleta estudios / exploración medicina familiar — herramienta → lectura

> **Regla:** primero el **DISCRIMINADOR** (una herramienta que separa por un hallazgo), luego el
> **PANEL** (la batería que pides por entidad), y de remate los **SIGNOS y SCORES** de memoria.
> En familiar pesa tanto qué pedir como **qué NO pedir de rutina** y cuándo referir.

---

## DISCRIMINADORES (por herramienta)

**1. Otoscopia** → **tímpano abombado/hiperémico** = OMA · nivel/burbujas + retraído = derrame · **conducto edematoso + otorrea** = otitis externa · tapón = cerumen.
*Trampa: dolor al traccionar pabellón = externa; con tímpano abombado = media.*

**2. Espirometría** → **FEV1/FVC <0.70 no reversible** = EPOC · **reversible (ΔFEV1 ≥12% y 200 mL)** = asma · FVC baja con relación normal = restrictivo.
*Trampa: el dx de EPOC exige espirometría; no se hace en la exacerbación aguda.*

**3. ECG (consultorio)** → **ST elevado** = IAMCEST · infra-ST/T invertida = isquemia · **sin P + R-R irregular** = FA · ST difuso cóncavo + PR↓ = pericarditis · QT largo/preexcitación = riesgo de síncope.
*Trampa: ECG normal NO descarta SCA.*

**4. Tira reactiva de orina** → **esterasa + nitritos** = ITU · **hematuria + proteinuria + cilindros** = glomerulopatía (referir) · proteinuria persistente = daño renal (cuantificar RAC) · glucosuria = hiperglucemia.
*Trampa: bacteriuria asintomática NO se trata (salvo embarazo/urológico).*

**5. Glucemia / HbA1c** → **HbA1c ≥6.5%** (o ayuno ≥126 / 2 h ≥200) = diabetes · **5.7-6.4%** = prediabetes · <5.7% = normal.
*Trampa: confirma con 2ª prueba; la HbA1c se altera con anemia/hemoglobinopatías.*

**6. Perfil tiroideo (TSH primero)** → **TSH↑ + T4L↓** = hipotiroidismo · TSH↑ + T4L normal = subclínico · **TSH↓ + T4L↑** = hipertiroidismo.
*Trampa: no pidas TSH en enfermedad aguda grave (eutiroideo enfermo).*

**7. Índices de la anemia (VCM, ferritina, reticulocitos)** → **VCM↓ + ferritina↓** = ferropénica · VCM↓/normal + ferritina normal/alta = enfermedad crónica · **VCM↑ + hipersegmentados** = megaloblástica · reticulocitos↑ = hemólisis/sangrado.
*Trampa: ferropénica en varón/posmenopáusica → estudiar tubo digestivo.*

**8. Exploración del vértigo (Dix-Hallpike / HINTS)** → **Dix-Hallpike +** (breve, fatigable) = VPPB → Epley · **nistagmo que no fatiga / HINTS central** = central (referir).
*Trampa: impulso cefálico NORMAL en vértigo agudo sugiere causa CENTRAL.*

## PANELES (por entidad)

| Entidad | Pido (clave) | Criterio / lo que NO pido |
|---|---|---|
| Crónico DM/HTA | **HbA1c, lípidos, función renal + albuminuria (RAC)**, ECG, fondo de ojo, pies | Integra cifras + daño de órgano + prevención |
| ITU | **Tira/EGO** + urocultivo si complicada/embarazo | No complicada en mujer: empírico sin cultivo |
| Dolor torácico | **ECG inmediato** + SatO₂ + troponina; traslado | ECG normal no descarta SCA |
| Respiratorio | SatO₂ + **Rx si neumonía/derrame/neumotórax** + espirometría programada | No Rx a todo catarro/bronquitis |
| Anemia | **BH + VCM + ferritina** + reticulocitos; B12/folato según patrón | Ferropénica varón/posmenop. → endoscopia |
| Próstata (LUTS) | **Tacto + PSA** + EGO + IPSS | Tamizaje = decisión compartida |
| Preventivo / chequeo | TA, glucosa, lípidos, cáncer (cérvix/mama/colon), **VIH**, vacunas | Por edad/riesgo, no "a todos todo" |
| Cefalea | **Clínico, SIN imagen**; TC/RM solo con banderas | Imagen sin banderas = sobrestudio |
| Digestivo alto (dispepsia/ERGE) | **H. pylori no invasivo** (heces/aliento) ± IBP; suspender AINE | Banderas → endoscopia |
| Diarrea crónica/malabsorción | BH, ferritina, TSH, **serología celíaca** (con gluten), **calprotectina** | Calprotectina separa SII de EII |

## SIGNOS Y SCORES (de memoria)

| Score / signo | Para qué |
|---|---|
| **Centor / McIsaac** | Faringitis estreptocócica → antibiótico |
| **CURB-65** | Gravedad de neumonía → sitio de manejo |
| **Anthonisen** | Exacerbación de EPOC → antibiótico |
| Reversibilidad espirométrica | Asma (reversible) vs EPOC (fija) |
| **Wells (TVP/TEP)** | Probabilidad → dímero D vs imagen |
| **CHA₂DS₂-VASc** | Anticoagulación en FA |
| Banderas de alarma digestivas | Disfagia, ↓peso, sangrado/anemia, vómito persistente, >55-60 a de novo → **endoscopia** (Ca eso-gástrico) |
| Test-and-treat H. pylori | Sin banderas y <60 a: prueba no invasiva → erradicar (dispepsia/úlcera) |
| Criterios de Roma IV | Dx **positivo** del SII (dolor que mejora al evacuar + cambio del hábito, sin banderas) |
| Anti-transglutaminasa (tTG-IgA) | Tamiz de celíaca (pedir **con gluten**) → biopsia confirma |
| Calprotectina fecal | Separa SII (funcional) de EII (orgánico) |
| Lasegue | Ciática / radiculopatía |
| **SNNOOP** | Banderas de cefalea → estudiar |
| Dix-Hallpike / Epley | VPPB (diagnóstico y tratamiento) |
| **HINTS** | Vértigo central vs periférico |
| **FAST** / hora de inicio | EVC → ventana de reperfusión |
| Triada de estenosis aórtica | Angina + síncope + disnea de esfuerzo |
| Triada de Cushing (clínica) | Obesidad central + estrías + cara de luna → cribar |
| Wagner | Úlcera del pie diabético → manejo/derivación |
| IPSS | Gravedad de síntomas prostáticos (HPB) |
| qSOFA | Riesgo de sepsis |

### Plan <3 días
1. **Hoy:** los **8 discriminadores** — "lo pido para separar X de Y, y la trampa es…" en voz alta.
2. **Hoy:** los **paneles** por entidad: batería + criterio + **qué NO pido de rutina**.
3. **Mañana:** memoriza los **scores** (reconocimiento) y enlázalos al caso.
4. **Día 3:** integra los 3 pilares en casos completos (tronco → herramienta/panel → eje de manejo).
