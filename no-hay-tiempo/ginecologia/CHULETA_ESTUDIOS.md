# Chuleta estudios / exploración ginecología — herramienta → lectura

> **Regla:** primero el **DISCRIMINADOR** (una herramienta que separa por un hallazgo), luego el
> **PANEL** (la batería que pides por entidad), y de remate los **patrones de imagen/flujo** que reconoces.

---

## DISCRIMINADORES (por herramienta)

**1. USG transvaginal (útero y anexos)** → endometrio, miomas, quistes anexiales (simple vs complejo), masa; mide grosor endometrial en sangrado posmenopáusico.
*Trampa: endometrio **>4-5 mm posmenopáusico con sangrado** = biopsiar.*

**2. Tacto bimanual** → tamaño/movilidad uterina, masa anexial, **dolor a la movilización cervical** (EIP), nódulos en uterosacros (endometriosis).

**3. Especuloscopia** → aspecto del flujo, cérvix (friable/lesión exofítica), toma de muestras.

**4. pH vaginal + fresco + KOH (whiff)** → **pH >4.5 + whiff+ + clue cells** = vaginosis · **pH >4.5 + flagelado móvil** = tricomonas · **pH <4.5 + hifas/pseudohifas** = candidiasis.
*Trampa: el pH separa candidiasis (ácido) de vaginosis/tricomonas (alcalino).*

**5. Inspección vulvar/perineal** → úlceras (única indurada=sífilis; dolorosas agrupadas=herpes; dolorosa sucia+bubón=chancroide), placas blancas (liquen), verrugas.

**6. Exploración mamaria** → nódulo móvil vs **duro/fijo + piel de naranja/retracción + ganglio**; zona fluctuante (absceso).

**7. Citología (Papanicolaou) + colposcopia** → tamizaje; anormal → colposcopia + biopsia dirigida (define el GRADO: NIC).

**8. USG mama + mamografía (BI-RADS)** → estratifica riesgo; **BI-RADS 4-5 → biopsia**.

## PANELES (por entidad)

| Entidad | Pido (clave) | Criterio / clave |
|---|---|---|
| SOP | Andrógenos, descartar otras causas (TSH, prolactina, 17-OHP), USG, glucosa/lípidos | Rotterdam: 2 de 3 (oligo-anovulación, hiperandrogenismo, USG) |
| Infertilidad | **Estudio de la pareja** (semen, ovulación, permeabilidad tubárica HSG) | Estudiar a ambos tras 12 meses (6 si >35 a) |
| Climaterio/menopausia | Clínico (dx); FSH si dudas; densitometría, lípidos | Dx clínico; cribar contraindicaciones de THR |
| Amenorrea | **β-hCG primero** + TSH/prolactina + FSH/estradiol; progestágeno (reto) | Descartar embarazo SIEMPRE primero |
| SUA / Ca endometrio | USG (grosor endometrial) + **biopsia endometrial** | Sangrado posmenopáusico = biopsia |
| ITS (batería) | Pruebas de clamidia/gonococo, **sífilis (VDRL/RPR→FTA)**, VIH, hepatitis | Cribar coinfecciones; tratar pareja |
| Sífilis (serología) | **No treponémica (VDRL/RPR)** para tamiz/seguimiento + **treponémica (FTA)** confirma | No treponémica titula respuesta; treponémica queda + de por vida |
| Masa anexial / Ca ovario | USG (sólido/septos/papilas/ascitis) + **CA-125** + valoración de riesgo | Posmenopáusica + masa sólida/ascitis → referir |

## PATRONES DE IMAGEN / FLUJO (reconocimiento rápido)

| Hallazgo | Dx |
|---|---|
| Útero globular, miometrio heterogéneo, zona de unión >12 mm | Adenomiosis |
| Quiste con ecos en **vidrio esmerilado** | Endometrioma |
| Foco hiperecoico endometrial con pedículo vascular único | Pólipo |
| Endometrio **>4-5 mm posmenopáusico** + sangrado | Sospecha de Ca endometrio → biopsia |
| Quiste **anecoico unilocular, pared fina <5 cm** | Quiste funcional (vigilar) |
| Masa **sólida/septada, papilas, ascitis** | Sospecha de Ca ovario |
| Nódulos dolorosos en uterosacros + útero fijo | Endometriosis profunda |
| Flujo gris + **whiff+ + clue cells** | Vaginosis bacteriana |
| Flujo verde espumoso + **cérvix en fresa** | Tricomoniasis |
| Nódulo mamario **duro, fijo, piel de naranja, ganglio** | Sospecha de Ca mama → biopsia |
