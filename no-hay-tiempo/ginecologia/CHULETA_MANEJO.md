# Chuleta manejo ginecología — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero el **EJE / patrón madre** (la regla que decide la bifurcación), luego la
> **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag). Memorizas 7 ejes + el primer
> movimiento de cada enfermedad.

---

## 7 EJES / PATRONES MADRE

1. **¿Es ITS de transmisión real? → decide si tratas a la pareja.** Si lo es (clamidia/gonococo, sífilis, tricomonas), trata a la(s) pareja(s); si no (candidiasis, vaginosis), no.
2. **Virus: no se cura, se controla.** VPH y herpes no se "erradican": se vigila/suprime (aciclovir en herpes; seguir la lesión en VPH).
3. **Lesión de cuello: el GRADO decide vigilar / cortar / referir.** NIC 1 → vigilar; NIC 2-3 → escisión (cono/LEEP); invasor → referir oncología.
4. **Mama: el patrón decide observar / drenar / biopsiar.** Quiste/fibroadenoma → seguir; absceso → drenar; **BI-RADS 4-5 → biopsia**.
5. **¿Desea embarazo? → bifurca toda la gine funcional.** SOP, endometriosis, miomatosis y climaterio cambian de tratamiento según el deseo reproductivo.
6. **Absceso = drenar y dejar abierto a epitelizar** (Bartholino, mama) + antibiótico si celulitis.
7. **Estrógeno-dependiente / estructural: ventana hormonal + tópicos.** Climaterio/atrofia → estrógeno (vaginal si solo local), valorando contraindicaciones.

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave | Red flag / trampa |
|---|---|---|
| Sífilis temprana | **Penicilina benzatínica IM** (dosis única) | Tratar pareja; Jarisch-Herxheimer |
| Candidiasis no complicada | Azol (fluconazol VO / tópico) | NO tratar pareja; recurrente = estudiar |
| Tricomoniasis | **Metronidazol** + **tratar pareja** | Es ITS (a diferencia de candidiasis/VB) |
| EIP ambulatoria | **Ceftriaxona + doxiciclina + metronidazol** | Dolor a movilización cervical; DIU/absceso → referir |
| Herpes genital | **Aciclovir/valaciclovir** (episódico o supresor) | No cura; supresión si recurrente/embarazo |
| NIC 1 | **Vigilancia** (suele regresar) | No sobretratar |
| NIC 2-3 | **Escisión (cono/LEEP)** | Lesión de alto grado precursora |
| Ca cérvix invasor | **Referir oncología** (estadificar) | Sangrado poscoital + lesión friable |
| Mama BI-RADS 4-5 | **Biopsia** | No "vigilar" un BI-RADS 4-5 |
| Mastitis puerperal | **Antibiótico (dicloxacilina) + seguir amamantando** | Si no mejora/zona fluctuante → absceso |
| Absceso mamario | **Drenaje** + antibiótico | Drenar, no solo antibiótico |
| SOP con deseo de embarazo | **Letrozol** (inducción) + estilo de vida | — |
| SOP sin deseo | **Anticonceptivo combinado** + estilo de vida | Metformina si resistencia/intolerancia |
| Endometriosis | Analgesia + **hormonal (ACO/progestágeno)**; cirugía si falla/infertilidad | Dolor + dispareunia + infertilidad |
| Miomatosis sintomática | Según deseo: hormonal/AINE vs miomectomía/histerectomía | Sangrado abundante + anemia |
| Climaterio sintomático | **Terapia hormonal** (ventana) o no hormonal; vaginal si solo atrofia | Cribar contraindicaciones |
| Absceso de Bartholino | **Drenaje + marsupialización** (catéter de Word) | No solo incisión simple |
| Liquen escleroso | **Corticoide tópico potente** + seguimiento | Riesgo de Ca vulvar → biopsia si dudas |

## MENOS COMUNES (segunda pasada) — primer movimiento + trampa

**ITS/flujo:** Sífilis latente tardía (penicilina **3 dosis** semanales) · Chancroide (azitromicina/ceftriaxona) · VPH condilomas (tópico/ablación; no cura el virus) · Vaginosis bacteriana (metronidazol; **no es ITS**, no tratar pareja) · Cervicitis (ceftriaxona + doxiciclina; tratar pareja).
**Tamizaje/oncología:** Tamizaje cervical (21-65 a, citología/co-test) · Papanicolaou anormal (ASC-US→VPH reflejo; LSIL/HSIL→colposcopia) · Ca endometrio (sangrado posmenopáusico → biopsia; referir) · Ca ovario (masa sólida/ascitis → referir; CA-125).
**Mama:** Fibroadenoma (joven, móvil → seguir) · Quiste simple (fluctúa con ciclo) · Paget (eccema del pezón que no cura → biopsia) · Telorrea patológica (**unilateral, uniporo, sanguinolenta** → estudiar).
**Estructural/funcional:** Adenomiosis (útero globular doloroso; hormonal/histerectomía) · Prolapso (pesarios/Kegel vs cirugía) · Patología vulvoperineal (lesión persistente → **biopsia**) · Infertilidad (estudiar a **la pareja** tras 12 meses).
