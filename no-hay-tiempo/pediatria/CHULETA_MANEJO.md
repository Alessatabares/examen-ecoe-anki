# Chuleta manejo pediatría — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero el **EJE / patrón madre** (la regla que decide la bifurcación), luego la
> **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag). En pediatría casi todo
> se decide por **TEP + edad + peso**.

---

## 8 EJES / PATRONES MADRE

1. **TEP primero: "¿se ve mal?"** Apariencia + Respiración + Circulación (observacional, antes de tocar) → decide la urgencia antes del dx.
2. **El lactante febril se estratifica por EDAD.** ≤28 d: estudio completo + LCR + ATB + ingreso SIEMPRE · 29-60 d: sangre+orina, PL/ATB según PCT/PCR · >3 m: según foco/aspecto.
3. **Todo por PESO/EDAD:** dosis en mg/kg, equipo por edad (Broselow), signos vitales por edad. **Glucemia siempre** en el niño grave.
4. **Fiebre + exantema:** pródromo + morfología dan el dx; **petequias que no blanquean + mal estado = meningococemia → ATB YA**.
5. **Deshidratación:** clasifico el grado → **plan A (casa) / B (SRO oral) / C (IV)**. Oral de elección salvo choque/intolerancia.
6. **Estridor = obstrucción alta** (crup vs epiglotitis vs cuerpo extraño); **no agites al niño** (empeora la vía aérea).
7. **Choque pediátrico:** **taquicardia es precoz, hipotensión es TARDÍA** (preterminal); bolos 10-20 mL/kg.
8. **El niño sano es consulta:** vacunas, desarrollo, crecimiento y **maltrato** (lesión incongruente → notificar).

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave | Red flag / trampa |
|---|---|---|
| Reanimación neonatal | **VPP** es la clave (no masaje/fármacos); 3:1 si FC<60 | Causa del paro = respiratoria |
| Ictericia neonatal | **Fototerapia** según umbral por horas/EG | <24 h = hemólisis; vigila kernícterus |
| Sepsis neonatal | Cultivos + **ATB ya** (ampi+genta) | Signos sutiles; no esperar |
| Fiebre sin foco <3 m | Estratificar por edad; orina por sondaje | Neonato: estudio+ATB+ingreso aunque se vea bien |
| ITU pediátrica | **Urocultivo válido** + ATB; eco renal post-febril | Bolsa solo descarta; ITU = fiebre sin foco |
| Bronquiolitis | **Soporte** (O₂<90%, hidratación) | NO broncodilatador/esteroide/ATB de rutina |
| Crup | **Dexametasona** ± adrenalina nebulizada si grave | Calmar al niño; ≠ epiglotitis |
| Neumonía | **Amoxicilina**; O₂/ingreso si grave | Taquipnea = mejor signo |
| Asma (crisis) | O₂ + SABA + **esteroide precoz** ± Mg | Silencio/somnolencia = grave |
| Otitis media | **Analgesia** + amoxicilina (o observar 48-72 h) | Mastoiditis → urgencia |
| Faringitis estrep | **McIsaac** → penicilina/amoxicilina | Previene fiebre reumática; <3 a casi nunca |
| GEA/deshidratación | Grado → **plan A/B/C**; seguir alimentando | Oral de elección; no ATB de rutina |
| Convulsión febril | Simple → **buscar el foco**, sin EEG/TAC/PL | Estatus → benzodiacepina; descartar meningitis |
| Meningitis | **ATB empírico urgente** ± dexametasona | Lactante: fontanela abombada; petequias=meningococo |
| Kawasaki | **IgIV + aspirina** + **ecocardiograma** | Riesgo = aneurisma coronario; tratar <10 d |
| PALS (paro) | RCP de calidad + tratar causa | Causa = **hipóxica**; ventilar |
| Vacunas | Completar según edad (oportunidad) | No reiniciar por retraso; vivos en inmunodepresión |
| Desarrollo/crecimiento | Hitos por área + curvas | **Regresión** de hitos = urgente |

## MENOS COMUNES (segunda pasada) — primer movimiento + trampa

**Neonatal:** Meningitis neonatal (ampi+cefotaxima; cubre Listeria) · TORCH (sospechar/estudiar; CMV la más frecuente) · Conjuntivitis neonatal (por día: gonococo urgente / Chlamydia **oral**) · VIH perinatal (TAR materna + profilaxis; **dx por PCR**).
**Vía aérea/respiratorio:** Epiglotitis (**vía aérea en quirófano, no explorar garganta** + cefalosporina) · Tos ferina (**azitromicina** + profilaxis a contactos; vigila apnea en <6 m).
**Exantemas:** Sarampión (**vitamina A** + aislar + notificar) · Escarlatina (penicilina) · Varicela (soporte, **NO aspirina** → Reye) · Roséola/eritema infeccioso/mano-pie-boca (soporte) · Rubéola (soporte; riesgo congénito).
**Piel/infeccioso:** Impétigo (tópico si localizado, oral si extenso) · Parasitosis (albendazol/metronidazol según agente + higiene).
**Social/urgencia:** **Maltrato** (proteger + estudio dirigido + **notificar**) · **Atragantamiento** (tos efectiva→animar; lactante 5 golpes+5 compresiones; niño Heimlich; **no barrido a ciegas**).
**Preventivo/cirugía:** Anemia ferropénica del lactante (hierro + reducir leche de vaca) · Displasia de cadera (**Ortolani/Barlow** + USG/Rx → Pavlik) · Abdomen quirúrgico (invaginación: enema; pilórica: corregir+piloromiotomía; **vómito bilioso=urgencia**) → Cirugía · Soplo (inocente vs patológico) → Ruidos Cardíacos.
