# Chuleta estudios / exploración pediatría — herramienta → lectura

> **Regla:** primero el **DISCRIMINADOR** (una herramienta que separa por un hallazgo), luego el
> **PANEL** (la batería que pides por entidad), y de remate los **SIGNOS y SCORES** de memoria.
> En pediatría pesa tanto qué pedir como **qué NO de rutina** (bronquiolitis/crup/febril simple).

---

## DISCRIMINADORES (por herramienta)

**1. TEP (Triángulo de Evaluación Pediátrica)** → **Apariencia** alterada = SNC/metabólico/sepsis · **Respiración** = dificultad respiratoria · **Circulación** = choque · los 3 = falla cardiopulmonar.
*Trampa: es observacional (sin tocar); un solo lado alterado ya cambia la prioridad.*

**2. Exantemas** → Koplik+coriza = sarampión · vesículas en estadios = varicela · piel en lija+lengua aframbuesada = escarlatina · fiebre 3 d que cede→exantema = roséola · "cara abofeteada" = eritema infeccioso · **petequias que no blanquean+mal estado = meningococemia**.
*Trampa: en toda fiebre+exantema busca petequias que no blanquean (diascopia).*

**3. Estridor (vía aérea alta)** → tos perruna+disfonía = crup · **fiebre alta+babeo+trípode+tóxico (sin tos perruna) = epiglotitis** · inicio súbito atragantado = cuerpo extraño · desde el nacimiento = laringomalacia.
*Trampa: en epiglotitis NO explores la garganta ni agites al niño.*

**4. Lactante febril (edad + biomarcadores)** → **≤28 d** = estudio completo+LCR+ATB+ingreso · **29-60 d** = sangre+orina, PL/ATB según PCT-PCR · **>3 m buen aspecto+foco** = menos estudio · **mal aspecto (TEP)** = agresivo.
*Trampa: el ASPECTO manda sobre la escala; orina por sondaje, no bolsa.*

**5. Grado de deshidratación** → alerta/sin signos = Plan A · ojos hundidos/pliegue lento/sed = Plan B (SRO) · letárgico/no bebe/llenado lento = Plan C (IV) · hipotensión = choque (IV ya).
*Trampa: la hipotensión es TARDÍA en el niño; pesa al niño para reponer.*

**6. Bilirrubina neonatal** → **<24 h = patológica (hemólisis)** · pasa umbral por horas/EG = tratar (fototerapia) · 2-3 d, buen estado = fisiológica · **prolongada/colestasis (acolia/coluria) = estudiar (atresia)**.
*Trampa: bilirrubina directa alta + acolia = colestasis (atresia biliar), no fisiológica.*

**7. Punción lumbar / LCR** → PMN + glucosa baja + proteínas altas + turbio = bacteriana · linfocitos + glucosa normal = viral.
*Trampa: si está inestable o hay HTIC, da antibiótico YA y difiere la PL.*

**8. Taquipnea y trabajo respiratorio** → **taquipnea (OMS: <2 m ≥60; 2-12 m ≥50; 1-5 a ≥40) = mejor signo de neumonía** · sibilancias 1er episodio <2 a = bronquiolitis · estridor = obstrucción alta · tiraje/aleteo/quejido/apneas = grave.
*Trampa: bronquiolitis y crup son clínicos; la Rx NO es de rutina.*

## PANELES (por entidad)

| Entidad | Pido (clave) | Criterio / lo que NO pido |
|---|---|---|
| Fiebre sin foco <3 m | BH+PCR/PCT, **hemocultivo, EGO+urocultivo**, valorar LCR | ≤28 d: completo+ATB+ingreso; orina por sondaje |
| Sepsis neonatal | **Hemocultivo** + BH + orina + valorar PL | No retrasar ATB (ampi+genta) |
| ITU pediátrica | EGO + **urocultivo válido**; **eco renal** post-febril | Bolsa solo descarta |
| Kawasaki | Clínica + reactantes + **ECOCARDIOGRAMA** | Aneurismas; ojo con el incompleto |
| Convulsión febril | Simple: **buscar foco**, sin EEG/TAC/PL | PL si meningismo/mal aspecto/dudas |
| Respiratorio | **Clínico**; Rx solo si duda/gravedad/complicación | No Rx ni broncodilatador de rutina |
| Maltrato | **Serie ósea** (<2 a), **fondo de ojo**, neuroimagen | Documentar objetivo; **notificar** |
| RN sano | **Tamiz metabólico, auditivo, cardiopatía (oximetría), caderas, reflejo rojo** | Detecta en presintomático |

## SIGNOS Y SCORES (de memoria)

| Score / signo | Para qué |
|---|---|
| **TEP** | Gravedad/urgencia antes de tocar (apariencia/respiración/circulación) |
| APGAR | Evalúa al RN (1 y 5 min); NO dirige la reanimación |
| **Manchas de Koplik** | Sarampión (preceden al exantema) |
| Lengua aframbuesada + piel en lija | Escarlatina |
| **Criterios de Kawasaki** | Fiebre ≥5 d + 4/5 → riesgo aneurisma coronario |
| **Centor / McIsaac** | Faringitis estreptocócica → prueba/ATB |
| **Westley** | Gravedad del crup → adrenalina |
| **Taquipnea por edad (OMS)** | Mejor signo de neumonía |
| Signos de deshidratación / planes A-B-C | Grado → vía (casa/SRO/IV) |
| **Fontanela abombada** | Meningitis/HTIC en el lactante |
| Kernig / Brudzinski | Meningismo (poco fiables en lactante) |
| **Petequias que no blanquean** | Meningococemia → ATB YA |
| **Ortolani / Barlow** | Displasia de cadera (DDC) |
| Tos en accesos + gallo + vómito | Tos ferina (apnea en <6 m) |
| Vómito en proyectil no bilioso + oliva | Estenosis pilórica (bilioso = obstrucción) |
| Heces en jalea de grosella + masa | Invaginación |
| Ritmos de paro (PALS) | Desfibrilables (FV/TVsp) vs no (asistolia/AESP); causa hipóxica |
