# Chuleta estudios / exploración cirugía — herramienta → lectura

> **Regla:** primero el **DISCRIMINADOR** (una herramienta que separa por un hallazgo), luego el
> **PANEL** (la batería que pides por entidad), y de remate los **signos y scores** de memoria.
> En cirugía: el inestable se estabiliza/opera; el TAC es para el estable.

---

## DISCRIMINADORES (por herramienta)

**1. eFAST** → líquido libre (Morrison/Douglas) = hemoperitoneo · líquido pericárdico = taponamiento · ausencia de deslizamiento pleural = neumotórax · derrame pleural = hemotórax.
*Trampa: FAST+ inestable = quirófano; FAST– NO descarta lesión de víscera hueca.*

**2. Rx de tórax (trauma/disnea)** → hemitórax hiperclaro = neumotórax · opaco con menisco = hemotórax · **mediastino ancho (>8 cm)** = lesión aórtica · aire subdiafragmático = neumoperitoneo.
*Trampa: el neumotórax a tensión es CLÍNICO (no esperes la Rx).*

**3. Rx de abdomen** → niveles hidroaéreos = obstrucción · **aire libre subdiafragmático** = perforación · "grano de café" = vólvulo · asa centinela = pancreatitis/íleo localizado.
*Trampa: Rx normal NO descarta; ante alta sospecha, TAC.*

**4. TAC de abdomen con contraste** → caracteriza el abdomen agudo en el **estable**: apendicitis, diverticulitis (Hinchey), **isquemia (neumatosis/gas portal)**, absceso, sangrado activo.
*Trampa: no mandes al inestable al TAC.*

**5. Exploración abdominal (signos)** → McBurney/Blumberg/Rovsing/psoas (apendicitis) · Murphy (colecistitis) · **defensa + rebote difuso** (peritonitis) · Cullen/Grey-Turner (hemorragia retroperitoneal).
*Trampa: defensa involuntaria que no cede al distraer = peritonismo real.*

**6. Lactato + gasometría** → lactato alto = hipoperfusión/shock · muy alto + dolor desproporcionado = isquemia mesentérica · no aclara con reanimación = mal pronóstico.
*Trampa: lactato normal no descarta isquemia temprana.*

**7. SNG + tacto rectal** → aspirado con sangre/posos = HDA · melena = sangrado alto · hematoquecia = HDB (o HDA masiva).
*Trampa: aspirado limpio no descarta HDA (sangrado pospilórico).*

**8. Eco Doppler (torsión)** → testículo/ovario sin flujo = torsión; hiperemia = epididimitis/orquitis.
*Trampa: si la clínica de torsión es clara, la **cirugía no espera al Doppler**.*

## PANELES (por entidad)

| Entidad | Pido (clave) | Criterio / clave |
|---|---|---|
| Trauma (ATLS) | **eFAST + Rx tórax/pelvis + lactato + grupo y cruzar** + β-hCG; TAC si estable | **Inestable = quirófano** (FAST/Rx); TAC para el estable |
| Pancreatitis | **Lipasa (>3×)** + PFH + calcio/TG + USG; TAC a las 72 h si dudas | Dx: 2 de 3; no TAC de entrada en la leve |
| Biliar / colangitis | PFH **colestásico** (BT/FA/GGT) + USG (dilatación) + **CPRE** | Colangitis = infección + obstrucción → CPRE |
| Sepsis (bundle 1 h) | **Lactato + hemocultivos antes del ATB** + cultivos del foco | Controlar el FOCO |
| Hemorragia / transfusión masiva | BH seriada + **grupo y cruzar + coagulación/fibrinógeno + calcio** | **1:1:1 + TXA <3 h + hipotensión permisiva** |
| Abdomen agudo (general) | BH/PCR + lactato + amilasa/lipasa + PFH + EGO + **β-hCG** | β-hCG **siempre** en mujer fértil |
| Vascular (AAA/disección) | **Angio-TAC** (si estable) + ECG/troponina (dif. SICA) + grupo y cruzar | Inestable con AAA = quirófano sin TAC |
| Obstrucción | Rx abdomen + **TAC con contraste** + electrolitos + **lactato** | TAC distingue simple vs estrangulada |

## SIGNOS Y SCORES (de memoria)

| Signo / score | Para qué |
|---|---|
| Blumberg (rebote) | Irritación peritoneal |
| Rovsing / psoas / obturador | Apendicitis |
| Murphy | Colecistitis |
| Cullen / Grey-Turner | Hemorragia retroperitoneal (pancreatitis grave, AAA, ectópico) |
| **Neumoperitoneo** (aire subdiafragmático) | Perforación de víscera |
| Niveles hidroaéreos | Obstrucción |
| "Grano de café" | Vólvulo de sigmoides |
| **Mediastino ancho (>8 cm)** | Lesión/disección aórtica |
| **Triada de Beck** | Taponamiento |
| Charcot / pentada de Reynolds | Colangitis |
| Escala de Alvarado | Probabilidad de apendicitis |
| Clasificación de Forrest | Úlcera sangrante (riesgo de resangrado) |
| Ranson / BISAP | Gravedad de pancreatitis |
| Clasificación de Hinchey | Diverticulitis complicada (drenaje vs cirugía) |
| LRINEC | Apoya fascitis necrotizante |
| Lactato | Hipoperfusión/isquemia (aclaramiento = pronóstico) |
