# Chuleta manejo cirugía — eje → conducta (para verbalizar al sinodal)

> **Regla:** primero el **EJE / patrón madre** (la regla que decide la bifurcación), luego la
> **CONDUCTA** de la entidad (verbalizo → conducta/consejería → red flag). Memorizas 7 ejes + el primer
> movimiento de cada cuadro.

---

## 7 EJES / PATRONES MADRE

1. **ABCDE: trato primero lo que MATA, no lo que duele.** Reevaluar desde A ante deterioro. Lo que mata en B (neumotórax a tensión, hemotórax masivo) y en C (hemorragia).
2. **ESTABLE vs INESTABLE decide TAC vs QUIRÓFANO.** Inestable que no responde → quirófano YA; estable → imagen para caracterizar. *"El TAC es el túnel de la muerte" para el inestable.*
3. **Hemorragia: control de daño + reanimación equilibrada.** Control del sangrado + **1:1:1 + TXA <3 h + hipotensión permisiva** (salvo TCE); corrige la triada letal.
4. **Abdomen agudo: si hay IRRITACIÓN PERITONEAL, va a quirófano.** La pregunta es "¿tiene abdomen quirúrgico?". Neumoperitoneo = víscera perforada.
5. **Obstrucción: descomprimo (NPO+SNG+líquidos) y vigilo ESTRANGULACIÓN.** Simple → conservador; estrangulación/asa cerrada/hernia incarcerada → cirugía.
6. **Sepsis quirúrgica: control del FOCO manda** (drenar/resecar/desbridar) + bundle 1 h. Antibiótico sin control del foco fracasa.
7. **Tiempo = tejido:** torsión, isquemia mesentérica, fascitis, compartimental, disección A, AAA roto → se actúa con alta sospecha (la imagen no retrasa el quirófano).

## MANEJOS COMUNES (core) — el primer movimiento

| Entidad | Conducta clave | Red flag / trampa |
|---|---|---|
| Apendicitis | NPO + ATB + **apendicectomía** | No retrasar (perforación) |
| Colecistitis | NPO + ATB + **colecistectomía temprana (<72 h)** | Murphy+; si ictericia/fiebre → colangitis |
| Colangitis | ATB IV + **descompresión biliar urgente (CPRE)** | Charcot/Reynolds = urgencia |
| Pancreatitis | **Líquidos** + analgesia + NPO; tratar causa; **no ATB de rutina** | Vigilar falla orgánica 48 h |
| Diverticulitis | No complicada → reposo ± ATB; complicada → drenaje/cirugía | Colonoscopia **tras** resolver |
| Obstrucción | **NPO + SNG + líquidos**; cirugía si estrangula | Continuo+fiebre+lactato = estrangulación |
| Perforación de víscera | ATB + **cirugía (laparotomía/reparación)** | **Neumoperitoneo** confirma |
| HDA por úlcera | Reanimar + **IBP IV** + **endoscopia <24 h**; Hb meta ~7 | Erradicar H. pylori; suspender AINE |
| HDA por varices | Reanimar + **vasoactivo + ceftriaxona + ligadura** | Antibiótico mejora supervivencia |
| HDB | Reanimar + **colonoscopia**; masiva → angio-TAC/embolización | Descartar HDA si inestable |
| Neumotórax a tensión | **Descompresión con aguja YA** → tubo (dx CLÍNICO) | No esperar Rx |
| Taponamiento | **Pericardiocentesis** / toracotomía | Triada de Beck |
| Hemotórax masivo | **Tubo de tórax** + hemoderivados; toracotomía si >1500 mL | Es problema de B y de C |
| Choque hipovolémico | ABC + 2 vías + **hemoderivados 1:1:1 + TXA** | No solo cristaloides |
| AAA roto | **Reanimación hipotensiva + cirugía/EVAR YA** | Inestable → quirófano sin TAC |
| Isquemia mesentérica | Reanimar + **anticoagular + revascularizar + resecar** | Dolor desproporcionado + lactato |
| Peritonitis | ATB + **cirugía (control del foco + lavado)** | Abdomen en tabla → quirófano |
| Sepsis / choque séptico | **Bundle 1 h** + control del foco | Antibiótico en la 1ª hora |

## MENOS COMUNES (segunda pasada) — primer movimiento + trampa

**Trauma:** penetrante (inestable/evisceración → laparotomía) · cerrado (FAST+ inestable → laparotomía; estable → TAC) · esplénica (estable → no operatorio ± embolización; vacunas post-esplenectomía) · tórax inestable (analgesia + el riesgo es la **contusión pulmonar**) · fractura pélvica (**faja** + reanimación + angioembolización).
**Obstrucción/abdomen:** vólvulo (sigmoides → descompresión endoscópica; ciego → cirugía) · hernia (estrangulada → **cirugía urgente, no reducir**) · íleo (tratar la causa) · asa cerrada (urgencia quirúrgica).
**Infección de partes blandas:** absceso (**drenaje** + ATB) · **fascitis necrotizante** (desbridamiento urgente + ATB amplio; la cirugía no espera al cultivo) · gangrena gaseosa (desbridar + penicilina/clindamicina).
**Tiempo = tejido:** torsión testicular (**cirugía <6 h** + orquidopexia bilateral) · torsión ovárica (laparoscopia: detorsión + preservar) · **disección aórtica** (betabloqueante ANTES del vasodilatador; A → cirugía) · síndrome compartimental (**fasciotomía**) · ectópico roto (reanimar + **salpingectomía**).
